**배열**은 컴퓨터 과학에서 가장 단순하고 기본적인 자료구조입니다. 연속된 메모리 위치에 요소를 저장하여 인덱스로 상수 시간 접근을 가능하게 합니다. 거의 모든 다른 자료구조가 배열 위에 구축되거나 배열과 비교되므로, 배열을 깊이 이해하는 것은 필수적입니다.

## 배열이란?

배열은 연속된 메모리 블록에 저장된, 고정 크기의 순서 있는 요소 모음입니다. 각 요소는 동일한 크기의 공간을 차지하며, 인덱스를 사용하여 어떤 요소든 직접 접근할 수 있습니다.

```
인덱스:   0     1     2     3     4
        +-----+-----+-----+-----+-----+
배열:   | 10  | 20  | 30  | 40  | 50  |
        +-----+-----+-----+-----+-----+
주소:    1000  1008  1016  1024  1032
        기본  +8    +16   +24   +32

요소 i의 주소 = 기본_주소 + i * 요소_크기
```

### 핵심 속성

| 속성 | 설명 |
|------|------|
| **연속 메모리** | 요소들이 RAM에서 나란히 저장됨 |
| **고정 크기** (정적) | 크기가 생성 시 결정되며 변경 불가 |
| **동질적** (전통적) | 모든 요소가 동일한 타입을 공유 |
| **임의 접근** | 인덱스 산술로 어떤 요소든 O(1)에 접근 |

### 연속 메모리가 중요한 이유

현대 CPU는 메모리 접근 속도를 높이기 위해 **캐시 계층** (L1, L2, L3)을 사용합니다. 배열의 한 요소에 접근하면 CPU는 전체 **캐시 라인** (일반적으로 64바이트)을 캐시에 로드합니다. 배열 요소는 연속적이므로 다음 요소들이 이미 캐시에 있을 가능성이 높습니다. 이를 **공간 지역성**이라 하며, 실제로 배열 순회를 매우 빠르게 만듭니다.

```
CPU 캐시 라인 (64 바이트):
+------+------+------+------+------+------+------+------+
| a[0] | a[1] | a[2] | a[3] | a[4] | a[5] | a[6] | a[7] |
+------+------+------+------+------+------+------+------+
   하나의 메모리 읽기로 모두 로드 -- 이후 접근은 캐시 히트!
```

## Python의 정적 배열: `array` 모듈

Python에는 C 스타일의 정적 배열이 없지만, `array` 모듈은 리스트보다 컴팩트하게 요소를 저장하는 타입 배열을 제공합니다:

```python
import array

# 부호 있는 정수 배열 생성
nums = array.array('i', [10, 20, 30, 40, 50])

# 인덱스로 접근 -- O(1)
print(nums[2])  # 30

# 배열은 타입이 지정됨 -- TypeError 발생:
# nums.append("hello")
```

## 동적 배열: Python의 `list`

Python의 `list`는 **동적 배열**입니다 -- 더 많은 공간이 필요하면 자동으로 크기를 조정합니다. 내부적으로 리스트는 다음을 유지합니다:

1. 객체에 대한 **참조**를 보관하는 연속 메모리 블록에 대한 포인터
2. 현재 **길이** (요소 수)
3. 현재 **용량** (할당된 슬롯)

```
Python list 내부 구조:
+------------------+
| length: 5        |
| capacity: 8      |
| data_ptr: ------>+--+-----+-----+-----+-----+-----+-----+-----+-----+
+------------------+  | ptr | ptr | ptr | ptr | ptr |     |     |     |
                      +--+--+--+--+--+--+--+--+--+--+-----+-----+-----+
                         |     |     |     |     |
                         v     v     v     v     v
                        10    20    30    40    50
                                          (향후 성장을 위한 빈 슬롯 3개)
```

### 동적 크기 조정 원리

가득 찬 리스트에 `append()`를 할 때 (length == capacity), Python은:

1. **새로운, 더 큰** 메모리 블록을 할당합니다 (대략 이전 용량의 1.125배)
2. 모든 기존 참조를 새 블록에 복사합니다
3. 이전 블록을 해제합니다
4. 새 요소를 삽입합니다

### 분할 상환 분석

개별 크기 조정 연산은 모든 요소를 복사하므로 O(n)입니다. 그러나 크기 조정은 드물게 발생하고 (용량이 기하급수적으로 증가하므로), `append()`의 **분할 상환 비용**은 **O(1)**입니다.

## 리스트 연산의 시간 복잡도

| 연산 | 평균 | 최악 | 비고 |
|------|------|------|------|
| `lst[i]` (접근) | O(1) | O(1) | 직접 인덱스 산술 |
| `lst[i] = x` (할당) | O(1) | O(1) | 직접 인덱스 산술 |
| `lst.append(x)` | O(1)* | O(n) | 분할 상환 O(1) |
| `lst.insert(i, x)` | O(n) | O(n) | 요소를 오른쪽으로 이동 |
| `lst.pop()` | O(1) | O(1) | 끝에서 제거 |
| `lst.pop(i)` | O(n) | O(n) | 요소를 왼쪽으로 이동 |
| `x in lst` | O(n) | O(n) | 선형 스캔 |
| `len(lst)` | O(1) | O(1) | 속성으로 저장됨 |
| `lst.sort()` | O(n log n) | O(n log n) | Timsort |

*분할 상환

## 인덱싱과 슬라이싱

Python은 음수 인덱스와 슬라이싱으로 강력한 인덱싱을 지원합니다:

```python
fruits = ["apple", "banana", "cherry", "date", "elderberry"]

# 양수 인덱싱 (0부터 시작)
fruits[0]    # "apple"
fruits[2]    # "cherry"

# 음수 인덱싱 (끝에서부터)
fruits[-1]   # "elderberry"
fruits[-2]   # "date"

# 슬라이싱: lst[start:stop:step]
fruits[1:3]    # ["banana", "cherry"]       -- start 포함, stop 미포함
fruits[:3]     # ["apple", "banana", "cherry"]  -- 처음부터
fruits[2:]     # ["cherry", "date", "elderberry"]  -- 끝까지
fruits[::2]    # ["apple", "cherry", "elderberry"] -- 2번째 요소마다
fruits[::-1]   # 역순 리스트
```

## 일반적인 리스트 패턴

### 리스트 컴프리헨션

리스트를 간결하게 생성하는 방법:

```python
# 기본 컴프리헨션
squares = [x ** 2 for x in range(10)]

# 조건 포함 (필터)
evens = [x for x in range(20) if x % 2 == 0]

# 중첩 컴프리헨션 (행렬)
matrix = [[i * 3 + j for j in range(3)] for i in range(3)]

# 행렬 평탄화
flat = [x for row in matrix for x in row]
```

### 투 포인터 기법

배열 문제를 효율적으로 해결하는 일반적인 패턴:

```python
def two_sum_sorted(nums, target):
    """정렬된 리스트에서 합이 target인 두 수를 찾습니다.
    
    투 포인터 사용 -- O(n) 시간, O(1) 공간.
    """
    left, right = 0, len(nums) - 1
    while left < right:
        current_sum = nums[left] + nums[right]
        if current_sum == target:
            return (left, right)
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    return None
```

### 슬라이딩 윈도우

또 다른 강력한 배열 기법:

```python
def max_sum_subarray(nums, k):
    """길이 k인 부분 배열의 최대 합을 찾습니다.
    
    슬라이딩 윈도우 -- O(n) 시간, O(1) 공간.
    """
    if len(nums) < k:
        return None
    window_sum = sum(nums[:k])
    max_sum = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, window_sum)
    return max_sum
```

## 배열/리스트를 사용할 때

**리스트 사용이 적합한 경우:**
- 인덱스로 임의 접근이 필요할 때
- 대부분의 연산이 끝에서 이루어질 때 (append/pop)
- 데이터 크기가 적당할 때

**리스트 사용을 피해야 하는 경우:**
- 시작이나 중간에서 자주 삽입/삭제할 때 (`deque` 사용)
- 빠른 멤버십 테스트가 필요할 때 (`set` 사용)
- 키-값 연관이 필요할 때 (`dict` 사용)

## 요약

| 개념 | 핵심 요점 |
|------|----------|
| 정적 배열 | 고정 크기, 연속, O(1) 접근 |
| 동적 배열 | 크기 조정 가능, 분할 상환 O(1) append |
| Python `list` | 객체 참조의 동적 배열 |
| 인덱싱 | O(1) 접근, 음수 인덱스 지원 |
| 슬라이싱 | 새 리스트 생성, k개 요소에 O(k) |
| 중간 삽입/삭제 | 이동으로 인해 O(n) |
| 캐시 친화성 | 연속 메모리 = 빠른 순회 |
