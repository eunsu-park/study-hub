# 자료구조

자료구조는 효율적인 소프트웨어의 기본 구성 요소입니다. 데이터가 어떻게 구성, 접근, 수정되는지를 결정하며, 작성하는 모든 프로그램의 성능과 확장성에 직접적인 영향을 미칩니다. 이 토픽은 기본 자료구조, Python에서의 구현, 그리고 하나의 구조를 다른 구조 대신 선택하는 이유에 대한 철저한 입문을 제공합니다.

## 학습 내용

이 토픽은 다음의 실습 중심 내용을 제공합니다:
- **배열과 리스트**: 동적 배열, 인덱싱, 슬라이싱, 분할 상환 시간 복잡도
- **연결 리스트**: 단일, 이중, 원형 연결 리스트와 포인터 조작
- **스택과 큐**: LIFO/FIFO 추상화, 구현, 실제 활용
- **해시 테이블**: 해시 함수, 충돌 해결, Python의 dict 내부 구조
- **트리**: 이진 트리, 순회, 이진 탐색 트리, 균형 트리 개념
- **힙**: 최소 힙, 최대 힙, 우선순위 큐 연산
- **그래프**: 표현 방법, 용어, BFS, DFS
- **집합과 맵**: 수학적 집합 연산, 맵 추상화, 구현
- **문자열 자료구조**: 트라이, 접미사 배열, 패턴 매칭 기초
- **정렬과 탐색**: 고전 알고리즘과 복잡도 분석
- **자료구조 선택**: 트레이드오프 분석과 의사결정 프레임워크

## 권장 학습 순서

01부터 14까지 순서대로 진행하세요. 각 레슨은 이전 레슨에서 소개된 개념을 기반으로 합니다:

1. **선형 구조 (레슨 1-4)**: 배열, 연결 리스트, 스택, 큐는 모든 자료구조의 기초를 형성합니다
2. **연관 구조 (레슨 5)**: 해시 테이블은 딕셔너리와 집합을 구동합니다 -- 실무 프로그래밍의 핵심 도구
3. **계층 구조 (레슨 6-8)**: 트리와 힙은 재귀적 데이터 구성을 소개합니다
4. **그래프 구조 (레슨 9)**: 그래프는 트리를 일반화하여 네트워크와 관계를 모델링합니다
5. **특수 구조 (레슨 10-11)**: 집합, 맵, 문자열 전용 구조
6. **구조 위의 알고리즘 (레슨 12-13)**: 정렬과 탐색이 모든 것을 연결합니다
7. **종합 (레슨 14)**: 각 작업에 맞는 올바른 도구를 선택하는 방법을 배웁니다
