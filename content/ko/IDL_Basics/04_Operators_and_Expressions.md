# 연산자와 표현식

**이전**: [배열과 연산](./03_Arrays_and_Operations.md) | **다음**: [제어 흐름](./05_Control_Flow.md)

## 학습 목표

이 레슨을 완료하면 다음을 할 수 있습니다:

1. 스칼라와 배열에 산술 연산자 (+, -, *, /, ^, MOD) 사용하기
2. 관계 연산자 (EQ, NE, LT, GT, LE, GE) 적용하기
3. 논리 연산자 (AND, OR, NOT, XOR)로 조건 결합하기
4. 비트 연산 이해하기
5. + 연산자로 문자열 연결하기
6. IDL의 연산자 우선순위 규칙 따르기
7. 삼항 연산자 유사 패턴으로 복잡한 표현식 작성하기

---

연산자는 IDL 표현식의 구성 요소입니다. IDL은 배열 지향적이므로 대부분의 연산자는 배열에 대해 요소별로 동작하여, 명시적 루프 없이 전체 데이터셋에 대한 계산을 간단하게 만듭니다.

## 산술 연산자

```idl
a = 15
b = 4
PRINT, a + b       ;       19   덧셈
PRINT, a - b       ;       11   뺄셈
PRINT, a * b       ;       60   곱셈
PRINT, a / b       ;        3   정수 나눗셈 (버림)
PRINT, a ^ 2       ;      225   거듭제곱
PRINT, a MOD b     ;        3   나머지 (모듈로)
```

### 정수 나눗셈 함정

```idl
PRINT, 7 / 2        ;        3   (3.5가 아님!)
PRINT, 1 / 3        ;        0   (0.333이 아님!)
PRINT, 7.0 / 2.0    ;      3.50000   (올바른 결과)
```

## 관계 연산자

IDL은 기호가 아닌 키워드 스타일의 관계 연산자를 사용합니다:

```idl
a = 10
b = 20
PRINT, a EQ b    ;        0   같음
PRINT, a NE b    ;        1   같지 않음
PRINT, a LT b    ;        1   미만
PRINT, a GT b    ;        0   초과
PRINT, a LE b    ;        1   이하
PRINT, a GE b    ;        0   이상
```

### < 와 > 연산자 (최소/최대)

IDL에서 `<`와 `>`는 관계 연산자가 아니라 최소/최대 연산자입니다:

```idl
PRINT, 5 < 3        ;        3   (둘 중 작은 값)
PRINT, 5 > 3        ;        5   (둘 중 큰 값)

; 값을 범위로 제한 (클램핑)
x = 150
clamped = 0 > x < 100     ; [0, 100]으로 제한
PRINT, clamped             ;      100
```

## 논리 연산자

```idl
PRINT, 1 AND 1      ;        1
PRINT, 1 AND 0      ;        0
PRINT, 1 OR 0       ;        1
PRINT, NOT 0         ;       -1  (비트 보수)
PRINT, 1 XOR 0      ;        1

; 단락 평가 (IDL 8+, 스칼라만)
a = 5
IF a GT 0 && SQRT(a) GT 1 THEN PRINT, 'OK'
```

## 연산자 우선순위

| 우선순위 | 연산자 | 설명 |
|---------|--------|------|
| 1 (최고) | `()` | 괄호 |
| 2 | `^` | 거듭제곱 |
| 3 | `*`, `/`, `MOD` | 곱셈, 나눗셈, 나머지 |
| 4 | `+`, `-` | 덧셈, 뺄셈 |
| 5 | `<`, `>` | 최소, 최대 |
| 6 | `EQ`, `NE`, `LT`, `GT`, `LE`, `GE` | 관계 |
| 7 | `NOT` | 비트 NOT |
| 8 | `AND` | AND |
| 9 | `OR`, `XOR` | OR, XOR |

## 삼항 연산자 (IDL 8+)

```idl
x = 42
label = (x MOD 2 EQ 0) ? 'even' : 'odd'
PRINT, label         ; even
```

## 문자열 연산자

```idl
greeting = 'Hello' + ', ' + 'World!'
PRINT, greeting      ; Hello, World!

; 문자열 비교는 동일한 관계 연산자 사용
PRINT, 'ABC' EQ 'abc'   ;        0  (대소문자 구분)
```

## 요약

| 범주 | 연산자 | 참고 |
|------|--------|------|
| 산술 | `+`, `-`, `*`, `/`, `^`, `MOD` | 정수 나눗셈은 버림 |
| 관계 | `EQ`, `NE`, `LT`, `GT`, `LE`, `GE` | 0 또는 1 반환 |
| 최소/최대 | `<`, `>` | 관계가 아님 — 더 작은/큰 값 반환 |
| 논리 | `AND`, `OR`, `NOT`, `XOR` | 정수에 대해 비트 연산도 수행 |
| 단락 | `&&`, `\|\|` | 스칼라만 (IDL 8+) |
| 문자열 | `+` | 연결 |
| 삼항 | `? :` | IDL 8+ 조건식 |
