양자 네트워킹은 양자 계산을 개별 양자 프로세서를 넘어 양자 통신 채널로 연결된 분산 시스템으로 확장합니다. 가장 성숙한 응용은 **양자 키 분배**(QKD)로, 두 당사자가 물리 법칙에 의해 보장되는 보안으로 공유 비밀 키를 설정할 수 있게 합니다.

미래의 **양자 인터넷**은 양자 컴퓨터를 연결하여 분산 양자 계산, 블라인드 양자 컴퓨팅, 하이젠베르크 한계 정밀도의 양자 센서 네트워크를 가능하게 합니다.

> **비유:** 고전 인터넷은 광섬유 케이블을 통해 비트를 전송합니다. 양자 인터넷은 큐비트를 전송하고, 더 중요하게는 얽힘을 배포합니다. 얽힘은 두 노드 사이의 공유된, 깨뜨릴 수 없는 비밀과 같습니다.

## 1. 양자 통신 기초

### 1.1 복제 불가 정리

복제 불가 정리(Wootters & Zurek, 1982)는 임의의 양자 상태를 복사하는 양자 연산이 존재하지 않음을 말합니다:

$$\nexists U: U|\psi\rangle|0\rangle = |\psi\rangle|\psi\rangle \quad \forall |\psi\rangle$$

**네트워킹에 대한 결과**:
- 고전 증폭기(신호를 복사하고 재전송)는 양자 신호에 사용할 수 없습니다
- 양자 통신에 대한 도청은 불가피하게 양자 상태를 교란합니다
- 양자 중계기는 증폭 대신 얽힘 교환을 사용해야 합니다

### 1.2 양자 채널

양자 정보는 물리적 채널(전형적으로 광섬유 또는 자유 공간)을 통해 전송됩니다:

| 채널 | 매체 | 손실률 | 거리 한계 |
|---------|--------|-----------|---------------|
| 광섬유 | 유리 섬유 | 1550 nm에서 $\sim 0.2$ dB/km | $\sim 100$ km (직접) |
| 자유 공간 | 대기/진공 | 가변적 | $> 1000$ km (위성) |
| 마이크로파 | 극저온 케이블 | 높음 | $\sim 1$ m |

핵심 과제: 섬유에서의 광자 손실은 지수적입니다 — 100 km 후 약 $1\%$의 광자만 살아남습니다.

### 1.3 양자 vs 고전 통신

| 특성 | 고전 | 양자 |
|---------|-----------|---------|
| 신호 증폭 | 가능 (복사 및 증강) | 불가능 (복제 불가) |
| 도청 검출 | 불가능 | 물리 법칙에 의해 보장 |
| 오류 정정 | 표준 (반복) | 양자 오류 정정 |
| 대역폭 | Gbps-Tbps | kbps-Mbps (현재 QKD) |
| 거리 | 글로벌 (중계기 포함) | $\sim 100$ km (양자 중계기 없이) |

## 2. BB84 프로토콜

### 2.1 프로토콜 설명

BB84(Bennett & Brassard, 1984)는 최초이자 가장 널리 구현된 QKD 프로토콜입니다.

**프로토콜 단계**:

1. **준비**: 각 비트 $b_i \in \{0, 1\}$에 대해, Alice가 무작위로 기저 $\theta_i \in \{+, \times\}$를 선택하고 해당 양자 상태를 준비합니다.

2. **전송**: Alice가 각 큐비트를 양자 채널을 통해 Bob에게 전송합니다.

3. **측정**: Bob이 각 큐비트에 대해 무작위로 기저를 선택하고 측정합니다.

4. **선별(Sifting)**: 고전 채널을 통해 Alice와 Bob이 기저 선택을 공개합니다(비트는 공개하지 않음). 같은 기저를 사용한 비트만 유지합니다. 평균적으로 $50\%$에서 일치합니다.

5. **오류 추정**: 선별된 키의 무작위 부분 집합을 공개적으로 비교합니다. 오류율이 임계값(BB84의 경우 $\sim 11\%$)을 초과하면 중단합니다(도청자 검출).

6. **프라이버시 증폭**: 해싱을 사용하여 원시 키에서 더 짧지만 완벽하게 안전한 키를 증류합니다.

### 2.2 보안 증명 개요

**도청이 실패하는 이유**: Eve가 큐비트를 가로채면, 측정해야 하며(상태 붕괴) 재전송해야 합니다. 잘못된 기저에서 측정하면 Alice와 Bob이 검출할 수 있는 오류를 도입합니다.

**정보이론적 보안**: 무한한 계산 능력을 가져도 Eve는 검출되지 않고 키를 알 수 없습니다. 이는 계산적 보안(예: RSA)보다 근본적으로 강력합니다.

## 3. E91 프로토콜

### 3.1 얽힘 기반 QKD

E91(Ekert, 1991)은 단일 광자 대신 얽힌 광자 쌍을 사용합니다:

1. **소스**: 벨 쌍 $|\Phi^+\rangle = (|00\rangle + |11\rangle)/\sqrt{2}$을 생성하고 한 광자는 Alice에게, 다른 하나는 Bob에게 전송
2. **측정**: 각 당사자가 세 기저 중 하나에서 무작위로 측정
3. **선별**: 같은 기저에서 측정했을 때, 결과가 완벽하게 상관 → 키 비트
4. **보안 확인**: 다른 기저에서 측정했을 때, CHSH 부등식을 테스트. $S > 2$의 위반이 얽힘을 인증하고 도청을 배제

### 3.2 CHSH 부등식 테스트

CHSH 매개변수:

$$S = |E(a_1, b_1) - E(a_1, b_2) + E(a_2, b_1) + E(a_2, b_2)|$$

- **고전 한계**: $S \leq 2$
- **양자 최대**: $S = 2\sqrt{2} \approx 2.828$
- **치렐슨 한계**: 어떤 양자 상태도 $2\sqrt{2}$를 초과할 수 없음

### 3.3 장치 독립적 QKD

E91은 **장치 독립적 QKD**를 가능하게 합니다: Alice와 Bob이 자신의 장치를 신뢰하지 않더라도 보안이 유지됩니다. CHSH 위반이 관측되는 한, 측정 장치의 내부 작동과 관계없이 키는 안전합니다.

## 4. 양자 중계기

### 4.1 거리 문제

광섬유를 통한 직접 양자 통신은 지수적 광자 손실로 인해 $\sim 100$ km로 제한됩니다. 전송 확률 $\eta = 10^{-\alpha L/10}$ (여기서 $\alpha \approx 0.2$ dB/km). 100 km에서: $\eta \approx 0.01$. 1000 km에서: $\eta \approx 10^{-20}$.

### 4.2 양자 중계기 개념

양자 중계기는 총 거리를 구간으로 나누고 **얽힘 교환**을 사용하여 구간 간 얽힘을 확장합니다:

```
Alice --- R1 --- R2 --- R3 --- Bob
  |-------|-------|-------|------|
  entangle  swap    swap   entangle
  A-R1    R1-R2  R2-R3   R3-B
```

### 4.3 세 세대의 중계기

| 세대 | 메커니즘 | 오류 처리 | 전송률 스케일링 |
|-----------|-----------|---------------|-------------|
| **1세대** | 얽힘 교환 + 증류 | 예고 얽힘 | $L$에 대해 다항식 |
| **2세대** | 링크에 양자 오류 정정 | QEC 코드 | 다항식, 더 빠름 |
| **3세대** | 완전 양자 오류 정정 | 전체 인코딩된 큐비트 | 상수 (고전과 같음) |

## 5. 얽힘 교환

### 5.1 프로토콜

얽힘 교환은 상호작용하지 않은 두 당사자 사이에 얽힘을 생성합니다:

1. **시작**: Alice가 Charlie와 벨 쌍 공유: $(|\Phi^+\rangle)_{AC}$. Charlie가 Bob과 벨 쌍 공유: $(|\Phi^+\rangle)_{CB}$.
2. **벨 측정**: Charlie가 자신의 두 큐비트(각 쌍에서 하나씩)에 벨 측정 수행.
3. **결과**: Alice와 Bob이 이제 벨 쌍을 공유하며, Charlie의 측정 결과에 따라 조건화됩니다.

### 5.2 수학적 설명

초기 상태 (4 큐비트: $A, C_1, C_2, B$):

$$|\Psi\rangle = |\Phi^+\rangle_{AC_1} \otimes |\Phi^+\rangle_{C_2B}$$

Charlie가 $C_1 C_2$를 벨 기저에서 측정합니다. 결과는 네 가지 중 하나이며, 각각 $A, B$를 벨 상태로 사영합니다.

### 5.3 중첩 교환

$n$개의 중간 노드에 대해, 얽힘 교환은 계층적으로 적용될 수 있습니다. 이는 $n - 1$번의 교환 연산이 필요하며, 성공 확률은 $(p_{\text{swap}})^{n-1}$입니다.

## 6. 얽힘 증류

### 6.1 문제

실제 양자 채널은 **잡음이 있는 얽힘**을 생성합니다: 완벽한 벨 쌍 대신, 충실도 $F = \langle\Phi^+|\rho_{AB}|\Phi^+\rangle < 1$인 혼합 상태 $\rho_{AB}$를 얻습니다.

### 6.2 Bennett 등의 증류 프로토콜

충실도 $F > 1/2$인 잡음이 있는 벨 쌍 $n$개가 주어지면, 충실도 $F' > F$인 $m < n$개의 쌍을 생성합니다:

1. Alice와 Bob이 각각 두 쌍 사이에 무작위 양측 CNOT를 적용
2. 타겟 쌍을 측정하고 결과를 고전적으로 비교
3. 결과가 일치하면 컨트롤 쌍을 유지(더 높은 충실도); 아니면 폐기

**충실도 개선**: $F' = \frac{F^2 + (1-F)^2/9}{F^2 + 2F(1-F)/3 + 5(1-F)^2/9}$

## 7. 양자 인터넷 아키텍처

| 단계 | 능력 | 현재 상태 |
|------|------|----------|
| 1 | 신뢰 노드 QKD | 배치됨 |
| 2 | 직접 큐비트 전송 | 근기 |
| 3 | 얽힘 배포 | 중기 |
| 4 | 양자 메모리 네트워크 | 연구 단계 |
| 5 | 완전 양자 인터넷 | 장기 목표 |

완전한 양자 인터넷은 분산 양자 계산, 장거리 얽힘 분배, 양자 클라우드 컴퓨팅을 가능하게 할 것입니다.

## 8. QKD를 넘어선 응용

양자 네트워킹의 응용은 QKD를 훨씬 넘어 확장됩니다:

1. **분산 양자 컴퓨팅**: 여러 소규모 양자 프로세서를 연결하여 단일 대규모 양자 컴퓨터처럼 동작하게 합니다
2. **블라인드 양자 컴퓨팅**: 서버에 계산 내용을 공개하지 않고 원격 양자 컴퓨터에서 계산을 수행합니다
3. **양자 센서 네트워크**: 분산된 양자 센서를 얽힘으로 연결하여 하이젠베르크 한계 정밀도를 달성합니다
4. **양자 클록 동기화**: 얽힘 기반 프로토콜을 통해 고전적 방법보다 정밀한 클록 동기화를 달성합니다

## 9. Python 구현

```python
import numpy as np

def bb84_protocol(n_bits, eve_present=False, seed=42):
    """BB84 양자 키 분배 프로토콜을 시뮬레이션합니다."""
    rng = np.random.default_rng(seed)

    alice_bits = rng.integers(0, 2, n_bits)
    alice_bases = rng.integers(0, 2, n_bits)
    bob_bases = rng.integers(0, 2, n_bits)
    bob_bits = np.zeros(n_bits, dtype=int)

    for i in range(n_bits):
        if eve_present:
            eve_base = rng.integers(0, 2)
            if eve_base != alice_bases[i]:
                if bob_bases[i] == alice_bases[i]:
                    bob_bits[i] = rng.integers(0, 2)
                else:
                    bob_bits[i] = rng.integers(0, 2)
            else:
                bob_bits[i] = alice_bits[i] if bob_bases[i] == alice_bases[i] else rng.integers(0, 2)
        else:
            bob_bits[i] = alice_bits[i] if bob_bases[i] == alice_bases[i] else rng.integers(0, 2)

    matching = alice_bases == bob_bases
    sifted_a = alice_bits[matching]
    sifted_b = bob_bits[matching]

    n_check = len(sifted_a) // 2
    check_idx = rng.choice(len(sifted_a), n_check, replace=False)
    qber = np.mean(sifted_a[check_idx] != sifted_b[check_idx]) if n_check > 0 else 0

    return {'qber': qber, 'n_key': len(sifted_a) - n_check, 'eve_detected': qber > 0.11}

print("=" * 60)
print("BB84 양자 키 분배")
print("=" * 60)

result = bb84_protocol(10000, eve_present=False)
print(f"\n도청자 없음: QBER = {result['qber']:.4f}, 키 길이 = {result['n_key']}")

result = bb84_protocol(10000, eve_present=True)
print(f"도청자 있음: QBER = {result['qber']:.4f}, 검출 = {result['eve_detected']}")
```
