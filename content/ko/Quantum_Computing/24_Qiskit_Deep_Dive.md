## 1. Qiskit 아키텍처 개요

### 1.1 Qiskit 구성 요소 (2025)

| 구성 요소 | 용도 |
|-----------|---------|
| **qiskit** (Terra) | 핵심: 회로, 트랜스파일레이션, 시각화 |
| **qiskit-aer** | 잡음 모델이 있는 고성능 시뮬레이터 |
| **qiskit-ibm-runtime** | IBM Quantum 하드웨어 인터페이스 |
| **qiskit-algorithms** | 양자 알고리즘 (VQE, QAOA, Grover 등) |
| **qiskit-nature** | 화학 및 물리학 응용 |
| **qiskit-machine-learning** | 양자 ML 모델 |

### 1.2 Qiskit 패턴

양자 계산을 위한 권장 워크플로우:

```
1. Map:        Problem → Quantum circuit
2. Transpile:  Abstract circuit → Hardware-compatible circuit
3. Execute:    Run on simulator/hardware, collect results
4. Post-process: Analyze results, error mitigate, extract answers
```

### 1.3 회로 표현

Qiskit은 회로를 유향 비순환 그래프(DAG)로 표현합니다:
- **노드**: 게이트, 측정, 배리어
- **간선**: 큐비트/고전 비트 와이어
- **위상적 순서**: 병렬로 실행 가능한 게이트가 같은 DAG 레벨에 놓임

이 DAG 표현은 트랜스파일레이션 동안 효율적인 최적화를 가능하게 합니다.

## 2. 회로 구성

### 2.1 기본 게이트

| 게이트 | Qiskit 이름 | 행렬 | 큐비트 수 |
|------|-------------|--------|--------|
| Pauli X | `x(q)` | $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ | 1 |
| Hadamard | `h(q)` | $\frac{1}{\sqrt{2}}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$ | 1 |
| CNOT | `cx(c,t)` | Controlled-X | 2 |
| Phase | `p(theta,q)` | $\begin{pmatrix}1&0\\0&e^{i\theta}\end{pmatrix}$ | 1 |
| Rotation | `ry(theta,q)` | $R_y(\theta)$ | 1 |
| Toffoli | `ccx(c1,c2,t)` | Controlled-controlled-X | 3 |

### 2.2 회로 깊이와 너비

- **너비(Width)**: 큐비트 수
- **깊이(Depth)**: 회로를 통한 가장 긴 경로 (순차 게이트 레이어 수)
- **크기(Size)**: 총 게이트 수
- **CNOT 수**: 2-큐비트 게이트 수 (주요 오류 원인)

최적화 목표: 회로의 유니터리를 보존하면서 CNOT 수와 깊이를 최소화합니다.

### 2.3 매개변수화 회로

매개변수화 회로는 나중에 바인딩되는 기호적 매개변수를 사용합니다. 이는 매개변수를 고전적으로 최적화하는 변분 알고리즘에 필수적입니다.

## 3. 트랜스파일레이션 파이프라인

### 3.1 트랜스파일이 필요한 이유

추상 회로는 임의의 큐비트 쌍에 대한 이상적 게이트를 사용합니다. 실제 하드웨어에는 제약이 있습니다:
- **기저 게이트**: 특정 게이트만 네이티브로 지원 (예: IBM 장치의 $\{CX, I, R_z, \sqrt{X}, X\}$)
- **연결성**: 모든 큐비트 쌍이 직접 상호작용할 수 있는 것은 아님 (예: heavy-hex 토폴로지)
- **게이트 오류**: 큐비트와 연결마다 다른 오류율

### 3.2 트랜스파일레이션 단계

| 단계 | 목적 | 주요 연산 |
|-------|---------|---------------|
| **풀기(Unrolling)** | 사용자 정의 게이트를 기저 게이트로 분해 | $\text{Toffoli} \to 6 \text{ CNOT} + \text{단일}$ |
| **라우팅(Routing)** | 논리 큐비트를 물리 큐비트에 매핑 | 비인접 상호작용에 SWAP 게이트 삽입 |
| **최적화(Optimization)** | 게이트 수와 깊이 감소 | 게이트 상쇄, 교환, 재합성 |
| **스케줄링(Scheduling)** | 실행 타이밍 결정 | ALAP/ASAP 스케줄링, 동적 디커플링 |

### 3.3 최적화 수준

| 수준 | 패스 | CNOT 감소 | 시간 |
|------|--------|----------------|------|
| 0 | 풀기 + 라우팅만 | 없음 | 빠름 |
| 1 | 가벼운 최적화 | $\sim 10\%$ | 보통 |
| 2 | 중간 최적화 | $\sim 20\%$ | 보통 |
| 3 | 무거운 최적화 | $\sim 30\%$ | 느림 |

### 3.4 큐비트 라우팅

비인접 큐비트 간 CNOT가 필요한 경우, SWAP 게이트를 삽입해야 합니다. 각 SWAP는 3개의 CNOT가 필요하므로, 라우팅이 회로 비용을 상당히 증가시킬 수 있습니다.

**라우팅 알고리즘**: Trivial, Stochastic, SABRE(Qiskit 기본값), Optimal(SAT 해법기, 지수 시간).

## 4. 잡음 모델

### 4.1 일반적인 잡음 유형

현실적 잡음 모델에는 다음이 포함됩니다:
- **탈분극 오류(Depolarizing error)**: 확률 $p$로 무작위 파울리 오류 적용
- **판독 오류(Readout error)**: $|0\rangle$을 $|1\rangle$로 잘못 읽거나 그 반대
- **열적 이완**: $T_1$(에너지 이완)과 $T_2$(결맞음깨짐) 과정
- **누화 오류(Crosstalk error)**: 이웃 큐비트 연산에 의한 원하지 않는 상호작용

### 4.2 잡음 모델 구성

Qiskit Aer에서 잡음 모델은 실제 장치의 특성을 기반으로 구성하거나 사용자 정의할 수 있습니다. 채널별 오류율, 판독 오류 행렬, 이완 시간을 개별적으로 설정할 수 있습니다.

## 5. Aer 시뮬레이터

### 5.1 시뮬레이션 방법

| 방법 | 최대 큐비트 | 잡음 지원 | 용도 |
|------|-----------|---------|------|
| 상태 벡터(Statevector) | $\sim 30$ | 아니오 | 정확한 시뮬레이션 |
| 밀도 행렬(Density matrix) | $\sim 15$ | 예 | 잡음 시뮬레이션 |
| 안정자(Stabilizer) | $> 1000$ | 제한적 | 클리포드 회로 |
| MPS (행렬 곱 상태) | $\sim 50$ | 예 | 저얽힘 회로 |

### 5.2 샷과 통계

양자 측정은 확률적이므로, 통계적으로 유의미한 결과를 얻으려면 동일한 회로를 여러 번(샷) 실행해야 합니다. 전형적으로 1024-8192 샷을 사용합니다.

## 6. 실제 장치 실행

IBM Quantum을 통해 실제 양자 하드웨어에 접근할 수 있습니다. 주요 고려사항:
- **큐비트 선택**: 오류율이 낮은 큐비트 선호
- **동적 회로**: 중간 측정과 조건부 연산 지원
- **Primitives API**: Sampler(확률 분포)와 Estimator(기댓값) 프리미티브 제공
- **세션(Sessions)**: 반복 실행을 위한 하드웨어 접근 예약

## 7. 오류 완화

양자 오류 수정이 실용적이 되기 전까지, 오류 완화 기법이 NISQ 결과를 개선합니다:

### 7.1 측정 오류 완화

판독 오류를 교정 행렬을 사용하여 보정합니다. 각 계산 기저 상태를 준비하고 측정하여 오류 행렬을 구성하고 역을 적용합니다.

### 7.2 영잡음 외삽법(ZNE)

잡음을 의도적으로 증폭(예: 게이트 폴딩)한 후, 여러 잡음 수준에서의 결과를 영잡음 한계로 외삽합니다.

### 7.3 확률적 오류 상쇄(PEC)

잡음 채널의 역을 확률적으로 적용하여 잡음을 상쇄합니다. 정확하지만 측정 횟수가 지수적으로 증가합니다.

## 8. 매개변수화 회로와 VQE

### 8.1 Estimator 프리미티브

VQE와 같은 변분 알고리즘은 관측량의 기댓값을 반복적으로 평가해야 합니다. Estimator 프리미티브는 이를 효율적으로 처리합니다.

### 8.2 최적화기

변분 매개변수를 최적화하기 위한 고전 최적화기:
- **COBYLA**: 기울기 없는 방법, 적은 매개변수에 적합
- **SPSA**: 확률적 섭동 기반, 잡음이 있는 함수 평가에 강건
- **L-BFGS-B**: 기울기 기반, 잡음이 없는 시뮬레이터에 적합

### 8.3 앤사츠 설계

효과적인 변분 회로 설계 원칙:
- **표현력**: 해를 포함할 수 있을 만큼 충분히 표현력이 있어야 함
- **훈련 가능성**: 황무지 고원(barren plateau)을 피해야 함
- **하드웨어 호환성**: 네이티브 게이트와 연결성에 맞추어 설계

## 9. Python 구현

```python
import numpy as np

I = np.eye(2, dtype=complex)
X = np.array([[0, 1], [1, 0]], dtype=complex)
H_gate = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)

def kron_list(ops):
    result = ops[0]
    for op in ops[1:]:
        result = np.kron(result, op)
    return result

# 벨 상태 회로 시뮬레이션
print("=" * 60)
print("양자 회로 구성 및 시뮬레이션")
print("=" * 60)

n_qubits = 2
N = 2 ** n_qubits
state = np.zeros(N, dtype=complex)
state[0] = 1.0

# H on qubit 0
state = kron_list([H_gate, I]) @ state

# CNOT(0,1)
cnot = np.eye(N, dtype=complex)
cnot[2, 2] = 0; cnot[3, 3] = 0; cnot[2, 3] = 1; cnot[3, 2] = 1
state = cnot @ state

probs = np.abs(state) ** 2
print(f"\n벨 상태 확률:")
for i in range(N):
    if probs[i] > 0.01:
        print(f"  |{format(i, f'0{n_qubits}b')}⟩: {probs[i]:.4f}")
```
