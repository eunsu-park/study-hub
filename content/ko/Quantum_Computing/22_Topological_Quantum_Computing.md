위상 양자 컴퓨팅은 양자 컴퓨터를 구축하는 근본적으로 다른 접근법입니다. 잡음으로부터 주의 깊게 격리해야 하는 취약한 양자 상태에 정보를 인코딩하는 대신, 위상 양자 컴퓨팅은 시스템의 전역적, 위상적 성질 — 국소적 섭동에 본질적으로 저항하는 성질 — 에 정보를 인코딩합니다. 위상적 큐비트는 줄의 매듭과 같습니다: 줄을 흔들거나, 늘이거나, 국소적으로 변형해도 매듭은 변하지 않습니다. 줄을 자르는 것(전역적 위상 변화)만이 정보를 파괴할 수 있습니다.

수학적 프레임워크는 **에이니온(anyon)** — 2차원 시스템에만 존재하는 이국적인 준입자 — 에 기반합니다. 보손(교환 시 변화 없음)이나 페르미온(교환 시 부호 반전)과 달리, 에이니온은 서로 주위를 꼬일 때 임의의 위상을 획득하거나 비자명한 유니터리 변환을 겪을 수 있습니다. 이러한 꼬임 연산은 본질적으로 위상적입니다: 정확한 경로가 아닌 입자 세계선의 위상에만 의존합니다.

> **비유:** 줄의 매듭으로 저장된 정보를 상상하세요. 줄을 흔들거나, 늘이거나, 국소적으로 변형해도 매듭 유형은 변하지 않습니다. 줄을 자르는 것(위상적 조작)만이 인코딩된 정보를 변경할 수 있습니다.

## 1. 동기: 위상적 보호

### 1.1 결어긋남 문제

기존 큐비트는 취약합니다: 국소적 섭동(전자기 요동, 열적 포논, 우주선)이 양자 상태를 반전, 위상 깨짐, 또는 기타 방식으로 손상시킬 수 있습니다. 게이트당 오류율은 전형적으로 $10^{-3}$에서 $10^{-4}$이며, 결맞음 시간은 마이크로초에서 밀리초입니다.

### 1.2 위상적 해결책

위상 양자 컴퓨팅은 연속적인 국소 변형 하에서 불변인 성질에 정보를 인코딩합니다:

- **국소적 섭동**은 위상적 성질을 변경할 수 없습니다 (커피잔을 자르지 않고 도넛으로 바꾸는 것과 같습니다)
- 정보는 **비국소적으로** 전체 시스템에 걸쳐 저장됩니다
- 정보를 손상시키려면 전체 시스템에 걸친 대규모 오류가 필요합니다

위상적 큐비트의 오류율은 $e^{-cL}$로 스케일되며, 여기서 $L$은 시스템 크기로 지수적 보호를 제공합니다.

### 1.3 수학적 기반

| 수학적 개념 | TQC에서의 역할 |
|---------------------|-------------|
| 위상수학 | 매듭과 꼬임의 분류 |
| 범주론 | 에이니온의 대수적 구조 |
| 표현론 | 꼬임군 표현 |
| 대수적 위상수학 | 위상적 불변량, 호몰로지 |
| 공형장론 | 2차원 물리학과의 연결 |

## 2. 에이니온과 교환 통계

### 2.1 2차원에서의 입자 통계

3차원에서 두 동일 입자를 두 번 교환하면 시스템이 원래 상태로 돌아옵니다. 이는 두 가지 가능성만 허용합니다:
- **보손(Boson)**: 교환 시 인자 $+1$
- **페르미온(Fermion)**: 교환 시 인자 $-1$

2차원에서는 입자 교환 경로의 위상이 더 풍부합니다(배치 공간의 기본군이 대칭군이 아닌 꼬임군입니다). 이는 다음을 허용합니다:
- **에이니온(Anyon)**: 교환 시 임의의 $\theta$에 대해 인자 $e^{i\theta}$ (가환 에이니온)
- **비가환 에이니온(Non-Abelian anyon)**: 교환 시 유니터리 행렬 적용 (단순한 위상이 아님)

### 2.2 가환 에이니온

가환 에이니온의 경우, 입자 $i$와 $j$를 교환하면:

$$|\psi\rangle \to e^{i\theta_{ij}}|\psi\rangle$$

위상 $\theta_{ij}$는 에이니온 유형에 의존하지만 상태에는 의존하지 않습니다. 오류 정정(예: 토릭 코드)에는 유용하지만 보편적 양자 계산에는 충분하지 않습니다.

### 2.3 꼬임군(Braid Group)

$n$개 가닥의 꼬임군 $B_n$은 기본 꼬임 $\sigma_1, \sigma_2, \ldots, \sigma_{n-1}$으로 생성되며 다음을 만족합니다:

- **양-박스터 방정식**: $\sigma_i \sigma_{i+1} \sigma_i = \sigma_{i+1} \sigma_i \sigma_{i+1}$
- **먼 가환성**: $|i-j| \geq 2$일 때 $\sigma_i \sigma_j = \sigma_j \sigma_i$

대칭군과 달리, $\sigma_i^2 \neq 1$ — 두 번 꼬는 것은 전혀 꼬지 않는 것과 같지 않습니다.

### 2.4 꼬임 다이어그램

기본 꼬임 생성자 $\sigma_i$는 가닥 $i$와 $i+1$을 교환하며, 가닥 $i$가 가닥 $i+1$ *위로* 지나갑니다. 시간은 아래로 흐릅니다:

```
  σ₁ (strand 1 over strand 2):      σ₁⁻¹ (strand 2 over strand 1):

  1    2    3                         1    2    3
  |    |    |                         |    |    |
  |    |    |                         |    |    |
   \  /     |                          \  /     |
    \/      |                           \/      |
    /\      |      strand 1 passes      /\      |
   /  \     |      OVER strand 2       /  \     |
  |    |    |                         |    |    |
  2    1    3                         2    1    3

  Identity (σ₁ σ₁⁻¹):               Yang-Baxter (σ₁ σ₂ σ₁ = σ₂ σ₁ σ₂):

  1    2    3                         Strands can slide past each other
  |    |    |                         as long as the crossing pattern
   \  /     |                         (over/under) is preserved. This
    \/      |                         topological invariance is what
    /\      |                         makes braiding robust against
   /  \     |                         local perturbations.
    \/      |
    /\      |
   /  \     |
  |    |    |
  1    2    3  (back to start)
```

### 2.5 위상적 전하

에이니온은 **위상적 전하(topological charge)**(또는 에이니온 유형)를 가집니다. 두 에이니온을 합치면 전하가 융합 규칙에 따라 **융합(fuse)**합니다:

$$a \times b = \sum_c N_{ab}^c \, c$$

여기서 $N_{ab}^c$는 $a$와 $b$가 $c$를 주는 방법의 수입니다. 어떤 $c$에 대해 $N_{ab}^c > 1$이면 에이니온은 비가환입니다.

## 3. 꼬임과 양자 게이트

### 3.1 꼬임을 통한 계산

위상 양자 컴퓨팅의 핵심 아이디어:

1. **초기화**: 진공에서 에이니온 쌍을 생성 (각 쌍은 자명한 총 전하를 가짐)
2. **계산**: 에이니온을 서로 주위로 이동 (꼬임). 각 꼬임 패턴은 특정 유니터리 연산을 구현
3. **판독**: 에이니온 쌍을 융합하고 총 전하를 측정 (계산 결과를 인코딩)

### 3.2 꼬임군 표현

$n$개의 유형 $a$ 에이니온을 가진 양자 시스템은 축퇴된 바닥 상태 공간을 가집니다. 꼬임군은 유니터리 표현을 통해 이 공간에 작용합니다:

$$\sigma_i \to R_i \in U(\text{바닥 공간의 차원})$$

### 3.3 예제: 피보나치 에이니온

피보나치 에이니온은 두 가지 위상적 전하를 가집니다: $1$ (진공)과 $\tau$ (비자명). 융합 규칙:

$$\tau \times \tau = 1 + \tau$$

$n$개 피보나치 에이니온의 융합 공간 차원은 $F_{n-1}$ (피보나치 수)입니다. 세 개의 에이니온은 2차원 융합 공간을 가져 하나의 큐비트를 인코딩합니다.

피보나치 에이니온의 꼬임 행렬:

$$\sigma_1 = \begin{pmatrix} e^{-4\pi i/5} & 0 \\ 0 & e^{3\pi i/5} \end{pmatrix}, \quad \sigma_2 = \begin{pmatrix} \phi^{-1}e^{-4\pi i/5} & \phi^{-1/2}e^{3\pi i/5} \\ \phi^{-1/2}e^{3\pi i/5} & -\phi^{-1} \end{pmatrix}$$

여기서 $\phi = (1 + \sqrt{5})/2$는 황금비입니다.

### 3.4 에이니온 융합을 통한 측정

위상 양자 컴퓨팅에서 측정은 에이니온을 **융합(fusing)** — 두 에이니온을 합치고 결과적인 위상적 전하를 관측 — 하여 수행됩니다. 융합 규칙 $\tau \times \tau = 1 + \tau$를 가진 피보나치 에이니온의 경우, 두 $\tau$ 에이니온을 융합하면 진공 $1$ 또는 또 다른 $\tau$ 에이니온을 얻을 수 있습니다. 결과는 확률적이며 이전 꼬임 연산에 의해 형성된 시스템의 양자 상태에 의해 결정됩니다.

융합 결과는 **간섭계 측정(interferometric measurement)**으로 감지됩니다: 탐침 에이니온을 융합된 쌍 주위로 보내고, 획득한 위상으로 총 전하를 밝힙니다. 쌍이 $1$(진공)으로 융합되면 탐침은 위상을 획득하지 않고, $\tau$로 융합되면 비자명한 위상을 획득합니다.

세 피보나치 에이니온($\tau_1, \tau_2, \tau_3$)에 인코딩된 큐비트의 경우, 측정은 $\tau_1$과 $\tau_2$를 융합하고 결과가 $1$(논리적 $|0\rangle$)인지 $\tau$(논리적 $|1\rangle$)인지 관측하는 것에 해당합니다.

### 3.5 보편성

**피보나치 에이니온은 양자 계산에 대해 보편적입니다**: 임의의 단일 큐비트 유니터리를 유한한 꼬임 시퀀스로 임의 정밀도로 근사할 수 있습니다. 이는 Freedman, Larsen, Wang(2002)에 의해 증명되었습니다.

근사 오차는 꼬임 길이에 따라 지수적으로 감소합니다: $\epsilon \sim e^{-cL}$, 여기서 $L$은 기본 꼬임의 수입니다.

## 4. 비가환 에이니온

### 4.1 이징 에이니온

이징 에이니온은 더 단순한(그러나 덜 강력한) 비가환 시스템입니다. 세 가지 에이니온 유형: $1$(진공), $\sigma$(이징 에이니온), $\psi$(페르미온).

융합 규칙:
$$\sigma \times \sigma = 1 + \psi, \quad \sigma \times \psi = \sigma, \quad \psi \times \psi = 1$$

**한계**: 이징 에이니온은 꼬임으로 클리포드 게이트를 구현할 수 있지만 T 게이트는 구현할 수 없습니다. 따라서 꼬임만으로는 보편적이지 않으며 보편성을 위해 "매직 상태 증류"가 필요합니다.

### 4.2 $SU(2)_k$ 에이니온

| $k$ | 에이니온 모델 | 보편적? | 물리적 시스템 |
|-----|-------------|-----------|----------------|
| 1 | 세미온 | 아니오 (가환) | $\nu = 1/2$ Laughlin |
| 2 | 이징 | 아니오 (클리포드만) | $\nu = 5/2$ FQHE, 마요라나 |
| 3 | 피보나치 | 예 | $\nu = 12/5$ FQHE (이론적) |
| 4 | $SO(3)_2$ | 아니오 | 특정 스핀 액체 |

### 4.3 물리적 구현

| 시스템 | 에이니온 유형 | 상태 |
|--------|-----------|--------|
| 분수 양자 홀 ($\nu = 5/2$) | 이징 (마요라나) | 실험적 증거 |
| 위상 초전도체 | 마요라나 영모드 | 활발한 연구 |
| 키타에프 스핀 액체 | 비가환 에이니온 | 이론적 |
| 광학 시스템 | 시뮬레이션된 에이니온 | 개념 증명 |

## 5. 마요라나 페르미온

### 5.1 마요라나 페르미온이란?

마요라나 페르미온은 자기 자신이 반입자입니다: $\gamma = \gamma^\dagger$. 응집물질에서 **마요라나 영모드(Majorana zero modes, MZM)**는 위상 초전도 와이어의 끝에 나타납니다:

$$\gamma_i = \gamma_i^\dagger, \quad \{\gamma_i, \gamma_j\} = 2\delta_{ij}$$

### 5.2 마요라나 큐비트

두 마요라나 영모드 $\gamma_1, \gamma_2$는 하나의 페르미온 모드를 형성합니다:

$$c = \frac{\gamma_1 + i\gamma_2}{2}, \quad c^\dagger = \frac{\gamma_1 - i\gamma_2}{2}$$

이 모드의 점유($n = c^\dagger c = 0$ 또는 $1$)가 큐비트입니다. $\gamma_1$과 $\gamma_2$가 공간적으로 분리되어 있으므로, 국소적 섭동은 점유를 변경할 수 없습니다.

### 5.3 마요라나 영모드 꼬임

두 MZM을 교환하면 다음을 구현합니다:

$$\gamma_i \to \gamma_j, \quad \gamma_j \to -\gamma_i$$

이는 유니터리 $U_{ij} = \frac{1}{\sqrt{2}}(1 + \gamma_i\gamma_j)$에 해당합니다.

### 5.4 마이크로소프트의 접근법

마이크로소프트는 마요라나 영모드를 사용한 위상 양자 컴퓨팅에 대규모 투자를 했습니다:

1. **플랫폼**: 반도체-초전도체 나노와이어 (InAs/Al, InSb/Al)
2. **목표**: 와이어 끝점에서 마요라나 영모드 생성 및 조작
3. **상태**: 위상 초전도성의 증거 주장(2023), 위상 큐비트 시연을 향해 진행 중
4. **과제**: 참 MZM과 자명한 영에너지 상태의 구별

## 6. 표면 코드

### 6.1 정의

표면 코드는 2차원 큐비트 격자에 정의된 위상 오류 정정 부호입니다. 근기 구현에 가장 실용적인 위상 코드입니다.

$L \times L$ 격자의 경우:
- 데이터 큐비트: $2L^2 - 2L + 1$
- 논리 큐비트: 1
- 코드 거리: $L$ ($\lfloor(L-1)/2\rfloor$개의 오류 정정 가능)

### 6.2 안정자

$$A_s = \prod_{i \in \text{star}(s)} X_i, \quad B_p = \prod_{i \in \text{plaquette}(p)} Z_i$$

모든 안정자는 가환합니다: 모든 $s, p$에 대해 $[A_s, B_p] = 0$.

코드 공간은 모든 안정자의 $+1$ 고유 공간입니다: $A_s|\psi\rangle = |\psi\rangle$, $B_p|\psi\rangle = |\psi\rangle$.

### 6.3 오류 검출

큐비트 $i$에 대한 $X$ 오류는 인접한 $Z$ 안정자와 반가환하여, 고유값을 $-1$로 뒤집습니다. 모든 안정자를 측정하여 오류 위치를 (동치까지) 밝혀주는 **신드롬(syndrome)**을 얻습니다.

### 6.4 논리 연산자

- **논리 $\bar{X}$**: 격자를 수평으로 가로지르는 $X$ 연산자의 체인
- **논리 $\bar{Z}$**: 격자를 수직으로 가로지르는 $Z$ 연산자의 체인

이 연산자들은 전체 격자($L$개 큐비트)에 걸치므로, $L$개 미만의 단일 큐비트 오류로는 발생할 수 없습니다.

### 6.5 오류 임계값

- **현상학적 임계값**: $\sim 3\%$ (완벽한 신드롬 측정 시)
- **회로 수준 임계값**: $\sim 1\%$ (현실적인 잡음이 있는 신드롬 추출 시)
- **현재 하드웨어**: $10^{-3}$ 오류율에 근접, 임계값 도달 가능 범위

## 7. 실용적 위상 코드

### 7.1 표면 코드 연산

**논리 게이트**:
- $\bar{X}$, $\bar{Z}$: 가로방향(Transversal) — 격자 전체에 파울리 문자열 적용
- $\bar{H}$: 격자 수술(lattice surgery) 또는 코드 변형 필요
- $\bar{S}$: 매직 상태 주입(magic state injection) 필요
- $\bar{T}$: 매직 상태 증류(magic state distillation) 필요 (가장 비용이 큼)

### 7.2 격자 수술(Lattice Surgery)

꼬임 대신, 표면 코드는 **격자 수술**을 통해 논리 게이트를 구현합니다: 경계를 따라 결합 안정자를 측정하여 코드 패치를 병합하고 분리합니다.

- **병합(Merge)**: 경계를 따라 XX 또는 ZZ 안정자를 측정하여 두 코드 패치를 결합 → 논리 CNOT 또는 CZ 구현
- **분리(Split)**: 절단선을 따라 단일 큐비트 연산자를 측정하여 병합된 패치를 분리

### 7.3 매직 상태 증류

T 게이트($T = \text{diag}(1, e^{i\pi/4})$)는 표면 코드에서 가로방향으로 구현할 수 없습니다. 대신:

1. 잡음이 있는 T 상태를 준비: $|T\rangle = T|+\rangle = (|0\rangle + e^{i\pi/4}|1\rangle)/\sqrt{2}$
2. 많은 잡음이 있는 T 상태를 소비하여 하나의 고충실도 T 상태를 생산하는 증류 프로토콜 사용
3. 증류된 T 상태를 계산에 주입

### 7.4 자원 오버헤드

| 구성 요소 | 오버헤드 |
|-----------|----------|
| 논리 큐비트당 물리 큐비트 | $2L^2$ (여기서 $L \sim 10$-$30$) |
| 신드롬 추출 사이클 | 오류 정정 라운드당 $L$ |
| T 게이트 (증류) | $d$회 증류에 $\sim 15^d$개 T 상태 |
| 유용한 계산에 필요한 총량 | $10^6$-$10^8$ 물리 큐비트 |

## 8. 기존 접근법과의 비교

### 8.1 위상적 vs. 게이트 기반

| 측면 | 위상 QC | 게이트 기반 QC |
|------|---------|------------|
| 오류 보호 | 내장 (위상적) | 능동적 (오류 정정) |
| 게이트 구현 | 꼬임 / 격자 수술 | 마이크로파/레이저 펄스 |
| 보편성 | 에이니온 유형에 따라 다름 | 구성상 보편적 |
| 현재 상태 | 실험 전 단계 | 1000+ 큐비트 프로세서 |
| 확장성 | 잠재적으로 우수 | 도전적 (오류율) |
| 하드웨어 | 특수 재료 | 초전도, 이온 등 |

### 8.2 하이브리드 접근법

실제로 표면 코드(위상 코드)는 기존 하드웨어(초전도 큐비트)에서 구현됩니다. 이는 위상적 오류 정정의 수학적 구조와 기존 양자 하드웨어의 공학적 성숙도를 결합하는 하이브리드 접근법입니다.

## 9. Python 구현

```python
import numpy as np

def fibonacci_braid_matrices():
    """피보나치 에이니온의 꼬임 행렬을 계산합니다."""
    phi = (1 + np.sqrt(5)) / 2
    theta_1 = np.exp(-4j * np.pi / 5)
    theta_tau = np.exp(3j * np.pi / 5)

    sigma1 = np.array([[theta_1, 0], [0, theta_tau]], dtype=complex)
    sigma2 = np.array([
        [theta_1 / phi, theta_tau / np.sqrt(phi)],
        [theta_tau / np.sqrt(phi), -theta_1 / phi]
    ], dtype=complex)
    return sigma1, sigma2

sigma1, sigma2 = fibonacci_braid_matrices()
lhs = sigma1 @ sigma2 @ sigma1
rhs = sigma2 @ sigma1 @ sigma2
print("=" * 60)
print("피보나치 에이니온 꼬임")
print("=" * 60)
print(f"\n양-박스터 관계 만족: {np.allclose(lhs, rhs)}")
```
