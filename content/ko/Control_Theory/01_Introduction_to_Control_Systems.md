# 레슨 1: 제어 시스템 입문

## 학습 목표

- 제어 시스템(control system)이 무엇이며 왜 필요한지 정의한다
- 개루프(open-loop) 제어와 폐루프(closed-loop, 귀환) 제어를 구분한다
- 귀환 제어 시스템의 구성 요소를 식별한다
- 성능과 강건성 향상에서 귀환의 역할을 이해한다
- 공학 및 과학 전반의 제어 이론 응용을 살펴본다
- 후속 레슨이 더 큰 분야에서 어디에 위치하는지 한 페이지 정신적 지도를 만든다

## 0. 강의 소개 — 이 강의가 당신에게 사 줄 것

이 레슨을 동기 부여하는 질문으로 시작하자: **왜 귀환이 작동하는가?**

답은 직관적으로 이미 알고 있다. 커피 머그를 잡으려고 손을 뻗을 때, 눈은 손과 머그 사이의 간격을 추적하고, 뇌는 근육 명령을 조정하며, 간격이 닫힌다. 눈을 감고 머그를 잡으려고 하면 빗나간다 — 개루프 도달은 신뢰할 수 없다. 귀환은 모델만으로는 닫을 수 없는 간격을 닫는다.

같은 원리가 다음을 구동한다:

- 결코 예측할 수 없었던 바람 속에서 고도를 유지하는 드론.
- 부하가 격렬하게 변하는데도 정확히 3.3 V를 공급하는 전원 칩.
- 휠 속도 측정에 기반하여 초당 30번 펌핑되는 자동차 잠금 방지 브레이크.

이후의 모든 장은 세 가지 작업 중 하나를 위한 도구다:

1. **모델링**: 플랜트가 무엇을 하는지 적기 (레슨 2, 3, 11).
2. **분석**: 후보 제어기가 작동할지 예측 — 안정성, 응답, 강건성 (레슨 4–8, 12).
3. **설계**: 제어기를 선택 (레슨 9, 10, 13, 14, 15, 16).

이 세 부분 지도를 염두에 두자. 모든 고급 주제 — 근궤적, Bode 선도, LQR, MPC — 가 이 슬롯 중 하나에 들어맞는다.

## 1. 제어 시스템이란 무엇인가?

**제어 시스템**은 원하는 출력을 달성하기 위해 동적 시스템의 거동을 관리, 명령, 또는 조절하는 구성 요소들의 상호 연결이다.

**일상의 예:**
- 실내 온도를 조절하는 온도조절기
- 차량 속도를 유지하는 정속 주행 장치
- 물체를 잡으려는 사람 손 (생물학적 귀환)
- 항공기를 항로에 유지하는 자동조종

제어 이론의 중심 질문: *특정 방식으로 동작하기를 원하는 시스템(플랜트)이 주어지면, 그 동작을 달성하기 위해 어떻게 제어기를 설계하는가?*

## 2. 개루프 vs. 폐루프 제어

### 2.1 개루프 제어

**개루프** 시스템은 실제 출력을 측정하지 않고 미리 계산된 입력을 적용한다.

```
Reference → [Controller] → [Plant] → Output
```

**예:** 타이머가 있는 토스터. 시간을 설정하지만, 토스터는 빵이 실제로 구워졌는지 확인하지 않는다.

**특성:**
- 단순하고 저렴
- 외란이나 모델 오차 보상 불가
- 플랜트의 정확한 지식 필요
- 귀환으로 인한 안정성 문제 없음

### 2.2 폐루프 (귀환) 제어

**폐루프** 시스템은 실제 출력을 측정하고 **오차**(원하는 값과 실제 값의 차이)를 사용하여 입력을 조정한다.

```
Reference →(+)→ [Controller] → [Plant] → Output
             ↑                           |
             └──── [Sensor] ←───────────┘
                    (feedback)
```

**예:** 온도조절기. 현재 온도를 측정하고, 설정값과 비교하고, 그에 따라 히터를 켜거나 끈다.

**특성:**
- 외란과 모델 불확실성 보상
- 파라미터 변동에 대한 민감도 감소
- 잘못 설계되면 불안정성을 도입할 수 있음
- 개루프보다 더 복잡

### 2.3 비교

| 성질 | 개루프 | 폐루프 |
|----------|-----------|-------------|
| 외란 제거 | 나쁨 | 좋음 |
| 파라미터 민감도 | 높음 | 낮음 |
| 복잡도 | 낮음 | 더 높음 |
| 안정성 위험 | 없음 | 가능 |
| 정확도 | 모델에 의존 | 자가 보정 |
| 비용 | 더 낮음 | 더 높음 |

## 3. 귀환 제어 시스템의 구성 요소

### 3.1 표준 블록 선도

```
         e(t)        u(t)         y(t)
r(t) →(+)→ [Controller] → [Plant] → Output
        ↑    (G_c)          (G_p)      |
        |                              |
        └────── [Sensor (H)] ←────────┘
                  b(t)
```

| 기호 | 이름 | 설명 |
|--------|------|-------------|
| $r(t)$ | 기준 (설정값) | 원하는 출력 |
| $e(t)$ | 오차 신호 | $e(t) = r(t) - b(t)$ |
| $u(t)$ | 제어 신호 (액추에이터 입력) | 제어기 출력 |
| $y(t)$ | 플랜트 출력 | 실제 시스템 출력 |
| $b(t)$ | 귀환 신호 | 측정된 출력 (스케일 가능) |
| $G_c$ | 제어기 | 오차를 처리해 제어 작용 생성 |
| $G_p$ | 플랜트 (공정) | 제어 대상 시스템 |
| $H$ | 센서 (귀환 요소) | 출력 측정 |

### 3.2 외란과 잡음

실무에서 시스템은 다음에 영향받는다:
- **외란(disturbance)** $d(t)$: 플랜트를 교란하는 외부 입력 (바람, 부하 변화)
- **측정 잡음(measurement noise)** $n(t)$: 귀환 신호를 손상시키는 센서 불완전성

```
                    d(t)
                     ↓
r(t) →(+)→ [G_c] →(+)→ [G_p] →(+)→ y(t)
        ↑                         ↑ n(t)
        └──── [H] ←──────────────┘
```

잘 설계된 제어기는 외란을 제거하면서 잡음을 과도하게 증폭하지 않는다.

## 4. 제어 시스템 성능 목표

제어기는 여러 (종종 경쟁하는) 목표를 만족하도록 설계된다:

### 4.1 안정성

시스템은 **안정**해야 한다: 유계 입력이 유계 출력을 생산하고, 시스템은 교란 후 평형으로 돌아간다. 이는 *가장 근본적인 요구사항* — 불안정 시스템은 쓸모없고 잠재적으로 위험하다.

### 4.2 추적

출력 $y(t)$는 기준 $r(t)$를 가능한 한 가깝게 따라야 한다:
- 일반적인 기준 신호(계단, 램프)에 대해 **0 정상상태 오차**
- **빠른 과도 응답** (짧은 상승 시간, 정착 시간)
- **최소 오버슈트**

### 4.3 외란 제거

제어기는 외란이 출력에 미치는 영향을 최소화해야 한다.

### 4.4 강건성

시스템은 다음에도 불구하고 잘 작동해야 한다:
- 플랜트 파라미터의 불확실성
- 미모델링된 동역학
- 동작 조건의 변동

### 4.5 민감도

**민감도**는 파라미터가 변할 때 시스템 거동이 얼마나 변하는지 측정한다. 귀환은 민감도를 감소시킨다 — 이는 그 주요 장점 중 하나.

**민감도 함수:**

$$S(s) = \frac{1}{1 + G_c(s) G_p(s) H(s)}$$

**루프 이득(loop gain)** $L(s) = G_c(s) G_p(s) H(s)$가 클 때 $S(s) \approx 0$이고 출력은 플랜트 변동에 둔감.

### 4.6 다섯 목표가 충돌한다

마음에 새길 짧은 표: 모든 목표 쌍은 어딘가에서 긴장 관계에 있다.

| ...을 강하게 하면 | 무엇이 손해 보는가 |
|-------------|--------------|
| 빠른 응답 | 큰 오버슈트, 더 많은 제어 노력, 강건성 감소 |
| 큰 루프 이득 (낮은 민감도) | 작은 안정성 여유, 더 많은 잡음 증폭 |
| 더 단단한 외란 제거 | 더 단단한 센서 잡음 추적 (같은 루프) |
| 더 강한 잡음 여과 | 더 느린 외란 응답 |
| 더 단단한 강건성 여유 | 느린 공칭 성능 |

이는 공학으로 없앨 수 있는 결함이 아니다 — 이는 귀환의 기하학이다. 모든 제어기는 이 표면 위의 선택된 점이다.

## 5. 역사적 맥락

| 연도 | 이정표 |
|------|-----------|
| ~270 BC | Ctesibius: 부유 조절기를 가진 물시계 |
| 1788 | Watt: 증기기관용 원심 조속기 |
| 1868 | Maxwell: "On Governors" — 최초의 수학적 안정성 분석 |
| 1922 | Minorsky: 선박 조종을 위한 PID 제어 |
| 1932 | Nyquist: 주파수 영역 안정성 판별법 |
| 1938 | Bode: 로그 주파수 선도 |
| 1948 | Evans: 근궤적법 |
| 1960 | Kalman: 상태 공간 방법, LQR, 칼만 필터 |
| 1970년대+ | 강건 제어 ($H_\infty$), 적응 제어, 비선형 제어 |
| 2000년대+ | 모델 예측 제어 (MPC), 학습 기반 제어 |

> **왜 그렇게 많은 오래된 수학?** 2026년의 대부분의 산업 제어기는 여전히 1932-1960년의 기법(PID, Bode, Nyquist, 근궤적)을 사용한다. 새로운 방법은 강력하지만 일반적인 산업 환경이 제공하는 것보다 더 높은 모델 충실도를 요구한다. 고전 도구를 먼저 마스터하라; 진짜 이유가 있을 때 $H_\infty$를 손에 잡으라.

## 6. 제어 시스템 분류

### 6.1 신호 유형별

- **연속 시간**: 신호와 시스템이 연속 시간 $t$에서 동작
- **이산 시간**: 신호가 간격 $T$로 샘플링됨 (디지털 제어)

### 6.2 선형성별

- **선형**: 중첩이 성립 — 고전 및 현대 제어 이론의 압도적 초점
- **비선형**: 중첩 안 됨 — 전문화된 방법 필요 (Lyapunov, sliding mode, feedback linearization)

### 6.3 입력/출력 수별

- **SISO**: 단일 입력, 단일 출력 (고전 제어)
- **MIMO**: 다중 입력, 다중 출력 (현대 상태 공간 방법)

### 6.4 시간 변동별

- **시불변 (LTI)**: 파라미터가 시간에 따라 변하지 않음
- **시변**: 파라미터가 변함 — 예: 연료 질량을 잃는 로켓

## 7. 수학적 사전 지식 복습

제어 이론은 미분방정식과 라플라스 변환의 개념 위에 구축된다. 가장 본질적인 것들의 짧은 복습:

### 7.1 선형 ODE

선형 시불변 (LTI) 시스템:

$$a_n \frac{d^n y}{dt^n} + a_{n-1} \frac{d^{n-1} y}{dt^{n-1}} + \cdots + a_1 \frac{dy}{dt} + a_0 y = b_m \frac{d^m u}{dt^m} + \cdots + b_0 u$$

### 7.2 라플라스 변환

라플라스 변환은 미분방정식을 대수 방정식으로 변환:

$$\mathcal{L}\{f(t)\} = F(s) = \int_0^\infty f(t) e^{-st} \, dt$$

핵심 성질: $\mathcal{L}\left\{\frac{d^n f}{dt^n}\right\} = s^n F(s) - s^{n-1}f(0) - \cdots - f^{(n-1)}(0)$

0 초기 조건에서 미분이 $s$ 곱셈이 되어 LTI 시스템 분석이 순수하게 대수적이 된다.

### 7.3 전달함수 (예고)

**전달함수**는 라플라스 변환된 출력 대 입력의 비율 (0 초기 조건):

$$G(s) = \frac{Y(s)}{U(s)}$$

이 개념은 레슨 3-10의 모든 것에 중심적이며 레슨 3에서 완전히 발전된다.

## 8. 강의 로드맵과 사용법

강의는 6개 부분으로 나뉜다. 각 부분이 사 주는 것의 짧은 요약:

| 부분 | 레슨 | 후 무엇을 할 수 있는가 |
|------|---------|-----------------------|
| I — 기초 | 1–3 | 물리 플랜트 모델링, 전달함수 유도 |
| II — 고전 분석 | 4–6 | 과도 거동 예측, 근궤적 스케치, 정상상태 오차 계산 |
| III — 주파수 영역 방법 | 7–8 | Bode/Nyquist 선도 읽기, 여유 계산, 지연 처리 |
| IV — 제어기 설계 | 9–10 | PID 튜닝, lead/lag 보상기 설계 |
| V — 현대 제어 | 11–14 | 상태 공간 모델 구축, 극점 배치, 관측기 설계, LQR/Kalman 유도 |
| VI — 확장 | 15–16 | 디지털 구현을 위한 이산화, 비선형성 처리 |

시간 제약이 있으면, 가장 영향력 높은 부분 집합은 **레슨 4, 7, 9** — 시간 영역 사양, Bode 선도, PID 튜닝이 산업 제어 작업의 ~80%를 커버한다.

## 9. 흔한 함정 — 강의 읽기

1. **LQR로 건너뛰기.** 현대 제어는 우아하지만 잘 모델링된 플랜트를 가정한다. 대부분의 실제 플랜트는 잘못 모델링됨 — 고전 방법(레슨 4–10)이 그 불일치를 더 잘 견딘다.
2. **"안정성"을 이진으로 취급.** 안정성은 바닥이지 천장이 아니다. "안정한" 시스템도 여전히 느리게 정착하거나, 가시적으로 진동하거나, 한 번의 외란에서 불안정성으로부터 떨어져 있을 수 있다. 여유(레슨 7–8)가 올바른 지표.
3. **액추에이터 잊기.** 모든 설계는 액추에이터가 요구 시 $u(t)$를 전달할 수 있다고 가정한다. 포화(레슨 9 사이드바)는 선형성을 깨고 선형 분석을 무효화한다. 항상 $\max|u|$를 액추에이터 한계와 비교 점검하라.
4. **센서 동역학 무시.** 50 ms 지연을 가진 센서는 플랜트의 일부이다; 이상으로 모델링하면 이득 교차에서 무는 위상 지연이 숨겨진다.
5. **순서대로 교과서 읽기 ≠ 이해.** 각 장은 다음 장이 가정하는 도구를 도입한다. 훑어본 후 돌아오라 — 도구가 어디로 향하는지 아는 두 번째 패스가 머리에 남는다.

3. 전원 공급 장치의 출력을 5V로 유지하는 전압 조정기

### 연습 문제 2: 개루프 vs. 폐루프

1. 세탁기가 30분 고정 사이클로 실행된다. 개루프인가 폐루프인가? 무엇이 폐루프로 만들 수 있는가?
2. 언덕이 많은 지형에서 차량 정속 주행이 순수 개루프일 수 없는 이유를 설명하라.
3. 폐루프 제어보다 개루프 제어가 선호되는 예를 들어라.

### 연습 문제 3: 귀환 효과

플랜트 이득 $G_p$가 8과 12 사이에서 변할 수 있는 시스템을 고려하라 (공칭 = 10).

1. 개루프에서 제어기 이득이 단위 전체 이득을 달성하기 위해 $G_c = 0.1$로 설정. 출력 이득의 범위는?
2. 폐루프 (단위 귀환 $H = 1$) $G_c = 100$에서 $G_p = 8, 10, 12$에 대한 폐루프 이득 $\frac{G_c G_p}{1 + G_c G_p}$을 계산하라. 출력은 얼마나 변하는가?
3. 민감도 감소를 위한 높은 루프 이득의 비용은 무엇인가?

### 연습 문제 4: 세 목표 드릴

화학 반응기의 온도 제어 루프에 대해, 추적, 외란 제거, 강건성 각각에 대한 세 가지 구체적이고 측정 가능한 목표 — 제어 엔지니어가 계약에서 헌신해야 할 — 를 나열하라. 그럴듯한 수치 목표(정착 시간, 최대 외란, 파라미터 변동 허용)를 추정하라.

### 연습 문제 5: 도구 선택

3. 디지털로 구현된 PID 제어기가 샘플 속도를 1 kHz에서 100 Hz로 줄이면 불안정 — 무엇을 확인하는가?
