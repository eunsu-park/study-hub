# 레슨 16: 비선형 제어와 고급 주제

## 학습 목표

- 비선형 제어가 필요한 이유와 선형 방법이 실패하는 경우를 이해한다
- Lyapunov 안정성 이론을 적용하여 비선형 시스템을 분석한다
- 기술 함수(describing function) 방법을 사용하여 한계 사이클(limit cycle)을 예측한다
- 슬라이딩 모드 제어(sliding mode control) 원리를 이해한다
- 모델 예측 제어(MPC)와 적응 제어(adaptive control) 개념을 살펴본다
- 각 고급 방법을 더 큰 제어 지형에 배치하고 각각이 옳은 도구일 때를 인식한다

## 0. 선형 도구가 멈추는 곳

레슨 1–15는 거의 전적으로 선형 시불변(LTI) 영역에 살았다. 이는 세상이 선형이기 때문이 아니라 — 그렇지 않다 — 동작점 근처에서 대부분의 플랜트가 선형 방법이 유용한 답을 만들 만큼 충분히 선형이기 때문이다. 이 레슨은 "동작점 근처"가 충분하지 않은 경우에 관한 것이다.

선형 방법이 곧 실패할 것임을 알리는 세 가지 구체적 신호:

- **동작 범위가 넓다.** 0° 주변에서 선형화된 진자는 ±5°에 적합하다. ±90°에서 $\sin\theta \approx \theta$는 복원력을 0.6 배 과소평가 — 선형 모델이 거짓말을 한다. 항공기, 로봇, 화학 반응기 모두 정기적으로 선형화가 의심스러운 범위에서 동작한다.
- **비선형성이 핵심이다.** 포화, 데드존, 릴레이, 히스테리시스, 마찰 — 이들은 선형화로 없앨 수 있는 버그가 아니다. 모든 실제 액추에이터와 많은 센서의 본질적 특징이다. 이를 무시하는 제어기는 프로덕션에서 부딪힌다.
- **GLOBAL 보장이 필요하다.** "국소 안정"은 선형 분석이 주는 답이다. "평형 주변 반 미터 공의 임의 초기 조건에서 안정" 같은 것은 Lyapunov 스타일의 논증을 요구한다 — 아래 2절.

이 레슨은 필연적으로 완전한 처리가 아니라 개관이다. 아래의 각 섹션은 기법이 적용될 때를 인식할 만큼 충분히 도입한다; 완전한 마스터는 토픽당 대학원 강의다.

## 1. 왜 비선형 제어인가?

모든 실제 시스템은 비선형이다. 선형화(레슨 2)는 동작점 근처에서 작동하지만, 다음 경우에 실패한다:

- 시스템이 **넓은 범위**에서 동작 (작은 섭동이 아닌 큰 각도의 진자)
- 비선형성이 **본질적** (포화, 데드존, 릴레이, 백래시, 히스테리시스)
- **글로벌** 안정성 보장 필요 (평형 근처 국소가 아님)
- 시스템이 **다중 평형**을 가짐 (상태가 어느 것에 수렴하는가?)

### 1.1 일반적 비선형성

| 비선형성 | 설명 | 효과 |
|-------------|-------------|--------|
| 포화 | 출력이 $\pm u_{\max}$로 제한 | 제어 권한 제한, 윈드업 |
| 데드존 | $|u| < \delta$에 대해 출력 없음 | 정상상태 오차, 한계 사이클 |
| 릴레이 (on-off) | 이진 출력 ($\pm M$) | 채터링, 한계 사이클 |
| 백래시 | 기계적 결합의 히스테리시스 | 위상 지연, 진동 |
| 쿨롱 마찰 | 운동에 반대하는 일정 마찰 | 스틱-슬립, 한계 사이클 |
| 양자화 | 이산 출력 레벨 | 설정값 주변 한계 사이클 |

### 1.2 비선형 현상

선형 시스템에서 **발생할 수 없지만** 비선형에서 흔한 거동:
- **한계 사이클**: 초기 조건과 무관한 지속 진동
- **분기(Bifurcation)**: 파라미터가 변할 때 거동의 질적 변화
- **카오스**: 초기 조건에 대한 민감한 의존
- **다중 평형**: 초기 조건에 따라 다른 정상 상태
- **유한 탈출 시간**: 상태가 유한 시간에 무한대로 감

## 2. Lyapunov 안정성 이론

### 2.1 개념

Aleksandr Lyapunov (1892)는 미분방정식을 **풀지 않고** 안정성을 증명하는 방법을 개발했다. 아이디어: 항상 감소하는 "에너지 같은" 함수를 찾을 수 있으면, 시스템은 평형에 접근하고 있어야 한다.

### 2.2 Lyapunov의 직접 방법

평형 $x = 0$에서 자율 시스템 $\dot{x} = f(x)$를 고려.

**정의:** 함수 $V(x): \mathbb{R}^n \to \mathbb{R}$이 **Lyapunov 함수**일 때:
1. $V(0) = 0$
2. 모든 $x \neq 0$에 대해 $V(x) > 0$ (양정치)
3. 궤적을 따라 $\dot{V}(x) = \nabla V \cdot f(x) \leq 0$

**정리 (Lyapunov):**

| $\dot{V}$의 조건 | 결론 |
|------------------------|------------|
| $\dot{V}(x) \leq 0$ (음 반정치) | Lyapunov 의미에서 안정 |
| $x \neq 0$에 대해 $\dot{V}(x) < 0$ (음정치) | 점근적 안정 |
| 어떤 $\alpha > 0$에 대해 $\dot{V}(x) \leq -\alpha V(x)$ | 지수적 안정 |

이 조건이 모든 $x$에 대해 성립하면 (원점 근처만이 아닌), 안정성은 **글로벌**.

### 2.3 예제: 감쇠 진자

$$\ddot{\theta} + \frac{b}{ml^2}\dot{\theta} + \frac{g}{l}\sin\theta = 0$$

상태: $x_1 = \theta$, $x_2 = \dot{\theta}$. 평형: $x = 0$.

**후보 Lyapunov 함수** (전체 에너지):

$$V(x) = \frac{1}{2}ml^2 x_2^2 + mgl(1 - \cos x_1) > 0 \quad (x \neq 0)$$

$$\dot{V} = ml^2 x_2 \dot{x}_2 + mgl(\sin x_1)\dot{x}_1 = ml^2 x_2\left(-\frac{b}{ml^2}x_2 - \frac{g}{l}\sin x_1\right) + mgl x_2 \sin x_1$$

$$= -bx_2^2 \leq 0$$

$\dot{V} = 0$이 $x_2 = 0$일 때만이고 (LaSalle 불변 원리에 의해, $x_2 = 0$인 유일한 불변 집합은 $x_1 = 0$), 원점은 **글로벌 점근적 안정**이다.

### 2.4 Lyapunov 함수 찾기

Lyapunov 함수를 찾는 일반 알고리즘은 없지만, 일반적 접근:
- **에너지 방법**: 물리적 에너지 사용 (운동 + 위치)
- **이차 형식**: $V(x) = x^T P x$ ($P > 0$) — 선형 시스템에 작동 ($A^T P + PA < 0$, Lyapunov 방정식)
- **변수 기울기 방법(variable gradient)**: $\nabla V = M(x)x$ 가정 후 $M$ 풀이
- **SOS (제곱의 합)**: 다항식 시스템용 계산 방법 — 반정치 계획법으로 $V$ 탐색

### 2.5 선형 시스템에 대한 Lyapunov

$\dot{x} = Ax$, $V = x^T P x$:

$$\dot{V} = x^T(A^T P + PA)x = -x^T Q x$$

Lyapunov 방정식 $A^T P + PA = -Q$는 임의의 $Q > 0$에 대해 유일한 양정치 해 $P$를 가질 필요충분조건이 $A$가 안정($A$의 모든 고유값이 LHP)인 것이다. 이는 대안적 안정성 판별.

> **에너지가 작동하는 이유**: 진자 예제에서 $V$는 문자 그대로 운동 에너지 + 위치 에너지다. 마찰이 그것을 소산한다. 논증은 일반화된다 — 궤적을 따라 단조 감소하는 임의의 스칼라량을 식별할 수 있으면 Lyapunov 함수를 얻는다. 기술은 비기계 시스템에 대해 옳은 "에너지"를 인식하는 것.

## 3. 기술 함수 분석

### 3.1 목적

**기술 함수(describing function)** 방법은 비선형 귀환 시스템의 **한계 사이클**(지속 진동)을 예측한다.

### 3.2 설정

```
     ┌────────┐      ┌────────┐
r=0 →(+)→│ N(a,ω) │→───→│ G(jω)  │→── y
     ↑   └────────┘      └────────┘  |
     └────────────────────────────────┘
```

$N(a, \omega)$는 비선형성의 **기술 함수** — 진폭 $a$의 사인 입력에 대한 출력 기본 고조파의 비율.

### 3.3 기술 함수

진폭 $a$의 사인 입력 $x(t) = a\sin(\omega t)$이 메모리 없는 비선형성 $y = n(x)$로 들어갈 때:

$$N(a) = \frac{1}{\pi a}\int_0^{2\pi} n(a\sin\theta) e^{j\theta} d\theta$$

**대칭** 비선형성(홀함수)의 경우, $N(a)$는 **실수**.

### 3.4 일반적 기술 함수

| 비선형성 | $N(a)$ |
|-------------|--------|
| 이상 릴레이 ($\pm M$) | $\frac{4M}{\pi a}$ |
| 포화 (기울기 $k$, 한계 $M$) | $\frac{2k}{\pi}\left[\sin^{-1}\frac{M}{ka} + \frac{M}{ka}\sqrt{1-\left(\frac{M}{ka}\right)^2}\right]$ ($a > M/k$) |
| 데드존 (폭 $2\delta$) | $\frac{k}{\pi}\left[\pi - 2\sin^{-1}\frac{\delta}{a} - \frac{2\delta}{a}\sqrt{1-\left(\frac{\delta}{a}\right)^2}\right]$ ($a > \delta$) |

### 3.5 한계 사이클 예측

진폭 $a$, 주파수 $\omega$의 한계 사이클 존재:

$$1 + N(a)G(j\omega) = 0 \quad \Rightarrow \quad G(j\omega) = -\frac{1}{N(a)}$$

**그래픽적으로:** 같은 Nyquist 평면에 $G(j\omega)$와 $-1/N(a)$를 그린다. 교차점이 한계 사이클을 예측.

**한계 사이클의 안정성:** $a$ 증가가 $-1/N(a)$를 $G(j\omega)$에 둘러싸인 영역으로 **이동**시키면, 한계 사이클이 **안정**(자기 지속).

## 4. 슬라이딩 모드 제어

### 4.1 개념

**슬라이딩 모드 제어(SMC)**는 시스템 상태를 **슬라이딩 표면(sliding surface)** $\sigma(x) = 0$로 강제하고 고주파 스위칭을 사용해 거기에 유지한다. 슬라이딩 표면 위에서 시스템 동역학은 차수가 줄어들고 원하는 거동을 위해 설계 가능.

### 4.2 2차 시스템 설계

$\ddot{y} = f(x) + bu$에 대해 슬라이딩 표면 정의:

$$\sigma = \dot{e} + \lambda e$$

$e = y - y_d$는 추적 오차, $\lambda > 0$는 표면에서의 수렴 속도 결정.

**제어 법칙:**

$$u = \frac{1}{b}\left[-f(x) + \ddot{y}_d - \lambda\dot{e} - k\text{sign}(\sigma)\right]$$

$k > 0$는 스위칭 이득. $\text{sign}(\sigma)$ 항이 상태를 $\sigma = 0$으로 끌고 간다.

### 4.3 도달 조건

상태가 슬라이딩 표면에 도달하도록:

$$\sigma\dot{\sigma} < 0$$

$k$가 외란과 불확실성을 극복할 만큼 크면 보장됨.

### 4.4 채터링(Chattering)

불연속 $\text{sign}(\sigma)$가 **채터링** — $\sigma = 0$ 주변 고주파 진동 — 을 야기. 완화 접근:
- **경계 층(boundary layer)**: $\text{sign}(\sigma)$를 $\text{sat}(\sigma/\phi)$로 대체, $\phi$는 층 폭
- **슈퍼 트위스팅 알고리즘**: 채터링을 줄이는 고차 슬라이딩 모드
- **도달 법칙 접근**: $\dot{\sigma} = -k|\sigma|^\alpha \text{sign}(\sigma)$ ($0 < \alpha < 1$) 사용

## 5. 모델 예측 제어 (MPC)

### 5.1 개념

**MPC**는 각 시간 단계에서 최적화 문제를 푼다:
1. 모델을 사용해 호라이즌 $N$에 걸쳐 미래 시스템 거동을 **예측**
2. 예측된 궤적에 대해 비용 함수를 **최적화**
3. **첫 번째** 제어 입력만 적용
4. 다음 시간 단계에서 **반복** (후퇴 호라이즌, receding horizon)

### 5.2 정형화

각 시간 단계 $k$에서 풀이:

$$\min_{u[k], \ldots, u[k+N-1]} \sum_{i=0}^{N-1} \left[ x[k+i]^T Q x[k+i] + u[k+i]^T R u[k+i] \right] + x[k+N]^T P_f x[k+N]$$

제약 조건:
- $x[k+i+1] = Ax[k+i] + Bu[k+i]$ (모델)
- $u_{\min} \leq u[k+i] \leq u_{\max}$ (입력 제약)
- $x_{\min} \leq x[k+i] \leq x_{\max}$ (상태 제약)

### 5.3 장점

- **제약을 명시적으로 처리** (액추에이터 한계, 안전 한계)
- **체계적 MIMO 설계**
- **미리 보기 능력** (알려진 미래 기준 통합 가능)
- **최적** (예측 호라이즌 내)

### 5.4 도전

- 계산 비용 (실시간으로 최적화 문제 풀이)
- 좋은 모델 필요
- 안정성 보장은 신중한 설계 필요 (종단 비용 $P_f$, 종단 제약)
- 호라이즌 $N$, 가중치 $Q$, $R$, 제약 튜닝

### 5.5 MPC vs. LQR

| 특성 | LQR | MPC |
|---------|-----|-----|
| 호라이즌 | 무한 | 유한 (후퇴) |
| 제약 | 처리 불가 | 명시적 처리 |
| 계산 | 오프라인 (ARE 한 번 풀이) | 온라인 (각 단계마다 QP 풀이) |
| 최적성 | 글로벌 최적 (제약 없음) | 국소 최적 (제약 있음) |
| MIMO | 예 | 예 |

제약 없이 $N \to \infty$일 때, MPC는 LQR로 수렴.

> **MPC의 킬러 기능**: 이 강의의 모든 다른 기법은 설계 시 제약을 무시하고 안티 윈드업이나 포화로 패치한다. MPC만이 제약을 최적화 안에 넣는다 — 이는 제어기가 액추에이터가 포화될 수 있음을 **알고** 한계를 존중하는 입력을 선택한다는 의미. 하드 한계가 있는 고성능 산업 제어(화학 반응기, 차량 안정성)에서 MPC가 기본이 되었다.

## 6. 적응 제어

### 6.1 동기

플랜트 파라미터가 **알려지지 않거나** **시변**이면, 고정 제어기가 잘 작동하지 않을 수 있다. 적응 제어는 제어기 파라미터를 실시간으로 조정.

### 6.2 모델 기준 적응 제어 (MRAC)

```
Reference ──→ [Reference Model] ──→ y_m (desired output)
    |                                      |
    └──→ [Adaptive Controller] ──→ [Plant] ──→ y (actual output)
              ↑                              |
              └── [Adaptation Law] ←── e = y - y_m
```

적응 법칙은 Lyapunov 기반 설계 또는 MIT 규칙을 사용해 $y(t) \to y_m(t)$가 되도록 제어기 파라미터를 조정.

### 6.3 자가 조정 조절기(Self-Tuning Regulators)

1. 플랜트 파라미터를 온라인으로 **추정** (재귀 최소제곱 등 사용)
2. 추정된 플랜트에 대해 제어기 **설계** (극배치, LQR 등 사용)
3. **적용**하고 반복

이는 시스템 식별과 제어기 설계를 폐루프에서 결합.

```
                    Control Theory
                         │
         ┌───────────────┼───────────────┐
    Classical           Modern          Advanced
         │                │                │
    ├── Transfer fn   ├── State-space  ├── Nonlinear
    ├── Root locus    ├── Pole place.  ├── Lyapunov
    ├── Bode/Nyquist  ├── LQR/LQG     ├── Sliding mode

```

**핵심 요점:** 작동하는 가장 단순한 방법으로 시작하라. PID가 산업 제어 문제의 대부분을 처리한다. 제약, MIMO 결합, 비선형성, 또는 엄격한 성능 요구사항이 요구할 때 고급 방법을 사용하라.

## 8. 흔한 함정

1. **잘못된 스칼라에 Lyapunov 시도.** 모든 양함수가 $V$로 작동하지 않는다. 기술은 궤적을 따라 음의 도함수를 갖는 것을 선택하는 것이다 — 에너지는 기계 시스템에 작동하지만, 다른 영역은 다른 선택이 필요하다 (열역학에는 엔트로피, 보존 시스템에는 Hamiltonian).
2. **심하게 왜곡된 출력에 기술 함수 신뢰.** 기술 함수는 기본 고조파만 사용한다. 비선형성이 루프의 $G(j\omega)$가 여과하지 못하는 강한 고조파를 만들면 예측이 어긋날 수 있다 — DF는 $G(j\omega)$가 두 번째 고조파보다 충분히 낮은 컷오프를 가진 저역통과일 때 신뢰할 수 있다.
3. **실제 SMC 구현에서 채터링 무시.** "$\text{sign}(\sigma)$"는 무한 스위칭 주파수를 의미하며, 어떤 액추에이터도 전달하지 못한다. 경계 층 SMC는 작은 정상상태 오차를 유한 스위칭과 교환한다 — 거의 항상 실용적으로 옳은 절충.
4. **재귀적 가능성(recursive feasibility) 분석 없는 MPC.** 단순한 MPC 정형화는 $N$ 단계에서 가능한 입력 시퀀스가 없는 상태에 부딪힐 수 있다 — 최적화는 그저 실패한다. 강건 MPC와 도달 가능성 도구(5.4절)가 이를 방지한다; 벤치탑 데모에서는 건너뛰는 것이 괜찮지만 프로덕션에서는 위험하다.
5. **모델 불확실성에 대한 마법 답으로서의 적응 제어.** MRAC와 자가 조정기는 플랜트의 구조가 알려져 있고 파라미터만 알려지지 않았다고 가정한다. 구조 자체가 틀리면 (예: 2차로 가정했지만 플랜트가 3차), 적응이 파라미터를 잘못된 방향으로 끌고 가 루프를 불안정화할 수 있다.
6. **너무 일찍 비선형 방법에 손대기.** 적절한 동작점에서 합리적 강건성 여유로 설계된 선형 제어기가 "비선형" 문제의 80%+를 처리한다. 게인 스케줄된 선형 제어가 충분하지 않을 명확한 이유가 있을 때만 SMC, MPC, 또는 feedback linearization에 손대라.

## 연습 문제

### 연습 문제 1: Lyapunov 분석

Van der Pol 진동자:

$$\ddot{x} - \mu(1 - x^2)\dot{x} + x = 0$$

1. 평형점을 구하라
2. 평형 주변에서 선형화하고 $\mu > 0$에 대한 국소 안정성을 분석하라
3. Lyapunov 함수 $V = \frac{1}{2}(x^2 + \dot{x}^2)$ 시도. $\dot{V}$를 계산하라. 안정성을 결론낼 수 있는가?
4. Van der Pol 진동자가 $\mu > 0$에 대해 무엇을 보이는가? (힌트: 한계 사이클)

### 연습 문제 2: 기술 함수

귀환 시스템에 릴레이 비선형성 ($\pm 1$)이 $G(s) = \frac{10}{s(s+1)(s+2)}$와 직렬.

1. 릴레이의 기술 함수를 작성하라
2. $-1/N(a)$를 구하고 복소 평면에 스케치하라
3. $G(j\omega)$와의 교차를 찾아 한계 사이클 진폭과 주파수를 예측하라

### 연습 문제 3: MPC 개념

이산 시간 이중 적분기 $x[k+1] = \begin{bmatrix} 1 & T \\ 0 & 1 \end{bmatrix} x[k] + \begin{bmatrix} T^2/2 \\ T \end{bmatrix} u[k]$, $T = 0.1$ s, 제약 $|u| \leq 1$:

1. $Q = I$, $R = 0.1$, $N = 10$로 MPC 최적화 문제를 정형화하라
2. 제약 없이는 유한 호라이즌 LQR — $|u| \leq 1$일 때 무엇이 변하는가?
3. 후퇴 호라이즌 ($u[k]$만 적용하고 다시 풀이)이 외란에 도움이 되는 이유를 설명하라

### 연습 문제 4: 옳은 도구 선택

각 시나리오에 대해 (선형 게인 스케줄, Lyapunov 기반 비선형, SMC, MPC, 적응) 중 하나를 선택하고 한 문장으로 정당화:

1. 다양한 페이로드 질량 하의 쿼드콥터 고도 유지.
2. 하드 온도 한계와 알려진 동역학을 가진 화학 반응기.
3. 마찰을 가진 나노미터 정확도 하드 디스크 드라이브 헤드 위치 결정.
4. 저속 접근에서 고속 순항까지 비행 영역을 가로지르는 항공기 자동조종.
5. 매달려 있는 상태에서 스윙 업하는 카트 위 역진자.

### 연습 문제 5: 선형화 실패 데모
