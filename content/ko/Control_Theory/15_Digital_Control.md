# 레슨 15: 디지털 제어 시스템(Digital Control Systems)

## 학습 목표

- 샘플링(sampling) 과정과 제어 시스템에 미치는 영향을 이해한다
- Z-변환을 적용하여 이산 시간 시스템을 분석한다
- 연속 시간 제어기를 이산 시간 구현으로 변환한다
- Z-영역에서 직접 디지털 제어기를 설계한다
- 이산 시간 시스템의 안정성을 분석한다
- `scipy.signal.cont2discrete`로 제어기를 수치 이산화하고 각 방법의 절충을 인식한다

## 0. 디지털 제어가 자체 레슨을 갖는 이유

오늘 배포되는 모든 제어기는 마이크로컨트롤러, DSP 또는 FPGA에서 실행된다 — "아날로그"처럼 보이는 시스템조차도 내부적으로 샘플링한다. 레슨 1–14의 연속 시간 수학은 설계 의도를 설정한다; 이 레슨은 그 의도가 A/D 변환기, 샘플 앤 홀드, 그리고 유한 정밀도 산술 단위를 통과해 살아남는 방법이다.

디지털 제어가 자체 분야인 세 가지 이유:

- **샘플링은 파괴적 연산이다.** Nyquist 주파수 위의 정보는 관심 대역으로 앨리어싱된다. 1 kHz 외란을 처리하는 연속 제어기가 100 Hz 샘플러가 그것을 먹어버린 후 완전히 보지 못할 수 있다.
- **이산화는 안정성을 변경한다.** 견고하게 안정한 연속 제어기가 너무 거칠게 이산화되면 불안정해질 수 있다. 특히 전향 Euler는 안정한 LHP 극점을 단위원 밖의 불안정 점으로 매핑할 수 있다.
- **유한 정밀도가 양자화 잡음을 추가한다.** 16비트 ADC + fp32 제어기 산술은 대부분의 루프에 적합; 12비트 ADC + fp16은 놀랄 만큼 잡음이 많다. 비트 예산은 설계의 일부이지 하류 관심사가 아니다.

머릿속 그림: 연속 설계는 s-평면에 산다 (LHP = 안정). 디지털 구현은 z-평면에 산다 (단위원 내부 = 안정). 그들 사이의 매핑은 설계의 가장 취약한 다리다.

## 1. 디지털 제어가 필요한 이유

현대 제어기는 **디지털 컴퓨터**(마이크로컨트롤러, DSP, FPGA)에 구현된다. 연속 시간 신호는:

1. 이산 시간 순간 $t = kT$에 **샘플링**됨 ($T$는 샘플링 주기)
2. 유한 정밀도로 **양자화**됨 (A/D 변환)
3. 디지털 제어기 알고리즘으로 **처리**됨
4. 영차 홀드 D/A 변환으로 연속 시간 신호로 **재구성**됨

```
r(t)→[Sampler]→r[k]→[Digital Controller]→u[k]→[ZOH]→u(t)→[Plant]→y(t)
                                                                   ↓
                                                            [Sampler]←─┘
                                                              y[k]
```

### 1.1 디지털 제어의 장점

- 유연성 (하드웨어가 아닌 소프트웨어로 알고리즘 변경)
- 반복성 (구성요소 드리프트 없음)
- 복잡한 알고리즘 가능 (적응, 최적, 비선형)
- 디지털 신호의 잡음 면역성
- 쉬운 로깅 및 모니터링

### 1.2 샘플링 정리

**Shannon/Nyquist 샘플링 정리:** 대역폭 $\omega_B$인 신호를 재구성하려면 샘플링 주파수가 다음을 만족해야 함:

$$\omega_s = \frac{2\pi}{T} > 2\omega_B$$

제어 실무에서 샘플링 속도는 보통 다음과 같이 선택:

$$\omega_s \geq (10\text{–}30) \times \omega_{BW}$$

여기서 $\omega_{BW}$는 폐루프 대역폭. 디지털 제어기가 연속 시간 대응물과 유사하게 동작하도록 보장.

## 2. 영차 홀드(Zero-Order Hold, ZOH)

**영차 홀드**는 이산 제어 신호를 조각별 상수 연속 신호로 변환:

$$u(t) = u[k] \quad \text{for } kT \leq t < (k+1)T$$

ZOH의 전달함수:

$$G_{\text{ZOH}}(s) = \frac{1 - e^{-sT}}{s}$$

ZOH는 약 $T/2$의 시간 지연을 도입하여, 위상 지연을 추가하고 $T$가 너무 크면 시스템을 불안정화할 수 있다.

> **설계자 단축식**: 모든 중요 주파수에서 추가 위상 지연으로 $T/2$ 예산. 60° 위상 여유와 $T = 10$ ms 샘플러를 가진 루프가 $\omega_{gc} = 100$ rad/s에서 ZOH만으로 $\approx 28°$의 여유를 잃는다 — 32°를 남긴다, 이는 경고 대역에 있다.

## 3. Z-변환

### 3.1 정의

이산 시간 수열 $f[k]$의 Z-변환:

$$F(z) = \mathcal{Z}\{f[k]\} = \sum_{k=0}^{\infty} f[k] z^{-k}$$

Z-변환은 라플라스 변환의 이산 시간 대응물.

### 3.2 주요 Z-변환 쌍

| $f[k]$ | $F(z)$ |
|---------|--------|
| $\delta[k]$ (단위 임펄스) | $1$ |
| $u[k]$ (단위 계단) | $\frac{z}{z-1}$ |
| $k u[k]$ (램프) | $\frac{Tz}{(z-1)^2}$ |
| $a^k u[k]$ | $\frac{z}{z-a}$ |
| $e^{-akT} u[k]$ | $\frac{z}{z-e^{-aT}}$ |

### 3.3 주요 성질

| 성질 | 시간 영역 | Z-영역 |
|----------|------------|----------|
| 선형성 | $af_1[k] + bf_2[k]$ | $aF_1(z) + bF_2(z)$ |
| 시간 이동 | $f[k-1]$ | $z^{-1}F(z)$ |
| 시간 전진 | $f[k+1]$ | $zF(z) - zf[0]$ |
| 최종값 | $\lim_{k\to\infty} f[k]$ | $\lim_{z\to 1}(z-1)F(z)$ |

### 3.4 s-에서 z-로의 매핑

$s$와 $z$ 영역 간의 기본 관계:

$$z = e^{sT}$$

매핑:
- $s$-평면 좌반평면 ($\text{Re}(s) < 0$) → 단위원 내부 ($|z| < 1$)
- 허수축 ($\text{Re}(s) = 0$) → 단위원 ($|z| = 1$)
- $s$-평면 우반평면 ($\text{Re}(s) > 0$) → 단위원 외부 ($|z| > 1$)

**Z-영역의 안정성:** 이산 시간 시스템이 안정할 필요충분조건은 모든 극점이 **단위원 내부** $|z| < 1$에 있는 것.

## 4. 이산 시간 전달함수

### 4.1 펄스 전달함수

이산 시간 시스템 $y[k] = G(z) U(z)$:

$$G(z) = \frac{Y(z)}{U(z)} = \frac{b_m z^m + b_{m-1}z^{m-1} + \cdots + b_0}{z^n + a_{n-1}z^{n-1} + \cdots + a_0}$$

### 4.2 ZOH-등가 이산화

연속 플랜트 $G_p(s)$가 주어지면, **ZOH-등가** 이산 전달함수:

$$G_d(z) = (1 - z^{-1})\mathcal{Z}\left\{\frac{G_p(s)}{s}\right\}$$

이는 샘플링 순간에 ZOH 앞에 놓인 연속 플랜트의 거동을 정확히 포착.

### 4.3 예제

$G_p(s) = \frac{1}{s+a}$:

$$\frac{G_p(s)}{s} = \frac{1}{s(s+a)} = \frac{1}{a}\left(\frac{1}{s} - \frac{1}{s+a}\right)$$

$$\mathcal{Z}\left\{\frac{G_p(s)}{s}\right\} = \frac{1}{a}\left(\frac{z}{z-1} - \frac{z}{z-e^{-aT}}\right)$$

$$G_d(z) = \frac{1-e^{-aT}}{z - e^{-aT}}$$

### 4.4 파이썬으로 이산화

`scipy.signal.cont2discrete`는 ZOH, Tustin (bilinear), 임펄스 불변을 한 번의 호출로 수행:

```python
import numpy as np
from scipy.signal import cont2discrete

# 연속 플랜트: G(s) = 1 / (s + 5)
num = [1]; den = [1, 5]
T = 0.1   # 10 Hz 샘플링

# 세 가지 방법을 시도하고 비교
for method in ["zoh", "bilinear", "euler"]:
    num_d, den_d, _ = cont2discrete((num, den), T, method=method)
    print(f"{method:>10}: num = {np.array(num_d).flatten()},  den = {den_d}")
```

ZOH와 bilinear는 다른 그러나 둘 다 안정적인 이산화를 만들어야 하며; 전향 Euler는 `T`가 시상수에 비해 크면 의심스럽다. 이산화 후 항상 단위원에 대한 극점 위치를 확인하라.

## 5. 연속 제어기의 이산화

### 5.1 일반적 방법

연속 제어기 $G_c(s)$가 주어지면, Z-영역에서 근사:

**전향 Euler (forward difference):**

$$s \approx \frac{z-1}{T} \quad \Rightarrow \quad G_d(z) = G_c(s)\big|_{s=(z-1)/T}$$

**후향 Euler (backward difference):**

$$s \approx \frac{z-1}{Tz} \quad \Rightarrow \quad G_d(z) = G_c(s)\big|_{s=(z-1)/(Tz)}$$

**Tustin 방법 (bilinear transform, trapezoidal rule):**

$$s \approx \frac{2}{T}\frac{z-1}{z+1} \quad \Rightarrow \quad G_d(z) = G_c(s)\big|_{s=\frac{2}{T}\frac{z-1}{z+1}}$$

### 5.2 비교

| 방법 | 안정성 보존 | 주파수 워핑 | 정확도 |
|--------|----------------------|-------------------|----------|
| 전향 Euler | 아니오 (안정 → 불안정 매핑 가능) | 아니오 | 낮음 |
| 후향 Euler | 예 (LHP를 단위원 내부로 매핑) | 아니오 | 낮음 |
| Tustin | 예 | 예 (주파수 워핑) | 좋음 |
| ZOH-등가 | 예 | 해당 없음 (샘플 시간에 정확) | $t = kT$에서 정확 |

**Tustin의 주파수 워핑:** 쌍선형 변환은 $\omega_s$ (연속)을 $\omega_d$ (이산)로 비선형 매핑:

$$\omega_d = \frac{2}{T}\tan\frac{\omega_s T}{2}$$

중요한 주파수(교차, 노치)에 대해, 쌍선형 변환을 적용하기 전에 연속 주파수를 조정하여 **사전 워핑(pre-warp)**.

### 5.3 디지털 PID 구현

연속 PID $u(t) = K_p e + K_i \int e \, dt + K_d \dot{e}$:

**위치 형태(Positional form)** (적분에 Tustin, 미분에 후향 Euler 사용):

$$u[k] = K_p e[k] + K_i T \sum_{j=0}^{k} e[j] + K_d \frac{e[k] - e[k-1]}{T}$$

**속도 형태(Velocity / incremental form)** (선호 — 적분 윈드업을 자연스럽게 회피):

$$\Delta u[k] = K_p(e[k] - e[k-1]) + K_i T e[k] + K_d \frac{e[k] - 2e[k-1] + e[k-2]}{T}$$

$$u[k] = u[k-1] + \Delta u[k]$$

> **속도 형태의 숨은 미덕**: 적분 상태를 명시적으로 누적하지 않는다. 액추에이터가 포화되어 `u[k]`를 클램핑하면, 다음 $\Delta u[k]$는 내부 누적합이 아니라 `e[k]`로 계산된다. 이는 위치 형태의 명시적 클램핑에 비해 "공짜" 안티 윈드업이다.

## 6. 이산 시간 안정성 분석

### 6.1 Jury 안정성 판별법

Routh-Hurwitz 판별법의 이산 시간 대응. 특성 다항식:

$$P(z) = a_n z^n + a_{n-1}z^{n-1} + \cdots + a_0$$

**필요 조건** (모두 성립해야 함):
1. $P(1) > 0$
2. $(-1)^n P(-1) > 0$
3. $|a_0| < a_n$

전체 Jury 배열이 충분 조건을 제공 (Routh 배열과 유사).

### 6.2 Routh를 사용하기 위한 쌍선형 변환

대안: $z = \frac{w+1}{w-1}$ (쌍선형 변환)을 $P(z)$에 대입하여 $w$의 다항식 얻기. $z$의 단위원이 $w$의 허수축으로 매핑되므로 표준 Routh-Hurwitz 판별법을 $w$-다항식에 적용 가능.

## 7. 직접 디지털 설계

연속 시간으로 설계 후 이산화하는 대신, Z-영역에서 **직접** 설계:

### 7.1 데드비트(Dead-Beat) 제어

폐루프 전달함수가 **유한 시간 내 0 오차**(보통 $n$차 시스템에 대해 $n$ 샘플링 주기)를 달성하도록 선택:

$$T(z) = z^{-d}$$

어떤 지연 $d$. 제어기:

$$G_c(z) = \frac{T(z)}{(1 - T(z))G_d(z)}$$

데드비트 제어기는 빠르지만 큰 제어 신호를 요구하고 모델 오차에 민감.

### 7.2 이산 근궤적

근궤적 기법은 Z-영역에서 동일하게 적용되며, 안정 경계가 허수축 대신 **단위원**.

## 8. 흔한 함정

1. **너무 느리게 샘플링.** 10–30× 경험 법칙은 경험적이지 선택사항이 아니다. 5× 마진은 때때로 작동하지만 ZOH 위상 지연이 너무 커서 위상 여유의 대부분을 먹는다. 의심되면 더 빠르게 샘플 — RAM과 CPU 비용은 거의 병목이 아니다.
2. **경계 안정 플랜트에 전향 Euler 이산화.** 전향 Euler는 $s = -a$를 $z = 1 - aT$로 매핑하여, $a > 2/T$일 때 단위원 **외부**로 이동. 작은 $T$에서 전향 Euler를 견디는 빠른 극점을 가진 연속 설계가 $T$가 커지면 불안정해진다. 후향 Euler 또는 Tustin을 대신 사용.
3. **Tustin 워프 잊기.** 쌍선형 변환은 DC와 Nyquist를 정확히 보존하지만 그 사이의 모든 주파수를 왜곡한다. 연속 설계에 50 Hz 노치가 있으면, 이산화된 노치는 사전 워핑하지 않는 한 약간 다른 주파수에 있다.
4. **프로덕션에서 위치 PID 형태 사용.** 속도 형태는 액추에이터 포화를 우아하게 처리(5.3절 사이드바). 위치 형태는 명시적 안티 윈드업이 필요하며 잘못하기 쉽다.
5. **$z$와 $z^{-1}$ 규약을 조용히 혼동.** 일부 교과서는 $G(z)$를 $z^{-1}$의 다항식 비율(FIR/IIR 규약)로, 다른 것들은 $z$로(제어 규약) 쓴다. 둘 다 옳지만 하나에 헌신해야 한다 — 유도 중간에 뒤집는 것은 부호 오류와 추가 $z^{-d}$ 지연의 레시피.
6. **저정밀 구현에서 양자화 잡음 무시.** 12비트 ADC는 대략 72 dB의 동적 범위를 가진다. 루프 대역폭이 풀스케일에서 80 dB 아래 변화를 감지해야 하면, 제어기가 그것을 보지 못한다. ADC를 업그레이드하거나 잡음 바닥을 받아들여라.

## 연습 문제

### 연습 문제 1: ZOH 이산화

샘플링 주기 $T = 0.1$ s인 플랜트 $G_p(s) = \frac{5}{s(s+5)}$:

1. ZOH-등가 이산 전달함수 $G_d(z)$를 계산하라
2. 이산 극점을 구하고 연속 극점에 $z = e^{sT}$를 적용한 것에 대응하는지 검증하라
3. DC 이득 확인: 계단 응답에 대해 $G_d(1) = G_p(0) \cdot T$

### 연습 문제 2: 디지털 PID

연속 PI 제어기 $G_c(s) = 2(1 + \frac{1}{0.5s})$를 $T = 0.05$ s로 디지털 구현.

1. Tustin 방법으로 이산화하라
2. 차분 방정식 $u[k] = f(u[k-1], e[k], e[k-1])$를 작성하라
3. 속도 형태 구현과 비교하라

### 연습 문제 3: 안정성 분석

이산 시간 특성 다항식 $P(z) = z^3 - 1.2z^2 + 0.5z - 0.1$:

1. Jury 판별법의 필요 조건을 적용하라
2. 시스템이 안정한지 판정하라
3. 실제 근을 찾고 검증하라

### 연습 문제 4: 이산화 방법 비교

연습 문제 2의 연속 제어기를 가져와라. 전향 Euler, 후향 Euler, Tustin, ZOH 등가로 $T = 0.05$ s에서 이산화하라. 각 $G_d(z)$의 크기 응답을 $\omega = 0$에서 $\omega = \pi/T$까지 그리고 연속 $G_c(j\omega)$와 비교하라. 관심 대역에서 연속 응답을 가장 잘 추적하는 방법을 식별하라.

### 연습 문제 5: 샘플링 속도 민감도

안정한 연속 폐루프를 가져와 $T \in \{0.001, 0.01, 0.1, 1\}$ s로 이산화하라. 각 샘플링 속도에 대해 z-평면에 이산 극점을 그리고 어느 극점이라도 단위원을 떠나는 $T$를 식별하라. 그 임계 $T$를 폐루프 대역폭과 관련지어라.
