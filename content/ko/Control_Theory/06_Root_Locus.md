## 0. 동기 — 컴퓨터 시대에 왜 근궤적인가?

초보자의 반박: 노트북은 $1 + KG(s) = 0$을 임의의 $K$에 대해 마이크로초 단위로 풀 수 있으니, 1950년대의 그래픽 방법을 왜 배우는가? 두 가지 답이 있다:

- **근궤적은 손잡이를 돌리기 *전에* 무슨 일이 일어날지 알려준다.** 개루프 플랜트가 주어졌을 때, "이득을 올리면 폐루프 극점이 어떻게 움직이는가?"를 한 장의 그림으로 답한다. 이러한 매개변수적 이해는 시행착오로 튜닝하는 기술자와 사고로 튜닝하는 설계자를 구분한다.
- **최적화가 답하지 못하는 문제에도 답한다.** 플랜트에 파라미터 불확실성, 액추에이터 한계, 혹은 재설계 요구("영점을 추가 — 어디에?")가 있을 때, 근궤적은 **전체 궤적**을 보여준다. 수치 근 찾기는 한 점을 준다. 근궤적은 일가(family)를 준다.

구체적 그림: 우세한 폐루프 극점을 두 개의 구슬로 상상하자. $K = 0$에서 개루프 극점 위치에 놓여 있다가 $K$를 올리면 궤적을 따라 굴러간다. 설계자의 역할은 구슬이 (레슨 4의) 시간 영역 사양을 만족하는 $s$-평면 영역에 놓이는 $K$를 고르는 것이다. 궤적은 구슬이 머무를 수 있는 트랙이다.

## 1. 근궤적 소개

**근궤적(root locus)**은 파라미터(보통 이득 $K$)가 $0$에서 $\infty$로 변할 때 가능한 모든 폐루프 극점 위치의 집합이다.

개루프 전달함수 $KG(s)H(s)$를 갖는 단위 귀환 시스템에서 특성 방정식(characteristic equation)은:

$$1 + KG(s)H(s) = 0$$

$$KG(s)H(s) = -1$$

이는 두 조건을 동시에 요구한다:
- **크기 조건(magnitude condition):** $|KG(s)H(s)| = 1$
- **각도 조건(angle condition):** $\angle G(s)H(s) = (2k+1) \times 180°$, $k = 0, \pm1, \pm2, \ldots$

근궤적은 각도 조건을 만족하는 모든 $s$로 이루어진다. 궤적 위의 임의 점에서의 이득 $K$는 크기 조건으로부터 구한다.

## 2. 근궤적 스케치 규칙

$G(s)H(s) = \frac{N(s)}{D(s)}$가 $n$개의 극점과 $m$개의 영점을 가진다고 하자 ($n \geq m$).

### 규칙 1: 시작점과 종점
- 궤적은 **개루프 극점**에서 **시작**한다 ($K = 0$)
- 궤적은 **개루프 영점**에서 **끝난다** ($K \to \infty$) (무한대에 있는 $n - m$개의 영점 포함)

### 규칙 2: 가지(Branch)의 개수
- 가지는 $n$개다(각 개루프 극점마다 하나)

### 규칙 3: 대칭성
- 근궤적은 **실수축에 대해 대칭**이다(복소 극점은 공액 쌍으로 등장)

### 규칙 4: 실수축 구간
- 실수축 위의 점이 근궤적 위에 있으려면 **그 오른쪽에 있는 실수 극점과 영점의 총 개수가 홀수**여야 한다

### 규칙 5: 점근선(Asymptote)
무한대로 가는 $n - m$개의 가지는 점근선에 접근한다:
- **각도:** $\theta_a = \frac{(2k+1) \times 180°}{n-m}$, $k = 0, 1, \ldots, n-m-1$
- **중심점(centroid)** (실수축 상의 교점): $\sigma_a = \frac{\sum p_i - \sum z_j}{n - m}$

### 규칙 6: 분기점(Breakaway / Break-in)
가지가 실수축을 떠나거나(breakaway) 진입하는(break-in) 점은 다음에서 구한다:

$$\frac{dK}{ds} = 0 \quad \text{여기서} \quad K = -\frac{1}{G(s)H(s)}$$

### 규칙 7: 출발각과 도착각
- 복소 극점 $p_i$로부터의 **출발각(departure angle)**: $\theta_d = 180° - \sum \angle(p_i - p_j) + \sum \angle(p_i - z_k)$ (다른 모든 극점과 영점에 대해 합산)
- 복소 영점 $z_i$로의 **도착각(arrival angle)**: $\theta_a = 180° + \sum \angle(z_i - p_j) - \sum \angle(z_i - z_k)$

### 규칙 8: 허수축 교차
$s = j\omega$를 특성 방정식에 대입하고 $\omega$와 $K$에 대해 푼다(또는 Routh 판별법으로 임계 $K$를 구한다).

### 2.1 규칙들이 어떻게 맞물리는가

규칙들은 무작위 체크리스트가 아니다. 실제로 스케치할 때 던지는 연속된 질문의 순서에 대응한다:

| 질문 | 규칙 |
|----------|------|
| 몇 개의 곡선을 그리는가? | 2 (가지 수 = $n$) |
| 어디서 시작하고 끝나는가? | 1 (극점 → 영점; 여분은 무한대) |
| 실수축 어디에 놓이는가? | 4 (홀수 카운트 규칙) |
| 어디로 떠나는가? | 5 (점근선 각도 + 중심점) |
| 실수축을 어디서 떠나는가? | 6 (분기점) |
| 복소 극점을 어떤 각도로 떠나는가? | 7 (출발각) |
| 우반평면으로 교차하는가? | 8 (jω 교차, Routh 도우미) |

이 순서대로 스케치하면 놓치는 일이 없다.

## 3. 근궤적 예제

**예제:** $G(s)H(s) = \frac{1}{s(s+1)(s+3)}$

- **극점:** $s = 0, -1, -3$ ($n = 3$, $m = 0$)
- **영점:** 유한 영점 없음 → 무한대에 3개

**규칙 적용:**

1. **가지:** 3개, $s = 0, -1, -3$에서 시작
2. **점근선:** $n - m = 3$
   - 각도: $60°, 180°, 300°$
   - 중심점: $\sigma_a = (0 + (-1) + (-3))/3 = -4/3$
3. **실수축 구간:** $(-\infty, -3)$와 $(-1, 0)$
4. **분기점:** $\frac{d}{ds}[s(s+1)(s+3)] = 0$ 풀이: $3s^2 + 8s + 3 = 0 \Rightarrow s = -0.451, -2.215$
   - $s = -0.451$은 궤적 위에 있음 ($-1$과 $0$ 사이) → 분기점
   - $s = -2.215$은 궤적 위에 없음
5. **허수축 교차:** $s^3 + 4s^2 + 3s + K = 0$에 Routh 적용: 임계 $K = 12$, $\omega = \sqrt{3}$

궤적은 실수축에서 벗어나는 세 가지를 보여준다 — $K$가 0에서 증가함에 따라, $K = 12$에서 시스템이 불안정해진다.

### 3.1 스케치 형태

이 레슨의 나머지를 읽기 위해 꼭 봐야 하는 손그림:

```
        jω
         │
         │ ┐  ← 60° 점근선을 따라 +∞로 가는 가지
         │/
      ───┼───────── 중심점 σ_a = -4/3
        /│
       / │─ 분기점 -0.451
  ────●──●──●───── σ  (세 개의 개루프 극점: -3, -1, 0)
       \ │
        \│
         │ ┘  ← 300° 점근선을 따라 -∞로 가는 가지
         │
         │  (세 번째 가지는 실수축을 따라 -∞로 달림)
```

$K = 0$에서 극점은 $\{0, -1, -3\}$에 있다(개루프). $K$가 올라가면 가장 오른쪽 두 극점이 실수축에서 서로 가까워지다 $s = -0.451$에서 만나고, 복소 쌍으로 축을 떠난다. 그 쌍은 $K = 12$에서 중심점을 지나며 우반평면으로 교차하여 폐루프를 불안정하게 만든다.

세 번째 가지는 실수축을 따라 $-\infty$로 향한다 — 항상 실수이고 항상 안정하다.

## 4. 극점과 영점 추가의 영향

### 4.1 극점 추가

개루프 극점을 추가하면:
- 근궤적을 **우반평면 쪽으로** 밀어낸다 (불안정화)
- 안정을 위한 $K$ 범위를 감소
- 무한대로 가는 가지가 하나 더 추가됨

### 4.2 영점 추가

개루프 영점을 추가하면:
- 근궤적을 **좌반평면 쪽으로** 당긴다 (안정화)
- 안정을 위한 $K$ 범위를 증가
- 궤적 가지의 종점을 제공

### 4.3 리드 및 래그 보상 예고

- **리드(Lead) 보상기** (극점 왼쪽의 영점): 근궤적을 왼쪽으로 구부림 → 과도 응답 개선
- **래그(Lag) 보상기** (원점 근처의 극점, 가까운 영점): 저주파 이득을 수정하되 근궤적 모양에 크게 영향 주지 않음 → 정상상태 오차 감소

레슨 10에서 완전히 다룬다.

## 5. 근궤적을 이용한 설계

### 5.1 이득 선택

원하는 폐루프 극점 위치 $s_d$에 도달하려면:

1. $s_d$가 근궤적 위에 있는지 확인(각도 조건 체크)
2. 크기 조건으로부터 $K$ 계산: $K = \frac{1}{|G(s_d)H(s_d)|}$
3. 다른 폐루프 극점들이 수용 가능한지 확인

### 5.2 사양에 맞는 설계

시간 영역 사양($t_s$, $M_p$ 등)이 주어지면:

1. 원하는 $\zeta$와 $\omega_n$ (또는 등가적으로 $\sigma$와 $\omega_d$)로 변환
2. $s$-평면에서 목표 영역 식별
3. 목표 영역의 점이 근궤적 위에 있으면 이득 선택
4. 없으면 보상(극점/영점)을 추가하여 궤적 재구성

### 5.3 예제: 이득 설계

$G(s) = \frac{K}{s(s+4)}$에서, $M_p \leq 20\%$와 $t_s \leq 2$ s로 설계.

**사양 → $s$-평면:**
- $M_p \leq 20\%$: $\zeta \geq 0.456$
- $t_s \leq 2$ s: $\sigma = \zeta\omega_n \geq 2$

근궤적은 $s = -2$에서의 수직선이다(실수축 중간에서의 분기). $\text{Re}(s) \leq -2$이고 $\zeta \geq 0.456$인 극점이 필요하다.

$s = -2 + j3.88$에서 ($\zeta = 0.456$ 만족): $K = |s(s+4)| = |(-2+j3.88)(-2+j3.88+4)| = 19.4$

### 5.4 파이썬으로 근궤적 플로팅

손그림은 모양을 주고, 파이썬 플롯은 정확한 이득과 극점 위치를 확인해 준다. `python-control` 사용:

```python
import numpy as np
import matplotlib.pyplot as plt
from control import TransferFunction, root_locus

# G(s) = 1 / [s(s+1)(s+3)] — 3절의 예제
G = TransferFunction([1], [1, 4, 3, 0])

gains = np.linspace(0, 30, 400)
root_locus(G, kvect=gains, plot=True)
plt.title("Root locus of 1 / [s(s+1)(s+3)]")
plt.xlabel("σ")
plt.ylabel("jω")
plt.grid(True)
plt.show()
```

3.1절의 스케치와 정확히 일치해야 한다: 세 개의 실수 극점에서 시작하는 가지, 두 개가 분기점에서 만나고, 복소 쌍이 위로 올라 $K = 12$ 근처에서 우반평면으로 들어간다. 플롯은 궤적 위에서 커서를 움직여 임의 점의 이득을 읽을 수 있게 해 주므로 — 손으로 크기 조건을 계산하기 지루할 때 매우 유용하다.

`python-control`을 쓸 수 없다면, `scipy`와 스윕으로 같은 일을 할 수 있다:

```python
gains = np.linspace(0, 30, 300)
loci = []
for K in gains:
    # 특성 다항식: s^3 + 4s^2 + 3s + K
    roots = np.roots([1, 4, 3, K])
    loci.append(roots)
loci = np.array(loci)

plt.figure(figsize=(6, 6))
for j in range(loci.shape[1]):
    plt.plot(loci[:, j].real, loci[:, j].imag, '.', markersize=2)
plt.axhline(0, color='gray', linewidth=0.5)
plt.axvline(0, color='gray', linewidth=0.5)
plt.xlabel("σ"); plt.ylabel("jω"); plt.title("Root locus (manual sweep)")
plt.grid(True); plt.axis('equal')
plt.show()
```

두 접근 모두 습관화할 가치가 있다 — 수작업 규칙은 궤적이 *왜* 움직이는지 알려주고, 플롯은 *정확히 어디로* 가는지 알려준다.

## 6. 음의 $K$에 대한 근궤적 (보완 근궤적)

$K$가 $-\infty$에서 $0$으로 변할 때, 각도 조건은:

$$\angle G(s)H(s) = 2k \times 180°$$

보완 근궤적(complementary root locus)은 약간 다른 규칙을 사용한다:
- 실수축 구간: 오른쪽의 극점과 영점의 총 개수가 **짝수**여야 함 (0 포함)
- 점근선 각도: $\theta_a = \frac{2k \times 180°}{n-m}$

양의 귀환 시스템에서 관련이 있다.

## 7. 흔한 함정(Common Pitfalls)

1. **"K = 0"과 "개루프 극점이 폐루프 극점이다"를 혼동.** $K = 0$에서 귀환이 사라지므로 폐루프는 개루프 극점을 상속한다. 이것은 궤적의 *시작점*이지 설계점이 아니다 — 루프를 연 채로 플랜트를 운전하지는 않는다.
2. **점근선 각도가 $(2k+1) \cdot 180° / (n-m)$라는 점을 잊음 ($360° / (n-m)$이 아님).** $n - m = 4$ 사례의 점근선은 $45°, 135°, 225°, 315°$이다 — $0°, 90°, 180°, 270°$가 아니다. 균등하게 간격을 두되 오프셋이 있다.
3. **중심점을 "극점이 중심점을 지나면 불안정해진다"로 읽음.** 중심점은 순수하게 점근선들의 산술적 교점일 뿐이다. 불안정성은 jω축 교차(규칙 8)로 결정되며, 중심점의 오른쪽일 수 있다.
4. **Breakaway = Breakpoint로 가정.** Breakaway는 가지가 실수축을 떠나는 점; break-in은 들어가는 점이다. 하나의 궤적이 이득 범위의 양쪽에 둘 다 가질 수 있다. 둘 다 $dK/ds = 0$에서 나오므로 — 후보가 실제로 실수축 구간 위에 있는지 확인한 뒤 받아들이자.
5. **출발각 오독.** 공식은 **다른** 극점과 영점들에 대한 각도의 합이다; 떠나는 극점 자체는 포함하지 않는다. 학생들이 실수로 포함시켜 $180°$ 어긋난 답을 내는 경우가 많다.
6. **플롯 범위가 잘린 수치 플롯을 절대적 진실로 받아들임.** `python-control`의 기본 축은 무한대로 가는 가지를 가릴 수 있다 — 항상 $K$를 넓게 스윕하고 실수축이 모든 개루프 극점과 점근선 중심점 너머까지 포함되는지 확인하라.

$G(s) = \frac{K(s+3)}{s(s+1)(s+5)}$에 대해:

1. 근궤적을 스케치하라
2. $s = -2$에 폐루프 극점을 놓는 $K$ 값을 구하라
3. 이 $K$에서의 모든 폐루프 극점을 구하라

### 연습 문제 3: 보상의 영향

$G(s) = \frac{K}{s(s+2)}$인 시스템. 보상기 영점을 다음 위치에 추가했을 때 근궤적을 비교하라:
1. $s = -1$ (극점들 사이)
2. $s = -5$ (두 극점의 왼쪽)

두 근궤적을 스케치하고 영점 위치가 달성 가능한 폐루프 극점 위치에 어떻게 영향을 주는지 논하라.

### 연습 문제 4: 파이썬으로 검증

5.4절의 파이썬 스니펫으로 연습 문제 1을 수치적으로 재현하라. 분기점과 jω축 교차가 손그림 값과 1% 이내로 일치함을 확인하라. 차이가 있는 경우, 오차가 손 계산에 있는지 플롯 범위 잘림에 있는지 식별하라.

### 연습 문제 5: 출발각 드릴

시스템의 개루프 극점이 $-1 \pm j2$와 $-4$, 영점이 $-2$에 있다. 위쪽 복소 극점에서의 출발각을 계산하라. 극점 근처의 궤적 방향을 스케치하고, 가지가 어느 방향(실수축을 향해 또는 멀어지며)으로 향하는지 설명하라.
