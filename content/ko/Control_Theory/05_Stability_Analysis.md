# 레슨 5: 안정성 분석(Stability Analysis)

## 학습 목표

- LTI 시스템에 대한 BIBO 안정성(BIBO stability)과 점근적 안정성(asymptotic stability)을 정의한다
- Routh-Hurwitz 판별법(Routh-Hurwitz criterion)을 사용하여 특성 다항식으로부터 안정성을 판정한다
- Routh 배열(Routh array)을 사용하여 안정성을 위한 파라미터 범위를 구한다
- 경계 안정(marginally stable) 시스템과 불안정(unstable) 시스템을 식별한다
- 극점 위치와 안정성의 관계를 이해한다
- 안정성 판정을 수치적으로 검증하고, Routh 판별법이 피하려는 함정을 인식한다

## 0. 동기 — `numpy.roots`가 있는데 왜 Routh인가?

2026년의 학생은 당연한 의문을 던진다: 파이썬의 세 줄짜리 호출로 어떤 다항식이든 인수분해할 수 있는데, 1875년에 발명된 표 알고리즘에 왜 여러 쪽을 할애하는가?

Routh 배열이 여전히 제 역할을 하는 세 가지 이유:

- **파라미터의 함수로서의 안정성.** 근 찾기는 "$K = 12$에서 극점은 …에 있다"를 말해 준다. Routh는 "이 시스템이 안정한 $K$의 범위는?"을 **한 번의 기호적 수행**으로 답해 준다. 이 매개변수적 질문이 제어 엔지니어가 가장 자주 묻는 것이며, 파이썬의 수치 근 찾기는 이에 직접 답하지 못한다.
- **해석적 통찰.** 3차 시스템에 대한 Routh 조건은 $a_2 a_1 > a_0$로 축약된다 — 냅킨에 적어서 기억하고 적용할 수 있는 관계다. 하나의 $K$에 대한 수치 답은 그런 직관을 주지 못한다.
- **기호 실수를 잡아낸다.** 특성 다항식을 손으로 유도할 때, 한 계수의 부호 오류가 안정성 결론을 뒤집는다. Routh의 필요조건(모든 계수가 같은 부호)은 10초짜리 sanity check — 수치 테스트를 셋업하는 것보다 훨씬 빠르다.

구체적 그림: 그릇 바닥에 놓인 공과 언덕 정상에 균형잡힌 공을 비교하자. 그릇은 안정(공을 밀면 돌아옴); 언덕 정상은 불안정. 좌반평면의 극점은 평형으로 감쇠하는 그릇 모양의 지수 함수; 우반평면의 극점은 달아나는 언덕 정상의 지수 함수. 허수축은 면도날 — 감쇠도 증가도 아닌 영원한 진동.

## 1. 안정성 개념

안정성은 모든 제어 시스템의 **가장 근본적인 요구사항**이다. 불안정 시스템은 잘해야 쓸모가 없고 최악의 경우 위험하다.

### 1.1 BIBO 안정성

시스템이 **유계 입력, 유계 출력(bounded-input, bounded-output, BIBO) 안정**이라 함은, 모든 유계 입력이 유계 출력을 만드는 것이다:

$$|u(t)| \leq M_u < \infty \quad \Rightarrow \quad |y(t)| \leq M_y < \infty$$

임펄스 응답 $g(t)$를 갖는 LTI 시스템에서, BIBO 안정성은 다음과 동치다:

$$\int_0^\infty |g(t)| \, dt < \infty$$

### 1.2 점근적 안정성(Asymptotic Stability)

시스템이 **점근적으로 안정(asymptotically stable)**이라 함은, 자유 응답(0 입력)이 0으로 감쇠하는 것이다:

$$\lim_{t \to \infty} y_{\text{free}}(t) = 0$$

### 1.3 극점 위치로부터의 안정성

LTI 시스템에서, 두 조건 모두 간단한 극점 테스트로 환원된다:

| 안정성 | 조건 |
|-----------|-----------|
| **점근적 안정** | 모든 극점이 개방 좌반평면(open LHP)에 있음: $\text{Re}(p_i) < 0 \; \forall i$ |
| **경계 안정** | RHP 극점 없음, 허수축에 단순 극점 하나 이상 |
| **불안정** | RHP 극점 하나 이상, 또는 허수축 중복 극점 |

폐루프 안정성을 위해 **특성 방정식(characteristic equation)**의 근을 분석한다:

$$1 + G(s)H(s) = 0 \quad \Leftrightarrow \quad \Delta(s) = 0$$

> **주의**: LTI 시스템의 입출력 쌍에서 BIBO 안정성과 점근적 안정성은 *불안정한 위치에서 극점-영점 소거가 없을 때에만* 동일하다. 영점에 의해 소거된 숨은 RHP 극점은 BIBO 테스트를 통과해도 여전히 내부 상태를 발산시킨다. 이것이 현대 분석이 전달함수가 아니라 **상태공간** $A$ 행렬의 극점을 확인하는 이유다 — 레슨 12에서 다룸.

## 2. Routh-Hurwitz 판별법

차수 $>2$ 다항식의 근을 찾는 것은 일반적으로 어렵다. Routh-Hurwitz 판별법은 **근을 계산하지 않고** 안정성을 판정한다.

### 2.1 필요조건

**정리:** $\Delta(s) = a_n s^n + \cdots + a_1 s + a_0$의 모든 근이 음의 실수부를 가질 **필요조건**은 모든 계수 $a_i > 0$이다 ($a_n > 0$ 가정).

계수 중 하나라도 0이거나 음수이면 시스템은 **불안정**하다. ($n \geq 3$에서 필요하지만 충분하지는 않음.)

### 2.2 Routh 배열 구성

특성 다항식이 주어지면:

$$\Delta(s) = a_n s^n + a_{n-1} s^{n-1} + a_{n-2} s^{n-2} + \cdots + a_0$$

Routh 배열을 구성한다:

| $s^n$ | $a_n$ | $a_{n-2}$ | $a_{n-4}$ | $\cdots$ |
|-------|-------|-----------|-----------|----------|
| $s^{n-1}$ | $a_{n-1}$ | $a_{n-3}$ | $a_{n-5}$ | $\cdots$ |
| $s^{n-2}$ | $b_1$ | $b_2$ | $b_3$ | $\cdots$ |
| $s^{n-3}$ | $c_1$ | $c_2$ | $c_3$ | $\cdots$ |
| $\vdots$ | | | | |
| $s^0$ | | | | |

여기서:

$$b_1 = \frac{a_{n-1}a_{n-2} - a_n a_{n-3}}{a_{n-1}}, \quad b_2 = \frac{a_{n-1}a_{n-4} - a_n a_{n-5}}{a_{n-1}}, \quad \ldots$$

$$c_1 = \frac{b_1 a_{n-3} - a_{n-1} b_2}{b_1}, \quad \ldots$$

### 2.3 Routh-Hurwitz 안정성 판별법

**정리 (Routh-Hurwitz):** 양의 실수부를 가진 $\Delta(s)$의 근의 개수는 Routh 배열 첫 열의 **부호 변화 횟수**와 같다.

**따름 정리:** 시스템이 안정할 필요충분조건은 **첫 열의 모든 항이 양수**인 것이다 ($a_n > 0$ 가정).

### 2.4 예제

$$\Delta(s) = s^4 + 2s^3 + 3s^2 + 4s + 5$$

Routh 배열:

| 행 | 열 1 | 열 2 | 열 3 |
|-----|-------|-------|-------|
| $s^4$ | $1$ | $3$ | $5$ |
| $s^3$ | $2$ | $4$ | $0$ |
| $s^2$ | $\frac{2 \cdot 3 - 1 \cdot 4}{2} = 1$ | $\frac{2 \cdot 5 - 1 \cdot 0}{2} = 5$ | |
| $s^1$ | $\frac{1 \cdot 4 - 2 \cdot 5}{1} = -6$ | | |
| $s^0$ | $5$ | | |

첫 열: $1, 2, 1, -6, 5$

부호 변화: $1 \to -6$과 $-6 \to 5$ → **2번의 부호 변화** → 2개의 RHP 근 → **불안정**.

### 2.5 배열 채우기 레시피, 기계적으로 서술

패턴을 보면 배열은 기계적이다. 각 새 행에 대해:

1. **바로 위 두 행**을 보자 (각각 "upper"와 "above-upper"로 부름).
2. 새 행의 각 열 $j$에 대해, 그 두 위 행의 열 $0$과 $j+1$로 이루어진 2×2 행렬식을 계산하고 피봇("upper"의 열 0)으로 나눈다:
   $$\text{new}_j = \frac{\text{upper}[0] \cdot \text{above-upper}[j+1] - \text{above-upper}[0] \cdot \text{upper}[j+1]}{\text{upper}[0]}$$
   분모에 "upper"가 오는 **같은 2×2 패턴**임에 주의.
3. 행이 비영점 열을 하나만 가질 때 멈춘다 (그것이 $s^0$ 행).

스프레드시트 스타일 연상법:

```
[above-upper]:   A  B  C
[upper]:         D  E  F
[new row]:      (D*B - A*E)/D   (D*C - A*F)/D   ...
```

"cross minus cross, divided by pivot D"의 2×2 패턴을 기억하면 공식을 다시 찾아볼 필요가 없다.

## 3. Routh 배열의 특수 경우

### 3.1 첫 열의 0

한 행의 첫 원소가 0이지만 (행 전체가 0은 아님) 행인 경우, 0을 작은 양수 $\epsilon > 0$으로 대체하고 계속 진행. 배열을 완성한 후 $\epsilon \to 0^+$에서의 부호를 검사한다.

**예제:** $\Delta(s) = s^3 + s^2 + 2s + 2$

| $s^3$ | $1$ | $2$ |
| $s^2$ | $1$ | $2$ |
| $s^1$ | $\frac{1\cdot 2 - 1\cdot 2}{1} = 0 \to \epsilon$ | |
| $s^0$ | $2$ | |

첫 열: $1, 1, \epsilon, 2$ — $\epsilon \to 0^+$에서 부호 변화 없음 → 안정?

실제로 0인 행은 **허수축 근**을 나타낸다: $\Delta(s) = (s^2+2)(s+1)$이므로 극점이 $s = \pm j\sqrt{2}$ → **경계 안정**, 점근적 안정이 아님.

### 3.2 행 전체가 0

한 행 전체가 0이 되면 특성 다항식에 **대칭 근 쌍**(서로의 음수인 근: $\pm\sigma$, $\pm j\omega$, 또는 $\pm\sigma \pm j\omega$)이 있음을 나타낸다.

**절차:**
1. 0인 행 **위 행**으로부터 **보조 다항식(auxiliary polynomial)** $P(s)$를 구성
2. 0인 행을 $\frac{dP}{ds}$의 계수로 대체
3. Routh 배열을 계속 진행

$P(s)$의 근은 대칭 근 쌍이며 허수축 근을 포함한다.

### 3.3 $\epsilon$ 트릭이 작동하는 이유

$\epsilon \to 0^+$ 대입은 꼼수가 아니라 극한 논법이다. Routh 조건은 피봇이 0인 특이점 바로 거기를 제외하면 다항식 계수에 대해 연속이다. 작은 양수 $\epsilon$로 섭동하면 특이 궤적에서 머리카락만큼 떨어지게 되고, 개수는 유효하게 유지되며, 극한이 올바른 부호 패턴을 복구한다.

부호 패턴이 $\epsilon \to 0^+$와 $\epsilon \to 0^-$에서 **다르다면** 경계 안정 시스템을 가진 것이다 — 다항식이 정확히 허수축 위에 근을 가진다. 이것이 3.1절이 암묵적으로 포착한 신호다.

## 4. Routh-Hurwitz를 이용한 안정성 범위

가장 강력한 응용: 시스템이 안정한 파라미터(보통 이득 $K$)의 범위를 찾기.

### 4.1 예제: $K$의 안정성 범위 찾기

$G(s) = \frac{K}{s(s+1)(s+5)}$인 단위 귀환 시스템.

특성 방정식: $s^3 + 6s^2 + 5s + K = 0$

Routh 배열:

| $s^3$ | $1$ | $5$ |
| $s^2$ | $6$ | $K$ |
| $s^1$ | $\frac{30 - K}{6}$ | |
| $s^0$ | $K$ | |

안정을 위해 첫 열의 모든 항이 양수:
- $6 > 0$ ✓
- $\frac{30-K}{6} > 0 \Rightarrow K < 30$
- $K > 0$

**안정성 범위:** $0 < K < 30$.

$K = 30$에서: $s^1$ 행이 0이 됨 → 지속 진동을 갖는 **경계 안정**. $s^2$ 행으로부터의 보조 다항식: $6s^2 + 30 = 0 \Rightarrow s = \pm j\sqrt{5}$. 진동 주파수 $\omega = \sqrt{5}$ rad/s.

### 4.2 파이썬으로 검증

위의 기호 답은 "$0 < K < 30$에서 안정"을 말한다. 20줄 남짓의 수치 스윕이 이를 확인하고 확신을 심어 준다:

```python
import numpy as np

def is_stable(K):
    # 특성 다항식: s^3 + 6s^2 + 5s + K
    roots = np.roots([1, 6, 5, K])
    return np.all(roots.real < 0)

for K in [0.1, 10, 20, 29, 30, 30.01, 100]:
    print(f"K = {K:>7.2f}  stable = {is_stable(K)}")
```

예상 출력:

```
K =    0.10  stable = True
K =   10.00  stable = True
K =   20.00  stable = True
K =   29.00  stable = True
K =   30.00  stable = False   # ← 정확히 경계
K =   30.01  stable = False
K =  100.00  stable = False
```

`K = 30`이 `False`로 보고됨에 주목: 경계에서 `numpy.roots`가 부동소수점 잡음 때문에 아주 작지만 0이 아닌 실수부를 가진 극점을 계산한다. 여기서 Routh 분석이 진실 — 시스템은 경계 안정이다($\omega = \sqrt{5}$에서 순수 진동), 점근적 의미로 "안정"도 아니고 RHP-불안정도 아니다. 이 불일치는 기호 방법을 알아둘 가치가 있는 이유다: 수치 도구는 경계를 흐리지만, Routh는 딱 잡는다.

## 5. Hurwitz 행렬식 (대안 형식)

Hurwitz 판별법은 같은 정보를 행렬식으로 제공한다. $a_n > 0$인 $\Delta(s) = a_n s^n + \cdots + a_0$에서, 모든 근이 음의 실수부를 가질 필요충분조건은 **Hurwitz 행렬식**이 모두 양수인 것이다:

$$D_1 = a_{n-1} > 0$$

$$D_2 = \begin{vmatrix} a_{n-1} & a_n \\ a_{n-3} & a_{n-2} \end{vmatrix} > 0$$

$$D_3 = \begin{vmatrix} a_{n-1} & a_n & 0 \\ a_{n-3} & a_{n-2} & a_{n-1} \\ a_{n-5} & a_{n-4} & a_{n-3} \end{vmatrix} > 0$$

저차 시스템에서는 전체 Routh 배열보다 간단할 수 있다.

### 5.1 특수 경우

**2차** $s^2 + a_1 s + a_0$: $a_1 > 0$이고 $a_0 > 0$일 필요충분조건.

**3차** $s^3 + a_2 s^2 + a_1 s + a_0$: $a_2 > 0$, $a_0 > 0$, $a_2 a_1 > a_0$일 필요충분조건.

### 5.2 물리적 예제: 스프링-질량-댐퍼

$m\ddot{x} + b\dot{x} + kx = F$의 특성 다항식은 $ms^2 + bs + k$, 즉 $a_1 = b/m$, $a_0 = k/m$인 2차 형태.

Routh / Hurwitz는 $b > 0$이고 $k > 0$일 때 안정이라 말한다. 물리적 파라미터로 번역하면:

- $k > 0$은 스프링이 되돌리는 것을 의미(양의 복원력). $k = 0$ 스프링은 자유 질량; $k < 0$은 반발력(선형화 전의 역진자) — 둘 다 불안정.
- $b > 0$은 댐퍼가 에너지를 소산하는 것을 의미. $b = 0$은 무손실 진동자(허수축 극점, 경계 안정); $b < 0$은 에너지를 주입하는 댐퍼 — 불안정.

그래서 Routh 조건은 물리 직관과 정확히 대응된다: 복원력 AND 에너지 소산이 필요하다. 수학은 이 직관을 기록하는 장부일 뿐이다.

## 6. 상대 안정성(Relative Stability)

Routh 판별법은 극점이 LHP에 있는지만 말해 준다. **상대 안정성** — 극점이 허수축으로부터 얼마나 멀리 있는지 — 를 위해서는 이동 변수(shifted variable)를 사용할 수 있다.

**방법:** 모든 극점이 $\text{Re}(p_i) < -\sigma_0$를 만족하는지 판정하려면, $\Delta(s)$에 $s = \hat{s} - \sigma_0$을 대입하고 새 다항식($\hat{s}$에 대한)에 Routh를 적용한다.

이동된 Routh 배열 첫 열의 모든 항이 양수면 모든 원래 극점이 $\text{Re}(p_i) < -\sigma_0$을 만족한다.

> 중요한 이유: 모든 극점이 LHP 안쪽 아슬아슬한 곳에 있는 시스템은 "기술적으로 안정"하지만 정착 시간이 매우 길고 잡음을 증폭한다. 공학 규칙은 보통 명시적 $\sigma_0$에 대해 $\text{Re}(p_i) < -\sigma_0$을 요구한다 — 느린 공정에서는 0.5 또는 1.0, 서보에서는 5–10.

## 7. 흔한 함정(Common Pitfalls)

1. **필요조건을 충분조건으로 사용.** "모든 계수가 양수이므로 안정"은 $n \geq 3$에서 틀리다. 빠른 첫 점검일 뿐, 전체 Routh 배열을 완성해야 한다.
2. **Routh 테스트가 $a_n > 0$을 가정함을 잊음.** 주 계수가 음수이면 먼저 다항식에 $-1$을 곱하라. 생략하면 모든 부호 변화 개수가 뒤집힌다.
3. **0인 행을 "부호 변화가 없으므로 안정"으로 오독.** 0인 행은 허수축 근 — 경계 안정, 점근적 안정이 아님 — 을 의미한다. 항상 보조 다항식 절차를 적용하라.
4. **$K$ 범위에 대한 Routh 혼동.** 학생들이 "$K > 0$"만 유도하고 멈추기 쉽다. $K$가 음의 부호로 들어가는 행에서 오는 상한을 잊는다. $K$의 함수로서 **모든** 첫 열 항을 확인하라.
5. **경계에서 수치 근 찾기를 과신.** 4.2절에서 보였듯, 경계 안정 근처의 부동소수점 오차는 오해를 사는 "불안정" 판정을 내린다. 경계 질문에는 Routh를 쓰자.
6. **극점-영점 소거에 의한 숨은 불안정.** 전달함수 Routh 테스트는 같은 RHP 위치의 영점에 의해 소거된 극점을 볼 수 없다. 상태공간 고유값 테스트(레슨 12)만이 유일하게 안전한 보장 — 안전-중요 시스템은 이에 의존하라.

## 연습 문제

### 연습 문제 1: Routh-Hurwitz 적용

다음 특성 다항식을 갖는 시스템의 안정성을 Routh-Hurwitz 판별법으로 판정하라:

1. $s^4 + 3s^3 + 5s^2 + 4s + 2$
2. $s^4 + s^3 + 2s^2 + 2s + 1$
3. $s^5 + 2s^4 + 3s^3 + 6s^2 + 2s + 1$

### 연습 문제 2: 이득 범위

$G(s) = \frac{K(s+2)}{s(s+1)(s+3)(s+4)}$인 단위 귀환 시스템.

1. 안정을 위한 $K > 0$의 범위를 결정하라
2. 임계 $K$ 값에서 진동 주파수를 구하라

### 연습 문제 3: 상대 안정성

특성 다항식 $s^3 + 10s^2 + 31s + 30$에 대해:

1. 시스템이 안정함을 확인하라
2. 모든 극점이 $\text{Re}(p_i) < -1$을 만족하는지 판정하라
3. 실제 극점을 구하고 파트 1, 2의 답을 검증하라

### 연습 문제 4: 수치 스윕

4.1절 시스템에 대해 $K$를 $-5$에서 $50$까지 0.1 간격으로 스윕하고, $K$의 함수로 가장 오른쪽 극점의 실수부를 플로팅하는 작은 파이썬 스크립트를 작성하라. 곡선이 0을 지나는 임계 $K$를 표시하라. Routh 예측과 비교하라.

### 연습 문제 5: 숨은 RHP 극점

분모에 대한 Routh 테스트로는 안정해 보이지만, 같은 위치의 영점에 의해 소거된 숨은 RHP 극점을 가진 폐루프 전달함수를 구성하라. 상태에 (입력을 우회하여) 작은 외란을 직접 가하고, BIBO 안정 전달함수에도 불구하고 출력이 발산함을 관찰하여 결과를 보여라.
