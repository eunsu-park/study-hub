# 레슨 7: 주파수 응답 — 보드 선도(Bode Plots)

## 학습 목표

- LTI 시스템의 주파수 응답(Frequency Response) 개념 이해
- 전달함수로부터 보드 크기 및 위상 선도(Bode magnitude/phase plot) 작성
- 빠른 스케치를 위한 점근 근사 사용
- 보드 선도에서 이득 여유와 위상 여유 읽기
- 시스템 성능 평가에 주파수 영역 사양 적용
- 보드 다이어그램을 수치적으로 그리고 문제를 알리는 시각적 단서 인식

## 0. 주파수 영역이 자체 레슨을 갖는 이유

시간 영역 분석(레슨 4)은 계단 응답이 어떻게 보이는지 알려준다. 주파수 영역 분석은 모든 사인파가 무엇을 하는지 한 번에 알려준다. 이것이 실제 공학에서 지배적 관점인 세 가지 이유:

- **실제 외란은 계단이 아니다.** 바람 돌풍, 노면 요철, 전자기 간섭 — 어느 것도 깨끗한 계단이 아니다. 모두 사인파의 합이다. 주파수 응답은 어느 사인파를 루프가 감쇠하고 어느 것을 증폭하는지 직접 보여준다.
- **여유가 차트에 그대로 있다.** 위상 여유와 이득 여유 — "이 루프가 얼마나 강건한가?"를 한 줄로 요약하는 두 숫자 — 가 보드 선도에서 한눈에 읽힌다. 시간 영역 분석은 이를 숨긴다.
- **합성이 덧셈이다.** 두 시스템을 직렬로 연결하면 크기 선도가 (dB 단위로) 더해지고 위상 선도가 더해진다. 곱셈도 합성곱도 없다. 이 단일 성질이 1930년대 Bode가 log-log 축을 선택한 이유이며 모두가 여전히 사용하는 이유다.

머릿속 그림: 보드 선도는 시스템에 대한 DJ 믹서의 EQ다. 모든 주파수 손잡이는 그 주파수가 더 크게, 더 작게, 또는 시간 이동되어 나오는지 보여준다.

## 1. 주파수 응답 개념

**주파수 응답**은 시스템이 다양한 주파수의 사인 입력에 어떻게 반응하는지 기술한다.

전달함수 $G(s)$를 가진 안정 LTI 시스템의 입력이:

$$u(t) = A\sin(\omega t)$$

이면 정상 상태 출력은:

$$y_{ss}(t) = A|G(j\omega)|\sin(\omega t + \angle G(j\omega))$$

시스템은 진폭을 $|G(j\omega)|$만큼 **스케일**하고 위상을 $\angle G(j\omega)$만큼 **이동**시킨다.

### 1.1 주파수 응답 함수

$$G(j\omega) = |G(j\omega)| e^{j\angle G(j\omega)}$$

- **크기:** $|G(j\omega)| = \sqrt{[\text{Re}(G(j\omega))]^2 + [\text{Im}(G(j\omega))]^2}$
- **위상:** $\angle G(j\omega) = \tan^{-1}\frac{\text{Im}(G(j\omega))}{\text{Re}(G(j\omega))}$

## 2. 보드 선도 기초

**보드 선도(Bode plot)**는 두 그래프로 구성:
1. **크기 선도(magnitude plot)**: $20\log_{10}|G(j\omega)|$ (dB) vs. $\log_{10}\omega$
2. **위상 선도(phase plot)**: $\angle G(j\omega)$ (도) vs. $\log_{10}\omega$

### 2.1 로그 선도의 장점

- 전달함수의 곱은 개별 보드 선도의 **합**이 된다
- 거듭제곱은 **곱셈**이 됨: $|G^n| \text{ dB} = n \times |G| \text{ dB}$
- 직선 점근 근사가 그리기 쉬움
- 넓은 주파수 범위(decades) 커버

### 2.2 데시벨 척도

$$|G|_{\text{dB}} = 20\log_{10}|G(j\omega)|$$

| 선형 | dB |
|--------|-----|
| $1$ | $0$ dB |
| $2$ | $6$ dB |
| $10$ | $20$ dB |
| $100$ | $40$ dB |
| $0.1$ | $-20$ dB |
| $0.01$ | $-40$ dB |

## 3. 기본 요소의 보드 선도

임의의 전달함수는 기본 요소로 분해 가능:

$$G(s) = \frac{K \prod(1 + s/z_i) \prod(1 + 2\zeta_k s/\omega_{n_k} + s^2/\omega_{n_k}^2)}{s^N \prod(1 + s/p_j) \prod(1 + 2\zeta_l s/\omega_{n_l} + s^2/\omega_{n_l}^2)}$$

### 3.1 상수 이득 $K$

- 크기: $20\log_{10}|K|$ dB (수평선)
- 위상: $K > 0$이면 $0°$, $K < 0$이면 $-180°$

### 3.2 적분기/미분기 $s^{\pm N}$

**적분기** $1/s$:
- 크기: $-20$ dB/decade ($\omega = 1$에서 0 dB를 통과하는 직선)
- 위상: $-90°$ (상수)

**이중 적분기** $1/s^2$:
- 크기: $-40$ dB/decade
- 위상: $-180°$

### 3.3 1차 인수 $(1 + s/\omega_0)^{\pm 1}$

**1차 영점** $(1 + s/\omega_0)$:

| 주파수 | 크기 점근선 | 위상 |
|-----------|-------------------|-------|
| $\omega \ll \omega_0$ | $0$ dB | $0°$ |
| $\omega = \omega_0$ | $+3$ dB | $+45°$ |
| $\omega \gg \omega_0$ | $+20$ dB/decade | $+90°$ |

- **코너(브레이크) 주파수:** $\omega_0$
- 위상 전환: $0.1\omega_0$에서 $10\omega_0$까지

**1차 극점** $1/(1 + s/\omega_0)$: 크기와 위상은 영점의 음수.

### 3.4 2차 인수

**부족 제동 이차** $\frac{1}{1 + 2\zeta s/\omega_n + s^2/\omega_n^2}$:

| 주파수 | 크기 점근선 | 위상 |
|-----------|-------------------|-------|
| $\omega \ll \omega_n$ | $0$ dB | $0°$ |
| $\omega = \omega_n$ | $-20\log_{10}(2\zeta)$ dB (공진 피크) | $-90°$ |
| $\omega \gg \omega_n$ | $-40$ dB/decade | $-180°$ |

공진 피크 높이는 $\zeta$에 의존:
- $\zeta = 0.1$: $+14$ dB 피크
- $\zeta = 0.3$: $+5.7$ dB 피크
- $\zeta = 0.707$: $0$ dB (피크 없음, $\omega_n$에서 $-3$ dB)
- $\zeta \geq 0.707$: 공진 피크 없음

**공진 주파수:** $\omega_r = \omega_n\sqrt{1 - 2\zeta^2}$ ($\zeta < 1/\sqrt{2}$일 때)

**공진 피크 크기:** $M_r = \frac{1}{2\zeta\sqrt{1-\zeta^2}}$

## 4. 합성 보드 선도 작성

### 4.1 절차

1. $G(s)$를 **시상수 형태**로 다시 쓰기: 각 항이 $(1 + s/\omega_i)$ 또는 $(1 + 2\zeta s/\omega_n + s^2/\omega_n^2)$가 되도록 상수를 인수분해
2. 모든 코너 주파수 식별 및 정렬
3. 각 요소의 기여도를 별도로 그리기
4. 모든 크기 기여도 **더하기** (dB 덧셈)
5. 모든 위상 기여도 **더하기**

### 4.2 예제

$$G(s) = \frac{100(s+1)}{s(s+10)} = \frac{10(1+s)}{s(1+s/10)}$$

DC 이득 정규화 (적분기 인수분해 후 $\omega \to 0$ 평가): $\omega = 1$에서 크기는 $10/\omega = 10$ → $20$ dB.

**요소들:**
- 이득 $10$: $+20$ dB
- 적분기 $1/s$: $-20$ dB/dec, $\omega = 1$에서 $0$ dB 통과
- $\omega = 1$의 영점: 위로 break
- $\omega = 10$의 극점: 아래로 break

**점근 크기:**
- $\omega < 1$: 기울기 $-20$ dB/dec (적분기만)
- $1 < \omega < 10$: 기울기 $0$ dB/dec (적분기 + 영점이 상쇄)
- $\omega > 10$: 기울기 $-20$ dB/dec (적분기 + 영점 + 극점)

**위상:**
- $\omega \to 0$: $-90°$ (적분기) + $0°$ + $0°$ = $-90°$
- $\omega = 1$: $-90°$ + $45°$ + $(-5.7°)$ ≈ $-51°$
- $\omega = 10$: $-90°$ + $84.3°$ + $(-45°)$ ≈ $-51°$
- $\omega \to \infty$: $-90°$ + $90°$ + $(-90°)$ = $-90°$

### 4.3 파이썬으로 그리기

몇 줄로 점근 스케치를 확인하고 정확한 곡선을 생성:

```python
import numpy as np
import matplotlib.pyplot as plt
from control import TransferFunction, bode_plot

# G(s) = 100(s+1) / [s(s+10)]
G = TransferFunction([100, 100], [1, 10, 0])

omega = np.logspace(-2, 3, 500)
mag, phase, _ = bode_plot(G, omega=omega, dB=True, plot=True)
plt.show()
```

4.2절의 점근 기울기는 코너 주파수에서 실제 곡선과 ±3 dB 이내로 일치해야 한다. 손그림과 플롯이 어디에서 6 dB 이상 다르면 가장 흔한 원인은 적분기 카운트 오류(각각이 점근선을 20 dB/decade씩 아래로 이동)이다.

## 5. 보드 선도의 안정도 여유

### 5.1 이득 여유 (GM)

**이득 여유**는 시스템이 불안정해지기 전 이득을 증가시킬 수 있는 양 (dB):

$$GM = -20\log_{10}|G(j\omega_{pc})| \quad \text{dB}$$

여기서 $\omega_{pc}$는 **위상 교차 주파수** ($\angle G(j\omega) = -180°$인 곳).

**해석:** 이득 여유는 $-180°$ 위상 교차에서 루프 이득이 0 dB에 도달하기 전 $K$를 몇 dB 늘릴 수 있는지를 알려준다.

### 5.2 위상 여유 (PM)

**위상 여유**는 이득 교차에서 $-180°$에 도달하기 위해 필요한 추가 위상 지연:

$$PM = 180° + \angle G(j\omega_{gc})$$

여기서 $\omega_{gc}$는 **이득 교차 주파수** ($|G(j\omega)| = 0$ dB, 즉 단위 이득인 곳).

### 5.3 여유로부터의 안정성

| 조건 | 안정? |
|-----------|---------|
| $GM > 0$ dB 그리고 $PM > 0°$ | 예 |
| $GM < 0$ dB 또는 $PM < 0°$ | 아니오 |
| $GM = 0$ dB 또는 $PM = 0°$ | 경계 안정 |

**전형적 설계 목표:**
- $GM \geq 6$ dB (2배 이득 허용)
- $PM \geq 30°$ ~ $60°$
- $PM \approx 60°$가 $\zeta \approx 0.6$을 줌 (속도와 제동의 좋은 균형)

### 5.4 위상 여유와 제동의 관계

2차 시스템에서, 위상 여유와 제동비는 근사적으로:

$$PM \approx 100\zeta \quad \text{도 (}\zeta < 0.7\text{인 경우)}$$

더 정확하게: $PM < 70°$일 때 $\zeta \approx PM/100$.

### 5.5 여유를 수치로 읽기

```python
from control import margin

gm, pm, wpc, wgc = margin(G)
print(f"GM = {20*np.log10(gm):.1f} dB at wpc = {wpc:.2f} rad/s")
print(f"PM = {pm:.1f} deg     at wgc = {wgc:.2f} rad/s")
```

`gm`은 크기 비율(선형)로 반환되므로 dB 변환은 명시적이다. 흔한 버그: $20\log_{10}$를 먼저 적용하지 않고 `gm`을 "6 dB"와 비교 — `gm = 2.0` 선형은 6 dB; 2.0을 이미-dB로 다루면 4배 과다 허용.

## 6. 주파수 영역 사양

| 사양 | 기호 | 의미 |
|--------------|--------|---------|
| **대역폭(Bandwidth)** | $\omega_{BW}$ | $|T(j\omega)|$가 $-3$ dB로 떨어지는 주파수 |
| **공진 피크(Resonant peak)** | $M_r$ | $|T(j\omega)|$의 최댓값 |
| **이득 교차 주파수** | $\omega_{gc}$ | 폐루프 대역폭 근사 |

**시간 영역과의 연결:**
- 더 큰 $\omega_{BW}$ → 빠른 응답 (더 작은 $t_r$)
- 더 큰 $M_r$ → 더 큰 오버슈트
- 2차 시스템: $\omega_{BW} \approx \omega_n\sqrt{(1-2\zeta^2) + \sqrt{4\zeta^4 - 4\zeta^2 + 2}}$

> **설계자 단축식**: 2차 우세 시스템에 대해 $\omega_{BW} \approx 1.5 \cdot \omega_{gc}$가 유용한 경험 법칙. 100 rad/s 대역폭이 필요하면 65-70 rad/s 근처에서 교차하도록 설계.

## 7. 흔한 함정

1. **$\omega_{gc}$와 $\omega_n$ 혼동.** 이득 교차와 고유 진동수는 보통 2배 이내이지만 같지 않다. PM-제동 규칙 $PM \approx 100\zeta$는 교차에서의 관계를 사용하지 $\omega_n$에서가 아니다.
2. **개루프 또는 폐루프에서 우연히 여유 읽기.** GM과 PM은 Nyquist 또는 Bode 선도 위 개루프 $G(s)$의 성질이다. 폐루프 전달함수 $T = G/(1+G)$를 그리고 거기서 "위상 여유"를 읽는 것은 무의미하다 — 그 그래프는 여유 개념이 없다.
3. **점근 기울기가 20 dB/decade씩 어긋남.** 가장 흔한 스케치 오류는 적분기가 다른 코너 이전, 저주파에서 이미 $-20$ dB/decade를 준다는 것을 잊는 것이다. 항상 $\omega \to 0$에서 스케치를 시작하고 각 코너가 20 dB/decade씩 더하거나 빼는 것을 추적하라.
4. **위상 점근선 vs. 정확한 위상.** 점근 위상은 코너에서 $0° / -90°$로 "즉시" 변하지만, 실제 위상은 한 decade에 걸쳐 부드럽게 변한다. 빡빡한 여유 작업에서는 점근선이 아니라 수치 플롯을 사용하라.
5. **우반평면 영점과 극점 간과.** 비최소-위상 영점은 최소-위상 영점과 같은 크기를 기여하지만 **반대 위상**($-90°$ 대신 $+90°$)이다. 모든 영점이 최소-위상이라 가정하는 스케치는 위상 여유를 크게 잘못 계산한다.
6. **Bode와 Nyquist를 다른 세계로 취급.** 같은 $G(j\omega)$가 둘 다 만든다. Nyquist 선도의 회전 카운트는 Bode 크기/위상이 인코딩하는 바로 그것이다 — 관점 사이의 전환은 단지 다른 매개변수화일 뿐이다.
