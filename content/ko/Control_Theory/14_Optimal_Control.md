## 학습 목표

- 선형 이차 조절기(Linear-Quadratic Regulator, LQR) 문제를 수식으로 정형화한다
- 대수 Riccati 방정식(algebraic Riccati equation, ARE)을 풀어 최적 이득을 구한다
- 잡음이 있는 환경에서 상태 추정을 위한 칼만 필터를 설계한다
- LQR과 칼만 필터를 결합하여 LQG 제어기를 구성한다
- LQR의 강건성 성질과 LQG의 한계를 이해한다
- `scipy.linalg.solve_continuous_are`로 LQR/Kalman 문제를 수치적으로 푼다

## 0. "최적"이 자체 레슨을 갖는 이유

극점 배치(레슨 13)는 폐루프 극점을 어디든 둘 수 있게 해 준다 — 그러나 _어디에_ 두어야 하는지는 알려주지 않는다. 최적 제어는 질문을 뒤집는다: 극점 위치를 추측하는 대신, 신경 쓰는 것을 포착하는 비용을 정의하고, 그것을 최소화하는 이득을 수학이 고르게 하라.

LQR/Kalman이 현대 제어 실무를 지배하는 세 가지 이유:

- **하나의 스칼라 튜닝 손잡이 (Q vs R).** 6 상태 시스템은 6 개의 폐루프 극점을 가지지만, LQR은 설계 선택을 $Q$ 대 $R$의 비율로 "얼마나 공격적인가"로 줄인다. 극점 배치는 6 개의 숫자를 고르도록 요구한다; LQR은 한 줌의 가중치로 모두 고른다.
- **LQR 측의 무료 강건성.** 결과는 자동으로 안정이고 이득 여유 $[1/2, \infty)$, 위상 여유 $\geq 60°$를 가진다. 어떤 극점-배치 설계도 이 보장을 무료로 제공하지 않는다.
- **상태 추정이 쌍대성으로 따라온다.** 칼만 필터는 LQR의 거울 쌍둥이 — $A \to A^T$, $B \to C^T$ 등을 갖는 같은 Riccati 방정식. 한 문제를 배우면 다른 문제도 얻는다.

머릿속 그림: $J = \int (x^T Q x + u^T R u)\,dt$는 "제어기가 끝난 후 내가 얼마나 불행할 것인가?" — 제어기는 $Q$와 $R$ 선택으로 가중된 미래의 불행을 최소화한다.

## 1. 최적 제어의 동기

극점 배치는 폐루프 극점 위치를 자유롭게 선택할 수 있게 하지만, **어떤** 극점 위치가 가장 좋은지는 말해 주지 않는다. 최적 제어는 체계적인 틀을 제공한다:

- 추적 오차와 제어 노력을 벌하는 **비용 함수(cost function)**를 정의
- 비용을 **최소화**하는 제어 법칙을 찾기
- 결과는 원리적으로 성능과 노력의 균형을 잡는다

## 2. 선형 이차 조절기 (LQR)

### 2.1 문제 정형화

**플랜트:** $\dot{x} = Ax + Bu$

**비용 함수:**

$$J = \int_0^\infty \left[ x^T(t) Q x(t) + u^T(t) R u(t) \right] dt$$

여기서:
- $Q \geq 0$ (양 반정치, positive semidefinite): **상태 가중 행렬** — 상태 편차를 벌함
- $R > 0$ (양정치, positive definite): **제어 가중 행렬** — 제어 노력을 벌함

**목표:** $J$를 최소화하는 $u(t)$를 찾기.

### 2.2 최적 해

**정리:** $(A, B)$가 가제어(또는 안정화 가능, stabilizable)이고 $(A, Q^{1/2})$가 가관측(또는 검출 가능, detectable)이면, 최적 제어 법칙은:

$$u^*(t) = -Kx(t), \quad K = R^{-1}B^T P$$

여기서 $P$는 **대수 Riccati 방정식(ARE)**의 유일한 양정치 해:

$$A^T P + PA - PBR^{-1}B^T P + Q = 0$$

### 2.3 LQR의 성질

**보장된 안정성:** 폐루프 시스템 $\dot{x} = (A - BK)x$는 항상 점근적 안정.

**보장된 강건성 (SISO):**
- **이득 여유:** $[1/2, \infty)$ — 이득을 절반으로 줄이거나 무한대로 늘려도 시스템은 안정
- **위상 여유:** $\geq 60°$

이는 놀라운 보장이다 — 다른 어떤 선형 설계 방법도 자동으로 이런 강한 여유를 제공하지 않는다.

### 2.4 $Q$와 $R$ 튜닝

**물리적 해석:**
- 큰 $Q_{ii}$: $x_i$를 적극적으로 0으로 끌고 감(빠른 응답)
- 큰 $R_{jj}$: 채널 $j$의 큰 제어 입력을 벌함(작은 제어 노력)
- $Q/R$ 비율: 성능과 제어 노력의 절충

**일반적 선택:**
- $Q = \text{diag}(q_1, \ldots, q_n)$, $R = \rho I$ — 단일 파라미터 $\rho$가 절충을 튜닝
- **Bryson 규칙:** $Q_{ii} = 1/x_{i,\max}^2$, $R_{jj} = 1/u_{j,\max}^2$ — 최대 허용 값으로 정규화

### 2.5 예제

이중 적분기: $A = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}$, $B = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$

$Q = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}$, $R = [1]$:

ARE 풀이로 $P = \begin{bmatrix} \sqrt{3} & 1 \\ 1 & \sqrt{3} \end{bmatrix}$

$$K = R^{-1}B^T P = \begin{bmatrix} 1 & \sqrt{3} \end{bmatrix}$$

폐루프 극점: $s = -\frac{\sqrt{3}}{2} \pm j\frac{1}{2}$ → $\omega_n = 1$, $\zeta = \frac{\sqrt{3}}{2} \approx 0.87$.

$Q_{11}$ 증가 → 빠른 응답, 더 많은 제어 노력. $R$ 증가 → 느리고 부드러운 응답.

### 2.6 파이썬으로 ARE 풀기

ARE는 이차 행렬 방정식; $n > 2$에 대해 손으로 풀기는 고통스럽고 기호적 해는 거의 단순화되지 않는다. SciPy의 `solve_continuous_are`가 정답이다:

```python
import numpy as np
from scipy.linalg import solve_continuous_are

A = np.array([[0, 1], [0, 0]], dtype=float)
B = np.array([[0], [1]], dtype=float)
Q = np.diag([1.0, 0.0])
R = np.array([[1.0]])

P = solve_continuous_are(A, B, Q, R)
K = np.linalg.inv(R) @ B.T @ P
print("P =\n", P)
print("K =", K)

# 폐루프 극점
A_cl = A - B @ K
print("closed-loop eigenvalues =", np.linalg.eigvals(A_cl))
```

위 이중 적분기에 대해 $K \approx [1.0, 1.732]$와 $-0.866 \pm 0.5j$의 고유값을 봐야 한다 — 해석적 결과와 일치.

$Q$ 대 $R$을 스윕하려면 한 가중치를 변화시키며 루프에서 다시 풀자. 폐루프 극점이 $s$-평면에서 곡선을 그린다 — 근궤적이 주는 같은 종류의 통찰이지만, 개루프 이득 대신 비용 비율로 매개변수화된다.

## 3. 칼만 필터(Kalman Filter)

### 3.1 문제 정형화

**잡음이 있는 플랜트:**

$$\dot{x} = Ax + Bu + Gw$$
$$y = Cx + v$$

여기서:
- $w(t)$: **공정 잡음(process noise)** (외란, 모델 불확실성) — $E[ww^T] = W$
- $v(t)$: **측정 잡음(measurement noise)** (센서 잡음) — $E[vv^T] = V$
- 둘 다 백색, 0 평균, Gaussian

**목표:** 잡음이 있는 측정 $y(t)$가 주어졌을 때 $x(t)$의 최선의 추정 $\hat{x}(t)$를 찾기.

### 3.2 칼만 필터 (연속 시간)

$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$$

최적 이득은:

$$L = P_f C^T V^{-1}$$

여기서 $P_f$는 **필터 대수 Riccati 방정식**의 해:

$$AP_f + P_f A^T - P_f C^T V^{-1} C P_f + GWG^T = 0$$

### 3.3 성질

- 칼만 필터는 **최적** 선형 추정기 ($E[\|x - \hat{x}\|^2]$ 최소화)
- 구조는 Luenberger 관측기(레슨 13)와 같지만 이득이 최적으로 선택됨
- 필터는 모델에 대한 신뢰와 측정에 대한 신뢰를 **균형**짓는다:
  - 큰 $W$ (잡음 많은 모델) → 큰 $L$ (측정을 더 신뢰)
  - 큰 $V$ (잡음 많은 센서) → 작은 $L$ (모델을 더 신뢰)

### 3.4 LQR과의 쌍대성

칼만 필터와 LQR은 **쌍대(dual)** 문제다:

| LQR | 칼만 필터 |
|-----|---------------|
| $A^TP + PA - PBR^{-1}B^TP + Q = 0$ | $AP_f + P_fA^T - P_fC^TV^{-1}CP_f + GWG^T = 0$ |
| $K = R^{-1}B^TP$ | $L = P_fC^TV^{-1}$ |
| 상태 가중 $Q$ | 공정 잡음 $GWG^T$ |
| 제어 가중 $R$ | 측정 잡음 $V$ |
| 귀환 이득 $K$ | 관측기 이득 $L$ |

실용적 결과: LQR ARE를 푸는 코드는 입력을 전치하면 칼만 ARE를 푼다. 같은 `scipy.linalg.solve_continuous_are(A.T, C.T, G@W@G.T, V)`가 필터 $P_f$를 반환 — 하나의 루틴, 두 알고리즘.

## 4. LQG 제어

### 4.1 LQR + 칼만 필터 결합

**선형-이차-Gaussian (LQG)** 제어기는 다음을 결합:
- LQR로 최적 상태 귀환
- 칼만 필터로 최적 상태 추정

$$u = -K\hat{x}, \quad K = R^{-1}B^T P \quad \text{(LQR)}$$
$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x}), \quad L = P_f C^T V^{-1} \quad \text{(칼만 필터)}$$

### 4.2 분리 원리 (확률적, Stochastic)

**확실성 등가 원리(certainty equivalence)**는 LQR과 칼만 필터를 독립적으로 설계할 수 있음을 보장 — 레슨 13의 분리 원리가 확률적 환경에도 그대로 적용된다.

### 4.3 LQG 전달함수

LQG 제어기는 동적 보상기:

$$G_{LQG}(s) = K(sI - A + BK + LC)^{-1}L$$

이는 차수 $n$의 진성(proper) 전달함수(플랜트와 같음).

## 5. LQG의 강건성 한계

### 5.1 문제

LQR이 보장된 여유($GM = [1/2, \infty)$, $PM \geq 60°$)를 가지는 반면, **LQG는 보장된 여유가 없다**. 칼만 필터는 LQR의 강건성을 임의로 저하시킬 수 있다.

이는 1970년대의 주요 발견(Doyle, 1978) — 최적 제어가 자동으로 강건 제어를 주지 않음을 보였다.

### 5.2 루프 전송 회복(Loop Transfer Recovery, LTR)

**LQG/LTR**은 칼만 필터를 설계하여 루프 전송 함수가 LQR 루프 전송 함수에 근사하도록 함으로써 LQR 강건성을 회복하려 시도:

$$L(j\omega) \approx K(j\omega I - A)^{-1}B \quad \text{플랜트 입력에서}$$

이는 공정 잡음 공분산을 증가시킴으로써 달성: $W \to qBB^T$, $q \to \infty$.

> **실용적 참고**: 안전-중요 응용(항공우주, 자동차)에서, LTR 없는 LQG는 거의 배포되지 않는다. 전체 LQG/LTR을 사용하거나, 칼만을 완전히 건너뛰고 명시적 여유 검사를 가진 모델 기반 관측기를 사용한다. 순수 LQR의 6 dB / 60° 보장은 의도치 않게 포기하기에 너무 가치 있다.

## 6. 유한 구간 LQR

### 6.1 시변 Riccati 방정식

유한 시간 구간 $[0, t_f]$:

$$J = x^T(t_f) S_f x(t_f) + \int_0^{t_f} \left[ x^T Q x + u^T R u \right] dt$$

최적 이득은 $K(t) = R^{-1}B^T P(t)$, 여기서 $P(t)$는 **미분 Riccati 방정식**을 만족:

$$-\dot{P} = A^T P + PA - PBR^{-1}B^T P + Q, \quad P(t_f) = S_f$$

이는 $t = t_f$에서 $t = 0$까지 **역방향(backward)**으로 적분된다. $t_f \to \infty$일 때 $P(t)$는 정상 상태 ARE 해로 수렴한다.

> **왜 역방향 적분?** 종단 비용 $S_f$가 $t = 0$이 아니라 $t_f$에서 경계 조건을 제공한다. $t = 0$에서 정방향으로 푸는 것은 $P(0)$을 알고 있어야 — 우리가 계산하려는 바로 그것 — 한다. 역방향 스윕이 수학적으로 동등하고 수치적으로 깔끔하다.

## 7. 흔한 함정

1. **LQR을 "마법 같은 강건성"으로 취급.** 6 dB / 60° 보장은 LQR 루프가 **완전 상태 귀환**일 때 — 즉, $x$를 직접 측정하고 $u = -Kx$일 때 — 다. 관측기와 LQR을 사용(LQG)하면 보장이 깨진다. LQG에서 강건성이 필요하면 LTR이나 다른 설계가 필요하다.
2. **$Q$와 $R$을 매우 다른 스케일로 선택.** 상태와 제어 크기가 6 자릿수 다를 때, ARE 솔버의 조건이 나빠진다. 설계 전에 Bryson 규칙을 사용하거나 상태/입력을 $[0, 1]$ 범위로 정규화하라.
3. **(A, Q^(1/2)) 검출가능성 조건을 잊음.** ARE는 이 조건을 만족할 때만 유일한 안정화 해를 가진다. $Q$가 rank-deficient이고 $A$에서 Q에 의해 미관측되는 모드가 불안정하면, ARE는 실패한다 — 때로는 수치 소프트웨어에서 조용히.
4. **임계 조건 근처의 수치 ARE 솔버를 과신.** `solve_continuous_are`는 Schur 방법을 사용 — 견고하지만 무적은 아니다. 항상 잔차 `A.T @ P + P @ A - P @ B @ inv(R) @ B.T @ P + Q`가 작은지 (예: Frobenius norm < $10^{-8}$) 검증하라.
5. **원하는 폐루프 극점 패턴을 맞추려 $Q$와 $R$ 튜닝.** $(Q, R) \to$ 극점 매핑은 비선형이고 가중 행렬에 의존한다. 특정 극점 목표가 있으면 직접 극점 배치(레슨 13)를 사용하라. LQR은 "비용 최소화"용이지 "X에 극점 배치"용이 아니다.
6. **유한 구간 $K(t)$가 시변임을 잊음.** 소프트웨어에서 시변 $K(t)$를 구현하려면 역방향 스윕에서 궤적 $P(t)$를 저장해야 한다. 많은 초보자가 정상 상태 $K$를 적용하는데 — 짧은 구간에서는 차선이며, 때로는 심하게.

2. 칼만 이득 $L$을 계산하라
3. 관측기 극점은 어디?

### 연습 문제 3: LQR 성질

SISO 경우, LQR 회귀 차이(return difference)가 다음을 만족함을 보여라:

$$|1 + K(j\omega I - A)^{-1}B| \geq 1 \quad \forall \omega$$

힌트: $1 + K(j\omega I - A)^{-1}B = 1 + R^{-1}B^T P(j\omega I - A)^{-1}B$에서 시작하여 ARE를 사용.

이것은 이득 여유와 위상 여유에 무엇을 의미하는가?

### 연습 문제 4: 수치 LQR 스윕

2.6절의 파이썬 스니펫으로 이중 적분기에 대해 $R \in \{0.01, 0.1, 1, 10, 100\}$로 LQR을 풀라. 각각에 대해 $s$-평면에 폐루프 극점 위치를 플로팅하라. 작은 $R$이 극점을 더 왼쪽으로 밀어냄(빠른 응답, 더 많은 노력)을 검증하라.

### 연습 문제 5: LQG 강건성 데모 — 개념적

작은 예제(2 상태 플랜트)를 구성하여, 강건한 LQR 설계에 칼만 필터를 추가하면 위상 여유가 $30°$ 이하인 LQG 제어기가 생성됨을 보여라. 한 가지 LTR 스타일 수정($BB^T$에 큰 $W$)을 제안하고 수치적으로 여유가 회복됨을 보여라.
