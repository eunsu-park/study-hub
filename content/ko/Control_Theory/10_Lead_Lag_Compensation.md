# 레슨 10: 앞섬-뒤짐 보상 (Lead-Lag Compensation)

## 학습 목표

- 앞섬 보상기(Lead Compensator)를 설계하여 과도 응답과 안정 여유를 개선한다
- 뒤짐 보상기(Lag Compensator)를 설계하여 안정성을 저하하지 않으면서 정상상태 오차를 줄인다
- 앞섬과 뒤짐 보상을 결합하여 종합적인 성능을 개선한다
- 보상기 합성을 위해 주파수 영역(Bode) 설계 방법을 적용한다
- 다양한 보상 전략 간의 절충 관계를 이해한다
- 보상기 설계를 수치적으로 검증하고 각 접근의 현실적 한계를 인식한다

## 0. 왜 PID를 더 강하게 하지 않고 Lead/Lag로 가는가

레슨 9 후 합리적 질문: PID가 어디에나 있는데, 왜 또 다른 보상기 계열을 배우는가?

Lead/Lag가 자리를 차지할 만한 세 가지 이유:

- **Lead는 실제 하드웨어에서 PD가 되고 싶어 하는 형태다.** 순수 미분($K_d s$)은 잡음을 무한히 증폭한다. Lead 보상기 $\frac{s+z}{s+p}$는 이 증폭을 비율 $p/z$로 제한한다 — 유한하고 예측 가능하며 조정 가능. 현장의 모든 PID 구현은 이상적 PID보다 "PI + lead"에 더 가깝다.
- **Lag는 PID가 결합한 두 설계 손잡이를 분리한다.** PI 제어기는 저주파 이득을 올리지만(추종에 좋음) 동시에 90°의 위상 지연을 더한다(안정성에 나쁨) — 한쪽만 움직일 수 없다. Lag 보상은 적분기의 효과를 이득 교차 훨씬 아래에 배치해 둘을 분리한다.
- **주파수 영역 설계는 일반화된다.** Lead/Lag는 Bode와 Nyquist가 본래 사용하는 언어다. 개념적 재발명 없이 MIMO와 강건 제어($H_\infty$, $\mu$ 합성)로 확장된다.

머릿속 그림: Lead 보상기는 "선택한 주파수 근처의 일시적 위상 부스트"; Lag 보상기는 "안정성을 해치기 전에 사라지는 추가 DC 이득". 대부분의 실제 보상기는 이 두 아이디어의 어떤 혼합이다.

## 1. 보상 개요

플랜트 $G_p(s)$에 단순 이득 $K$만으로 모든 설계 사양을 만족할 수 없을 때, 시스템의 주파수 응답이나 근궤적을 재구성하기 위해 **보상기(compensator)** $G_c(s)$를 추가한다.

```
R →(+)→ [G_c(s)] → [G_p(s)] → Y
    ↑                          |
    └──────────────────────────┘
```

**보상 종류:**

| 종류 | 구조 | 주요 효과 |
|------|-----------|----------------|
| Lead | 극점 왼쪽의 영점 | 위상 앞섬 추가 → PM 개선, 응답 가속 |
| Lag | 원점 가까운 극점, 그 근처의 영점 | 저주파 이득 증가 → $e_{ss}$ 감소 |
| Lead-Lag | 결합 | 과도 및 정상상태 모두 개선 |

## 2. 앞섬 보상기(Lead Compensator)

### 2.1 전달함수

$$G_{\text{lead}}(s) = K_c \frac{s + z}{s + p} = K_c \frac{\tau s + 1}{\alpha\tau s + 1} \quad (p > z, \; 0 < \alpha < 1)$$

여기서:
- $z = 1/\tau$: 영점 위치
- $p = 1/(\alpha\tau)$: 극점 위치 ($p > z$, 즉 극점이 더 왼쪽)
- $\alpha = z/p < 1$: 최대 위상 앞섬 결정

### 2.2 주파수 응답

Lead 보상기는 영점과 극점 주파수 사이에서 양의 위상을 제공한다:

$$\phi_{\max} = \sin^{-1}\frac{1-\alpha}{1+\alpha}$$

기하 평균 주파수에서:

$$\omega_{\max} = \frac{1}{\tau\sqrt{\alpha}} = \sqrt{zp}$$

**설계 통찰:** $\alpha$가 작을수록 더 많은 위상 앞섬을 주지만 고주파에서 이득 증가도 더 크다(잡음 증폭). 실용적 한계: $\alpha \geq 0.05$ ($\phi_{\max} \leq 65°$). 더 많은 앞섬이 필요하면 두 개의 Lead 보상기를 직렬로 연결한다.

기억할 짧은 표 ($\alpha$ → $\phi_{\max}$):

| $\alpha$ | $\phi_{\max}$ | 고주파 이득 증가 |
|----------|---------------|---------------------|
| $0.5$ | $\approx 19°$ | 6 dB |
| $0.25$ | $\approx 37°$ | 12 dB |
| $0.1$ | $\approx 55°$ | 20 dB |
| $0.05$ | $\approx 65°$ | 26 dB |

고주파 이득 증가는 정확히 센서 잡음을 증폭하는 양이다 — 모든 $\alpha$ 선택은 위상 앞섬과 잡음의 절충이다.

### 2.3 Bode 설계 절차

**주어짐:** 플랜트 $G_p(s)$, 원하는 위상 여유 $PM_d$, 정상상태 오차 요구사항.

**단계:**

1. **이득 $K$ 설정** — 정상상태 오차 요구사항을 만족 (오차 상수 $K_p$, $K_v$, $K_a$ 사용)
2. **평가** — 보상 전 시스템: 이득 $K$에서 현재 $PM$ 찾기
3. **필요한 위상 앞섬 결정:** $\phi_{\max} = PM_d - PM_{\text{current}} + \text{여유}$ (보상기가 $\omega_{gc}$를 이동시키므로 5°-12° 여유 추가)
4. **계산** $\alpha = \frac{1 - \sin\phi_{\max}}{1 + \sin\phi_{\max}}$
5. **새 $\omega_{gc}$ 찾기**: $|KG_p(j\omega)| = -10\log_{10}(1/\alpha)$ dB가 되는 주파수 (보상 후 $\omega_{\max}$에서 이득이 0 dB가 되도록)
6. $\omega_{\max} = \omega_{gc,\text{new}}$로 **설정**, $\tau = 1/(\omega_{\max}\sqrt{\alpha})$ 계산
7. **계산** $K_c = K/\alpha$ (또는 전체 DC 이득이 맞도록 조정)
8. 보상된 Bode 선도를 그려 설계를 **검증**

### 2.4 예제

**플랜트:** $G_p(s) = \frac{1}{s(s+1)}$

**사양:** $K_v = 10$, $PM \geq 45°$

1. $K_v = 10$에 대해: $K_v = \lim_{s\to 0} sKG_p(s) = K \Rightarrow K = 10$
2. 보상 전: $KG_p(s) = \frac{10}{s(s+1)}$. $\omega_{gc} \approx 2.9$ rad/s에서 $PM \approx 18°$
3. 필요한 lead: $\phi_{\max} = 45° - 18° + 10° = 37°$
4. $\alpha = \frac{1 - \sin 37°}{1 + \sin 37°} = \frac{1 - 0.602}{1 + 0.602} = 0.249$
5. 새 $\omega_{gc}$: $|10/(j\omega)(j\omega + 1)| = 10\log_{10}(1/0.249) = 6$ dB가 되는 곳 → $\omega_{gc} \approx 3.8$ rad/s
6. $\tau = 1/(3.8\sqrt{0.249}) = 0.527$ → 영점 $1/\tau = 1.9$, 극점 $1/(\alpha\tau) = 7.6$

Lead 보상기: $G_c(s) = \frac{10}{0.249} \cdot \frac{0.527s + 1}{0.131s + 1} = 40.2\frac{s + 1.9}{s + 7.6}$

### 2.5 파이썬으로 검증

위 설계는 종이로 보상기를 계산하기에 충분하지만, 30줄 정도의 스크립트가 PM과 $\omega_{gc}$를 정확히 확인해 준다:

```python
import numpy as np
import matplotlib.pyplot as plt
from control import TransferFunction, bode_plot, margin

# 보상 전과 보상 후의 개루프 전달함수
G_uncomp = TransferFunction([10], [1, 1, 0])              # 10 / (s(s+1))
G_lead   = TransferFunction([40.2 * 0.527, 40.2],
                            [0.131, 1])                    # 40.2 (s+1.9)/(s+7.6) — 이득 × lead
G_comp   = G_lead * TransferFunction([1], [1, 1, 0])

for label, G in [("uncompensated", G_uncomp), ("compensated", G_comp)]:
    gm, pm, wpc, wgc = margin(G)
    print(f"{label:>14}: PM = {pm:5.1f}°  at  wgc = {wgc:.2f} rad/s")

omega = np.logspace(-2, 2, 500)
bode_plot([G_uncomp, G_comp], omega=omega, dB=True)
plt.show()
```

예상 출력: 보상 전 PM이 18° 근처, 보상 후 PM이 45° 근처 — 설계와 일치. 수치 PM이 설계 목표보다 훨씬 작다면 가장 흔한 원인은 단계 5에서 잘못된 이득 교차 주파수를 사용한 것이다 ($\omega_{gc}$의 1–2 rad/s 오차가 5° PM 오차를 만든다).

## 3. 뒤짐 보상기(Lag Compensator)

### 3.1 전달함수

$$G_{\text{lag}}(s) = K_c \frac{s + z}{s + p} = K_c \frac{\tau s + 1}{\beta\tau s + 1} \quad (z > p, \; \beta > 1)$$

여기서 $z > p$ (영점이 극점보다 원점에서 더 멀리), 즉 $\beta = z/p > 1$.

### 3.2 동작 원리

Lag 보상기는 다음과 같이 작동한다:
- 영점 주파수 아래의 **저주파 이득을 $\beta$ 배 증가**
- 이득 교차 주파수 근처의 위상에는 **유의하지 않은 영향** (극점-영점 쌍을 $\omega_{gc}$ 훨씬 아래 배치)
- $\omega_{gc}$에서 작은 위상 지연이 대가

### 3.3 Bode 설계 절차

1. 현재 $\omega_{gc}$가 원하는 $PM$을 제공하도록 **이득 $K$ 설정** ($e_{ss}$ 무시)
2. 추가로 필요한 이득 **결정**: $\beta = \frac{K_{\text{required}}}{K_{\text{current}}}$ ($e_{ss}$용 이득과 PM용 이득의 비)
3. **영점 배치**: $\omega_z = \omega_{gc}/10$ (위상 영향 최소화를 위해 교차로부터 한 decade 아래)
4. **극점 배치**: $\omega_p = \omega_z/\beta$
5. 보상된 시스템의 PM과 $e_{ss}$ **검증**

### 3.4 예제

**플랜트:** $G_p(s) = \frac{1}{s(s+1)(s+2)}$

**사양:** $K_v = 5$, $PM \geq 40°$

1. Lag 없이 $PM = 40°$를 위해: $\omega_{gc} = 0.5$에서 $PM \approx 63°$. $\omega = 0.5$에서 이득 $|G_p(j0.5)| = 0.89 \Rightarrow K = 1/0.89 = 1.12$ → $K_v = K/2 = 0.56$ (너무 작음)
2. $\beta = 5/0.56 = 8.93$
3. 영점 $\omega_z = 0.5/10 = 0.05$ → $z = 0.05$
4. 극점 $\omega_p = 0.05/8.93 = 0.0056$ → $p = 0.0056$

Lag 보상기: $G_c(s) = 1.12 \frac{s + 0.05}{s + 0.0056} = 1.12 \frac{20s + 1}{178.6s + 1}$

## 4. Lead-Lag 보상기

### 4.1 구조

$$G_{c}(s) = K_c \frac{(s + z_1)(s + p_2)}{(s + p_1)(s + z_2)}$$

여기서 lead 부분은 $(s + z_1)/(s + p_1)$ ($p_1 > z_1$, 영점이 극점 왼쪽)을 사용하고, lag 부분은 $(s + p_2)/(s + z_2)$ ($z_2 > p_2$)를 사용. 일부 교과서는 lead-lag를 곱 $(s+z_1)(s+z_2)/[(s+p_1)(s+p_2)]$로 쓰며 각 절의 규약을 명시한다.

### 4.2 설계 전략

1. **Lag** 부분을 먼저 설계해 정상상태 오차 요구사항 충족
2. **Lead** 부분을 설계해 위상 여유 요구사항 충족
3. 결합하고 검증

대안:
1. 원하는 PM을 위해 **Lead** 먼저 설계
2. $e_{ss}$를 위해 저주파 이득을 올리도록 **Lag** 설계
3. Lag 절의 위상 기여가 이득 교차에 영향을 주면 반복

### 4.3 어느 것을 언제 사용

| 사양 | 보상기 |
|--------------|-------------|
| 부족한 PM, 적절한 $e_{ss}$ | Lead |
| 적절한 PM, 부족한 $e_{ss}$ | Lag |
| PM과 $e_{ss}$ 모두 개선 필요 | Lead-Lag |
| 매우 큰 PM 개선 필요 ($> 65°$) | 이중 lead 또는 lead-lag |

## 5. PID와의 비교

고전적 보상기는 PID와 밀접하게 관련된다:

| PID 항 | 보상기 등가물 |
|----------|----------------------|
| P | 이득 조정 |
| PI | Lag 보상기 (원점 극점, 그 근처 영점) |
| PD | Lead 보상기 (영점, 멀리 있는 극점) |
| PID | 적분기 포함 Lead-Lag |

**PID 대비 Lead-Lag의 장점:**
- 극점/영점 배치의 더 큰 유연성
- 더 나은 잡음 처리 (lead는 유한한 고주파 이득을 가짐)
- 체계적 주파수 영역 설계

**PID의 장점:**
- 현장 구현 및 튜닝이 더 단순
- 잘 확립된 산업 튜닝 규칙
- 비전문가가 이해하기 쉬움

> **실용적 참고**: 산업 제어기의 대부분의 "PID" 구현은 실제로 여과된 미분(즉, P+lead인 PD)을 사용한다. 따라서 Lead-Lag는 이국적인 대안이 아니다 — 잘 설계된 PID가 수렴하는 형태다.

## 6. 설계 검증

보상기 설계 후, 다음을 계산하여 검증:

1. **계단 응답**: $M_p$, $t_s$, $t_r$, $e_{ss}$ 확인
2. **Bode 선도**: $GM$, $PM$, 대역폭 검증
3. **근궤적**: 폐루프 극점 위치 확인
4. **감도**: 모든 주파수에서 $|S(j\omega)| < M_s^{\max}$ 확인
5. **제어 노력**: $|u(t)| < u_{\max}$ 확인 (액추에이터 포화 검사)

## 7. 흔한 함정

1. **Lead 부분 과설계.** $\phi_{\max} > 60°$를 목표로 하면 $\alpha$가 너무 작아 고주파 이득이 26 dB 이상으로 폭발한다. 그러면 센서 잡음이 액추에이터로 쏟아진다. 두 개의 직렬 lead — 각각 30° 기여 — 를 사용하여 잡음 이득을 제한된 채로 유지하라.
2. **Lead 추가 후 이득 이동 잊음.** $\alpha = 0.25$인 lead는 중간 주파수 이득을 6 dB 올려 $\omega_{gc}$를 더 높은 주파수로 이동시킨다. 설계 절차의 단계 5는 정확히 이것을 고려하기 위해 존재한다; 건너뛰면 위상은 맞지만 교차 주파수가 틀린 보상기가 나온다.
3. **Lag 영점을 이득 교차 너무 가까이 배치.** "한 decade 아래"는 lag의 잔여 위상 기여가 이득 교차에서 $\leq 6°$가 되기 때문에 경험 법칙이다. 한 decade보다 가까우면 lag가 위상 여유를 먹어버린다.
4. **Lag 극점을 정확히 원점으로 취급.** 원점의 극점은 적분기지 lag가 아니다. 순수 적분기는 모든 주파수에 90°의 위상 지연을 더한다 — Lag 보상기의 제한된 기여와 매우 다르다. PI는 적분기 + lead 영점; lag는 유한 극점 + 영점이다.
5. **Bode에서 설계하고 계단 응답을 시뮬레이션하지 않음.** 교과서적으로 완벽한 $PM = 45°$도 더 높은 주파수의 폐루프 극점이 $\zeta < 0.4$를 가지면 30% 오버슈트를 만들 수 있다. 항상 계단 응답을 시뮬레이션하고 $M_p$를 끝까지 확인하라.
6. **액추에이터 포화 무시.** $\alpha = 0.05$인 lead 보상기는 고주파 제어 신호를 26 dB 곱한다. 설정값 계단의 선두에서 액추에이터 명령 스파이크가 포화 한계를 초과하여 선형 설계가 예측하지 못한 비선형성으로 시스템을 몰아갈 수 있다.

## 연습 문제

### 연습 문제 1: Lead 보상기 설계

$G_p(s) = \frac{5}{s(s+2)}$에 대해 $K_v = 10$을 유지하면서 $PM \geq 50°$를 달성하는 Lead 보상기를 설계하라.

1. 필요한 이득을 결정하라
2. 보상 전 위상 여유를 구하라
3. Bode 방법으로 Lead 보상기를 설계하라
4. 보상된 시스템의 위상 여유를 검증하라

### 연습 문제 2: Lag 보상기 설계

$G_p(s) = \frac{1}{s(s+1)(s+5)}$에 대해 $K_v = 10$이고 $PM \geq 40°$가 되도록 Lag 보상기를 설계하라.

### 연습 문제 3: Lead-Lag 설계

플랜트 $G_p(s) = \frac{10}{(s+1)(s+5)}$가 다음을 요구한다:
- 계단 입력에 대한 정상상태 오차 0 ($K_p = \infty$, 적분기 필요)
- $PM \geq 50°$

두 요구사항을 모두 만족하도록 Lead-Lag 보상기 (lag 절에 적분기 포함)를 설계하라.

### 연습 문제 4: 수치 검증

연습 문제 1의 설계를 2.5절의 파이썬 스니펫으로 수치 검증하라. 보상 전후의 Bode 다이어그램을 모두 그려라. 달성된 PM이 설계 목표의 3° 이내인지 확인하라. 그렇지 않다면 어느 절차 단계가 오류를 도입했는지 식별하라.

### 연습 문제 5: Lead 위상을 잡음과 트레이드

연습 문제 1에 대해 두 가지 설계 선택을 고려하라: $\alpha = 0.1$인 단일 lead vs. 각각 $\alpha = 0.32$인 두 개의 직렬 lead (각각이 위상의 약 절반에 기여). 두 설계의 고주파 이득을 비교하라. 30 rad/s 위에서 유의한 센서 잡음이 있는 시스템에는 어느 쪽이 선호되는가?
