# 레슨 2: 물리 시스템의 수학적 모델링

## 학습 목표

- 기계, 전기, 전기기계 시스템에 대한 미분방정식 모델 유도
- 물리 영역 간 유사성 식별
- 평형점 주변에서 비선형 모델을 선형화
- 물리 모델을 제어 분석에 적합한 표준 형태로 변환
- 모델을 수치적으로 검증하고 모델이 너무 공격적으로 선형화되었을 때를 인식

## 0. 모델러의 일

이 강의의 모든 제어기는 모델을 가정한다. 모델은 결코 시스템 자체가 아니다 — 관심 시간 척도와 동작 범위에서 중요한 동역학을 포착하는 의도적으로 단순화된 수학적 대용물이다. 무엇을 유지하고 무엇을 버릴지 선택하는 것이 모델링 결정이며, 대부분의 프로젝트에서 제어기 선택보다 폐루프 성능에 더 큰 영향을 준다.

반복적으로 손에 잡을 세 가지 안내 원칙:

- **지배적 물리 유지.** 자동차의 횡 동역학은 타이어 슬립, 질량, 요 관성에 의해 지배된다. 앞 유리가 곡면이라는 사실은 무관하다. 앞뒤 차축이 다르다는 사실은 본질적이다. 모델링 충실도는 모든 것을 추가함으로써가 아니라, 다음으로 가장 중요한 물리를 추가함으로써 자란다.
- **동작점에서 선형화.** 비선형 물리($\sin\theta$, $v^2$ 항력, 히스테리시스)는 설계를 어렵게 만든다. 거의 모든 제어 설계는 "선형화, 설계, 원래 비선형 시스템 시뮬레이션, 반복"으로 환원된다. 6절이 작업 절차다.
- **영역 간의 유사성 존중.** 스프링 위 질량과 LC 탱크 회로는 동일한 방정식을 따른다. 이를 인식하면 분야를 바꿀 때 몇 주의 유도를 절약할 수 있다. 5절이 치트 시트.

이 레슨의 출력 — 플랜트의 선형 ODE — 가 레슨 3의 전달함수에 입력되고, 그 후 모든 분석 레슨에 입력된다. 이를 옳게 하면 강의의 나머지는 부기 작업.

## 1. 왜 수학적 모델링인가?

제어 설계는 **수학적 모델** — 플랜트의 동적 거동을 기술하는 방정식 집합 — 을 요구한다. 모델은 본질적 물리를 포착하면서 분석과 제어기 합성에 충분히 단순해야 한다.

**모델링 접근:**
- **제1원리(First principles)**: 물리에서 유도 (Newton 법칙, Kirchhoff 법칙, 보존 법칙)
- **시스템 식별(System identification)**: 측정된 입출력 데이터에 모델 적합 (고급 강의)
- **하이브리드**: 물리 기반 구조와 데이터 적합 파라미터 결합

이 레슨에서는 제1원리 모델링에 집중.

## 2. 기계 시스템

### 2.1 병진 시스템

세 가지 기본 요소:

| 요소 | 법칙 | 방정식 |
|---------|-----|----------|
| 질량 $m$ | Newton 제2법칙 | $F = m\ddot{x}$ |
| 댐퍼 $b$ | 점성 마찰 | $F = b\dot{x}$ |
| 스프링 $k$ | Hooke 법칙 | $F = kx$ |

**예제: 질량-스프링-댐퍼**

```
    F(t)
    →  ┌───┐
   ────┤ m ├────┬──── wall
       └───┘    │
          ├──┤b├──┤  (damper)
          ├──/\/\──┤  (spring, k)
```

Newton 제2법칙 적용:

$$m\ddot{x}(t) + b\dot{x}(t) + kx(t) = F(t)$$

이는 상수 계수의 **2차 선형 ODE**.

**표준 형태** ($m$으로 나눔):

$$\ddot{x} + 2\zeta\omega_n \dot{x} + \omega_n^2 x = \frac{F(t)}{m}$$

$\omega_n = \sqrt{k/m}$는 **고유 진동수(natural frequency)**, $\zeta = b/(2\sqrt{mk})$는 **제동비(damping ratio)**.

### 2.2 회전 시스템

| 요소 | 법칙 | 방정식 |
|---------|-----|----------|
| 관성 모멘트 $J$ | Newton 회전 법칙 | $\tau = J\ddot{\theta}$ |
| 회전 댐퍼 $B$ | 점성 마찰 | $\tau = B\dot{\theta}$ |
| 비틀림 스프링 $K$ | Hooke 법칙 (회전) | $\tau = K\theta$ |

**예제: 단순 진자 (작은 각도)**

길이 $l$, 질량 $m$인 진자:

$$ml^2 \ddot{\theta} + mgl\sin\theta = \tau(t)$$

작은 각도 ($\sin\theta \approx \theta$)에 대해 선형화:

$$ml^2 \ddot{\theta} + mgl\theta = \tau(t)$$

### 2.3 기어 트레인

기어비 $N = N_2/N_1$ (이빨 비)인 기어 트레인은 토크와 속도를 변환:

$$\theta_2 = \frac{N_1}{N_2}\theta_1, \quad \tau_2 = \frac{N_2}{N_1}\tau_1$$

입력 축에서 본 반사 관성:

$$J_{\text{eff}} = J_1 + \left(\frac{N_1}{N_2}\right)^2 J_2$$

## 3. 전기 시스템

### 3.1 수동 요소

| 요소 | 전압-전류 | 임피던스 $Z(s)$ |
|---------|----------------|-------------------|
| 저항 $R$ | $v = Ri$ | $R$ |
| 인덕터 $L$ | $v = L\frac{di}{dt}$ | $Ls$ |
| 커패시터 $C$ | $v = \frac{1}{C}\int i \, dt$ | $\frac{1}{Cs}$ |

### 3.2 Kirchhoff 법칙

- **KVL** (전압 법칙): 루프 주위 전압의 합 = 0
- **KCL** (전류 법칙): 노드에서 전류의 합 = 0

**예제: 직렬 RLC 회로**

KVL 적용:

$$L\frac{di}{dt} + Ri + \frac{1}{C}\int i \, dt = v_{\text{in}}(t)$$

미분하고 $v_C = \frac{1}{C}\int i \, dt$ 대입:

$$LC\ddot{v}_C + RC\dot{v}_C + v_C = v_{\text{in}}(t)$$

이는 질량-스프링-댐퍼 시스템과 **같은 형태**!

### 3.3 Op-Amp 회로

이상 op-amp 가정: 무한 입력 임피던스, 0 출력 임피던스, 무한 이득.

**반전 증폭기:**

$$v_{\text{out}} = -\frac{R_f}{R_{\text{in}}} v_{\text{in}}$$

**적분기:**

$$v_{\text{out}} = -\frac{1}{R_{\text{in}}C_f} \int v_{\text{in}} \, dt$$

**미분기:**

$$v_{\text{out}} = -R_f C_{\text{in}} \frac{dv_{\text{in}}}{dt}$$

Op-amp 회로는 아날로그 제어기(PID) 구현에 흔히 사용.

## 4. 전기기계 시스템

### 4.1 DC 모터

DC 모터는 전기 에너지를 기계 에너지로 변환. 핵심 방정식:

**전기 (전기자 회로):**

$$L_a \frac{di_a}{dt} + R_a i_a + K_b \dot{\theta} = v_a(t)$$

**기계 (회전자):**

$$J\ddot{\theta} + B\dot{\theta} = K_t i_a$$

여기서:
- $v_a$: 인가 전압
- $i_a$: 전기자 전류
- $K_b$: 역기전력 상수
- $K_t$: 토크 상수 (SI 단위에서 $K_t = K_b$)
- $R_a, L_a$: 전기자 저항과 인덕턴스

**전달함수** ($V_a(s)$에서 $\Theta(s)$, $L_a \approx 0$ 가정):

$$\frac{\Theta(s)}{V_a(s)} = \frac{K_t}{s(JR_a s + BR_a + K_t K_b)}$$

DC 모터는 제어 공학에서 가장 중요한 플랜트 중 하나 — 로봇, 디스크 드라이브, 프린터, 그 외 무수한 응용에 사용.

## 5. 물리 영역 간 유사성

물리 시스템의 수학적 구조는 종종 영역에 걸쳐 동일하다:

| 기계 (병진) | 기계 (회전) | 전기 | 유체 | 열 |
|---------------------|-------------------|------------|-------|---------|
| 힘 $F$ | 토크 $\tau$ | 전압 $v$ | 압력 $P$ | 온도 $T$ |
| 속도 $\dot{x}$ | 각속도 $\dot{\theta}$ | 전류 $i$ | 유량 $Q$ | 열류 $q$ |
| 질량 $m$ | 관성 $J$ | 인덕턴스 $L$ | Inertance | — |
| 댐퍼 $b$ | 회전 댐퍼 $B$ | 저항 $R$ | 유체 저항 | 열 저항 |
| 스프링 $k$ | 비틀림 스프링 $K$ | Elastance $1/C$ | 유체 용량 | 열 용량 |
| 변위 $x$ | 각도 $\theta$ | 전하 $q$ | 부피 | 열량 $Q$ |

이 유사성은 한 영역에서 개발된 기법을 다른 영역에 직접 적용할 수 있게 한다.

> **이것이 절약하는 시간**: 1940년대 화학 반응기 온도 루프용으로 개발된 PID 튜닝 규칙은 오늘날 모터 속도 제어에 직접 이전된다 — 둘 다 같은 정전적(canonical) 2차 플랜트로 환원되기 때문이다. 한 산업의 지혜가 다른 산업에 재사용 가능한 것은 오직 수학이 동일하기 때문이다.

## 6. 선형화

대부분의 실제 시스템은 **비선형**이다. 선형 제어 이론은 **동작점**(평형) 주변에서 **선형화** 후에만 적용된다.

### 6.1 평형점

평형 $(\bar{x}, \bar{u})$는 $\dot{x} = f(\bar{x}, \bar{u}) = 0$을 만족.

### 6.2 Taylor 급수 선형화

비선형 시스템 $\dot{x} = f(x, u)$에서 섭동 변수 정의:

$$\delta x = x - \bar{x}, \quad \delta u = u - \bar{u}$$

$f$를 Taylor 급수 전개하고 1차 항만 유지:

$$\delta\dot{x} \approx \frac{\partial f}{\partial x}\bigg|_{(\bar{x},\bar{u})} \delta x + \frac{\partial f}{\partial u}\bigg|_{(\bar{x},\bar{u})} \delta u$$

이는 평형 근처에서 유효한 **선형 근사**를 산출.

### 6.3 예제: 비선형 진자

전체 비선형 방정식:

$$\ddot{\theta} + \frac{g}{l}\sin\theta = \frac{\tau}{ml^2}$$

**평형:** $\bar{\theta} = 0$, $\bar{\tau} = 0$

**선형화:** 작은 $\theta$에 대해 $\sin\theta \approx \theta$:

$$\ddot{\theta} + \frac{g}{l}\theta = \frac{\tau}{ml^2}$$

**평형:** $\bar{\theta} = \pi$ (역진자), $\bar{\tau} = 0$

$\delta\theta = \theta - \pi$ 설정: $\sin(\pi + \delta\theta) = -\sin(\delta\theta) \approx -\delta\theta$:

$$\delta\ddot{\theta} - \frac{g}{l}\delta\theta = \frac{\tau}{ml^2}$$

부호 변화에 주목 — 역 평형은 **불안정**($\delta\theta$의 양 계수), 매달린 평형은 **안정**(음 계수).

### 6.4 선형화는 얼마나 멀리 성립하는가?

유용한 경험 법칙: 선형화는 비선형 항의 상대 오차가 ~10% 이하인 동안 "충분히 좋다". 진자에 대해 $\sin\theta = \theta - \theta^3/6 + \cdots$. 상대 오차는 $\theta^2/6$이므로 10% 임계는 $\theta \leq \sqrt{0.6} \approx 0.77$ rad ≈ 44°. 그 너머에서 선형 모델이 거짓말을 하고 제어기가 잘못 동작할 수 있다.

$\bar{\omega}$ 주변 $\omega^2$ 비선형성을 가진 원심 속도 조절기에서 국소 기울기는 $2\bar{\omega}$이고 2차 항은 섭동에 따라 이차로 자란다 — 같은 10% 규칙은 선형 모델이 실패하기 전 $\bar{\omega}$의 ~22%까지 섭동할 수 있다고 말한다.

실무에서: 선형 모델로 설계, 비선형으로 시뮬레이션, 발산을 플로팅. 시뮬레이션된 응답이 동작 범위 전체에 걸쳐 선형 예측의 10% 이내에 머무르면 안전하다.

## 7. 물리 모델에서 전달함수로

전달함수를 얻는 표준 작업 흐름:

1. 물리 요소와 그 상호 연결 **식별**
2. 물리 법칙 **적용** (Newton, Kirchhoff 등)
3. 미분방정식 **유도**
4. 필요시 **선형화**
5. **라플라스 변환** (0 초기 조건 가정)
6. $G(s) = Y(s)/U(s)$에 대해 **풀이**

**예제:** 질량-스프링-댐퍼 $m\ddot{x} + b\dot{x} + kx = F$:

$$ms^2 X(s) + bsX(s) + kX(s) = F(s)$$

$$G(s) = \frac{X(s)}{F(s)} = \frac{1}{ms^2 + bs + k}$$

### 7.1 파이썬으로 같은 모델 만들기

`sympy`가 자동으로 전달함수를 유도한다 — 대수 실수를 잡는 데 유용:

```python
import sympy as sp

s, m, b, k = sp.symbols('s m b k', positive=True)
X, F = sp.symbols('X F')

# 방정식: m s^2 X + b s X + k X = F
eq = sp.Eq(m * s**2 * X + b * s * X + k * X, F)
G = sp.simplify(sp.solve(eq, X)[0] / F)
print("G(s) =", G)         # 1 / (m s^2 + b s + k)

# 수치 값 대입: m=1, b=2, k=10
G_num = G.subs({m: 1, b: 2, k: 10})
print("Numeric G(s) =", G_num)

# 표준 형태: omega_n, zeta
omega_n = sp.sqrt(k / m)
zeta    = b / (2 * sp.sqrt(m * k))
print("omega_n =", omega_n.subs({m: 1, k: 10}).evalf())
print("zeta    =", zeta.subs({m: 1, b: 2, k: 10}).evalf())
```

sympy 표현 `G = 1/(m*s**2 + b*s + k)`는 손 유도와 일치한다. 더 복잡한 다중 요소 회로나 모터에 대해 이는 매우 유용해진다 — sympy는 산술 실수 없이 $C(sI-A)^{-1}B$를 기호적으로 단순화한다.

## 8. 흔한 함정

1. **너무 많이 모델링.** 다음 물리 효과를 추가하면 항상 모델이 단단해진다 — 그리고 설계 복잡성이 세 배가 된다. 효과의 기여가 관련 주파수에서 지배적인 것보다 10× 이하일 때 효과 추가를 멈추라.
2. **잘못된 동작점에서 선형화.** $\theta = 0$에서 선형화된 진자는 $\theta = \pi$에서 선형화된 것과 전혀 다르게 동작한다. 물리 파라미터의 부호가 **뒤집힐** 수 있다. 항상 동작점을 명시적으로 식별하고 평형 조건 $f(\bar x, \bar u) = 0$을 검증하라.
3. **단위를 조용히 혼합.** 역기전력 / 토크 상수 동등성($K_t = K_b$)에는 SI가 필수. 단위를 혼합(예: RPM과 rad/s)하면 방정식이 더 이상 균형을 잡지 못한다. 유도하기 전 모든 것을 SI로 변환하라.
4. **센서와 액추에이터 동역학 무시.** 플랜트의 상태에 직접 접근할 수 있는 것처럼 모델링하는 것은 교과서에는 괜찮다. 실제 하드웨어에서 센서는 자체 시간 상수를 가지고(열전대는 느림, 인코더는 빠름) 액추에이터는 자체 대역폭을 가진다(유압 램은 느림, 피에조는 빠름). 둘 다 모델에 속한다.
5. **선형화된 모델을 정확한 것으로 취급.** 동작 범위 내에서 선형 모델은 유용한 도구다. 그 너머에서는 틀리다. 설계를 하드웨어에 헌신하기 전 항상 비선형 시뮬레이션을 최종 점검으로 실행하라.
6. **유사성 존중 잊기.** 엔지니어는 종종 자신의 경력에 걸쳐 같은 정전적 2차 시스템을 다섯 가지 다른 영역에서 다시 유도한다. 한 번 형태를 인식하면 영원히 80%의 대수를 건너뛴다.

## 연습 문제

### 연습 문제 1: 기계 모델링

두 질량 시스템에서 질량 $m_1$과 $m_2$가 스프링 $k_{12}$와 댐퍼 $b_{12}$로 연결. 질량 $m_1$은 스프링 $k_1$과 댐퍼 $b_1$로 벽에 연결. 힘 $F(t)$가 $m_2$에 가해진다.

1. 각 질량에 대한 자유물체도를 그려라
