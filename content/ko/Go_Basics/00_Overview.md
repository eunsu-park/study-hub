# Go 기초

Go(Golang)는 Google에서 설계한 정적 타입, 컴파일 프로그래밍 언어입니다. **단순성**, **가독성**, **실용적 생산성**을 강조하는 설계 철학을 가지고 있습니다. 이 토픽은 Go의 기초 — 변수와 타입부터 동시성 프리미티브(고루틴, 채널), 테스팅, 표준 라이브러리까지 다룹니다.

## 학습 내용

- **언어 기초**: 변수, 타입, 제어 흐름, 기본 문법
- **복합 타입**: 배열, 슬라이스, 맵, 구조체
- **함수와 메서드**: 함수 타입, 리시버, 클로저, 메서드 집합
- **인터페이스**: 덕 타이핑, 타입 단언, 인터페이스 설계 패턴
- **에러 처리**: 에러 타입, 커스텀 에러, 래핑, 센티널 에러
- **패키지와 모듈**: Go 모듈, 의존성 관리, 프로젝트 구조
- **동시성**: 고루틴, 채널, 동시성 패턴(팬인/아웃, 워커 풀)
- **테스팅**: 테이블 기반 테스트, 벤치마크, 퍼징
- **표준 라이브러리**: io, net/http, encoding/json, os, filepath

## 환경 설정

```bash
# Go 설치 (macOS - Homebrew)
brew install go

# Go 설치 (Linux)
wget https://go.dev/dl/go1.22.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.22.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 설치 확인
go version
go env GOPATH
```

예제 코드는 `examples/Go_Basics/`에서 확인할 수 있습니다.
