# Go 고급

Go 기초를 바탕으로, 실전 애플리케이션 개발과 고급 언어 기능을 다룹니다. HTTP 서버, REST API, CLI 도구, 완전한 마이크로서비스를 직접 구축하면서 — 제네릭, 리플렉션, 프로파일링, 클라우드 네이티브 패턴을 학습합니다.

## 학습 내용

- **웹 개발**: HTTP 서버, REST API, 미들웨어, 라우팅
- **데이터베이스 접근**: database/sql, 커넥션 풀링, 마이그레이션
- **CLI 도구**: cobra, flag, 대화형 TUI
- **고급 타입**: 제네릭, 타입 제약, 제네릭 데이터 구조
- **리플렉션**: reflect 패키지, 구조체 태그, 코드 생성
- **성능**: pprof, trace, 벤치마킹, 메모리 최적화
- **빌드와 배포**: 크로스 컴파일, Docker, CI/CD, 릴리즈
- **네트워킹**: TCP/UDP, WebSocket, gRPC
- **클라우드 네이티브**: 컨텍스트, 헬스 체크, 우아한 종료, 12팩터 앱
