# 레슨 8: 정보 이론

## 학습 목표

- 섀넌 엔트로피를 정의하고 분포의 기대 놀라움으로 해석한다
- 교차 엔트로피를 계산하고 표준 분류 손실인 이유를 이해한다
- KL 발산을 정의하고 비음수성을 증명한다 (깁스 부등식)
- $H(p, q) = H(p) + D_\text{KL}(p \| q)$ 분해를 통해 교차 엔트로피, 엔트로피, KL 발산을 연결한다
- 상호 정보량을 적용하여 변수 간 의존성을 측정한다
- 정보 이론적 양을 DL 모델 분석에 사용한다 (정보 병목, VAE ELBO)
- 이산 및 연속 분포에서 엔트로피, 교차 엔트로피, KL 발산을 수치적으로 계산한다

---

## 1. 섀넌 엔트로피

### 1.1 정의

이산 분포 $p$의 **섀넌 엔트로피**는 기대 놀라움:

$$H(p) = -\sum_{x} p(x) \log p(x)$$

### 1.2 성질

1. $H(p) \geq 0$
2. $p$가 결정적이면 $H(p) = 0$
3. $K$개 결과에서 $H(p) \leq \log K$, 균등 분포일 때 등호

### 1.3 가우시안의 엔트로피

$X \sim \mathcal{N}(\mu, \sigma^2)$에 대해: $h(X) = \frac{1}{2}\log(2\pi e \sigma^2)$

가우시안은 주어진 평균과 분산을 가진 모든 분포 중 **최대 엔트로피**를 가집니다.

---

## 2. 교차 엔트로피

### 2.1 정의

참 분포 $p$와 모델 분포 $q$ 사이의 **교차 엔트로피**:

$$H(p, q) = -\sum_{x} p(x) \log q(x)$$

### 2.2 손실 함수로서

분류에서 $p$는 참 레이블(원-핫), $q = \hat{\boldsymbol{\pi}}$는 모델 예측:

$$H(p, q) = -\log \hat{\pi}_c$$

### 2.3 분해

$$\boxed{H(p, q) = H(p) + D_\text{KL}(p \| q)}$$

$H(p)$는 모델 매개변수에 대해 상수이므로, **교차 엔트로피 최소화 = KL 발산 최소화**입니다.

---

## 3. KL 발산

### 3.1 정의

$$D_\text{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)}$$

### 3.2 비음수성 증명

젠센 부등식 ($-\log$가 볼록)을 사용:

$$D_\text{KL}(p \| q) = -\mathbb{E}_p\left[\log \frac{q}{p}\right] \geq -\log \mathbb{E}_p\left[\frac{q}{p}\right] = 0$$

### 3.3 순방향 KL vs 역방향 KL

- **순방향 KL** $D_\text{KL}(p \| q)$ (평균 추구): $q$가 $p$의 모든 모드를 커버하려 함
- **역방향 KL** $D_\text{KL}(q \| p)$ (모드 추구): $q$가 $p$의 한 모드에 집중하려 함

---

## 4. 상호 정보량

$$I(X; Y) = D_\text{KL}(p(x, y) \| p(x)p(y)) = H(X) + H(Y) - H(X, Y)$$

- $I(X; Y) \geq 0$, $X$와 $Y$가 독립일 때만 등호
- 대칭: $I(X; Y) = I(Y; X)$

**정보 병목**: 신경망 층 $T$는 $I(T; Y)$를 최대화 (레이블 정보 보존)하면서 $I(T; X)$를 최소화 (입력 정보 압축)해야 합니다.

---

## 5. VAE에서의 정보 이론

### 5.1 ELBO

$$\log p(\mathbf{x}) \geq \mathbb{E}_{q(\mathbf{z}|\mathbf{x})}[\log p(\mathbf{x}|\mathbf{z})] - D_\text{KL}(q(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))$$

- **복원 항**: 디코더가 $\mathbf{x}$를 얼마나 잘 복원하는가
- **KL 항**: 인코더 사후 분포가 사전 분포에 얼마나 가까운가

---

## 6. 레이블 스무딩

원-핫 레이블을 다음으로 교체:

$$y_k^{\text{smooth}} = (1 - \alpha) y_k + \frac{\alpha}{K}$$

$H(\mathbf{y}^{\text{smooth}}) > 0$이므로, 완벽한 교차 엔트로피에 덜 극단적인 로짓이 필요합니다. 과신뢰 예측을 방지합니다.

## 요약

| 개념 | 핵심 요점 |
|------|----------|
| 엔트로피 | 기대 놀라움; 균등 분포에서 최대화 |
| 교차 엔트로피 | 잘못된 모델 하의 기대 코드 길이; = 분류 손실 |
| 분해 | $H(p, q) = H(p) + D_\text{KL}(p\|q)$; CE 최소화 = KL 최소화 |
| KL 비음수성 | 젠센 부등식으로 증명 |
| 순방향 vs 역방향 KL | 평균 추구 vs 모드 추구 행동 |
| 상호 정보량 | 대칭적 의존성 측도; $I = H(X) + H(Y) - H(X,Y)$ |
| ELBO | 로그 증거의 하한; 복원 - KL |
