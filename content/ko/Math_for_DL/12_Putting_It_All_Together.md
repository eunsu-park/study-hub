# 레슨 12: 종합 정리

## 학습 목표

- 데이터에서 학습된 모델까지의 완전한 수학적 여정을 추적한다
- 이 과정의 각 수학 개념을 현대 DL 파이프라인에서의 역할에 매핑한다
- 전체 트랜스포머 블록의 그래디언트를 단계별로 유도한다
- 모든 손실 함수, 옵티마이저, 아키텍처가 수학적으로 어떻게 연결되는지 이해한다
- 디버깅이나 설계 시 어떤 수학적 도구를 사용할지 식별한다
- 이 과정 이후의 수학적 학습 경로를 도표화한다

## 2. 진단 도구: 언제 어떤 수학을 사용하는가

### 2.1 학습 실패

| 증상 | 수학 도구 | 확인 사항 |
|------|----------|----------|
| 손실 = NaN | 수치 안정성 (L10) | 소프트맥스/exp 오버플로우? 0으로 나눔? |
| 손실 정체 | 최적화 이론 (L05) | 학습률 너무 작음? 안장점에 걸림? |
| 손실 진동 | 그래디언트 분석 (L02, L05) | 학습률 너무 큼? 나쁜 조건수? |
| 그래디언트 소실 | 야코비안 분석 (L03, L04) | 활성화 포화? 잔차 연결 필요? |
| 그래디언트 폭발 | 노름 분석 (L01, L03) | 그래디언트 클리핑 필요? 가중치 초기화 잘못? |
| 과적합 | MAP/정규화 (L07) | 가중치 감쇠 추가? 드롭아웃? |

## 3. 트랜스포머 블록 뒤의 수학

$$\mathbf{X}' = \text{LayerNorm}(\mathbf{X} + \text{MultiHeadAttn}(\mathbf{X}))$$
$$\mathbf{X}'' = \text{LayerNorm}(\mathbf{X}' + \text{FFN}(\mathbf{X}'))$$

| 구성 요소 | 수학 개념 | 레슨 |
|----------|----------|------|
| 선형 투영 $W_Q, W_K, W_V$ | 행렬 곱셈, 매개변수 그래디언트 | 01, 03 |
| 스케일드 닷-프로덕트 | 닷 프로덕트, 분산 분석 | 01, 11 |
| 소프트맥스 | 지수함수, 수치 안정성 | 10, 11 |
| 잔차 연결 | 항등 야코비안, 그래디언트 보존 | 03, 04 |
| 층 정규화 | 평균/분산, 결합 야코비안 | 04 |
| 교차 엔트로피 손실 | MLE, 정보 이론 | 07, 08 |
| Adam 옵티마이저 | 모멘텀, 대각 헤시안 | 04, 05 |

## 4. 추가 학습 가이드

### 4.1 더 깊이: AI를 위한 수학 (Tier 3)

이 과정은 DL 실무자를 위한 필수 수학을 다뤘습니다. 연구자를 위해 [Math_for_AI](../Math_for_AI/00_Overview.md)는 다음으로 확장됩니다:

- **측도론**: 엄밀한 확률 기초
- **함수해석학**: 무한 차원 최적화 (뉴럴 탄젠트 커널)
- **미분기하학**: 다양체 위의 리만 최적화
- **최적 운송**: 생성 모델을 위한 바서스타인 거리

### 4.2 활발한 연구 분야

1. **뉴럴 탄젠트 커널 (NTK)**: 무한 너비 네트워크의 커널 방법 행동
2. **손실 지형 기하학**: 극소점 구조의 이해
3. **일반화 이론**: 과매개변수화 네트워크가 왜 일반화하는가?
4. **기계적 해석가능성**: 네트워크가 무엇을 학습하는지 선형대수로 이해
5. **스케일링 법칙**: 계산, 데이터, 성능 사이의 멱법칙 관계

## 5. 12개 레슨 한눈에 보기

| # | 레슨 | 핵심 아이디어 | 핵심 공식 |
|---|------|-------------|----------|
| 01 | 벡터와 행렬 | 텐서 표기법, 행렬 미적분 규칙 | $\frac{\partial L}{\partial W} = \frac{\partial L}{\partial y} x^\top$ |
| 02 | 편미분 | 그래디언트 = 최대 상승 방향 | $\nabla f = (\frac{\partial f}{\partial x_1}, \ldots)$ |
| 03 | 연쇄 법칙 | 역전파 = 역방향 연쇄 법칙 | $\nabla_x L = J^\top \nabla_y L$ |
| 04 | 야코비안/헤시안 | 곡률이 최적화 난이도 결정 | $f \approx f_0 + g^\top \delta + \frac{1}{2}\delta^\top H \delta$ |
| 05 | 최적화 | 수렴은 매끄러움과 볼록성에 의존 | $x \leftarrow x - \eta \nabla f$ |
| 06 | 확률 | 분포 $\to$ 손실 함수 | MSE $\leftrightarrow$ 가우시안 |
| 07 | MLE | 학습 = NLL 최소화 | $\theta^* = \arg\min -\sum \log p$ |
| 08 | 정보 이론 | 교차 엔트로피 = 엔트로피 + KL | $H(p,q) = H(p) + D_{KL}$ |
| 09 | 행렬 분해 | SVD로 압축, 분석, 정규화 | $A = U\Sigma V^\top$ |
| 10 | 수치 안정성 | log-sum-exp, 안정 구현 | $\log\sum e^{z_i} = c + \log\sum e^{z_i-c}$ |
| 11 | 어텐션 수학 | $\sqrt{d_k}$ 스케일링으로 포화 방지 | $\text{Attn} = \text{softmax}(QK^\top/\sqrt{d_k})V$ |
| 12 | 종합 | 모든 수학이 학습 파이프라인에서 연결 | 이 레슨 |
