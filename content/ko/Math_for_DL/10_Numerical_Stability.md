# 레슨 10: 수치 안정성

## 학습 목표

- IEEE 754 부동소수점 표현과 그 한계를 이해한다
- 일반적인 DL 연산에서 오버플로우와 언더플로우를 식별한다
- 수치적으로 안정한 소프트맥스와 로그 소프트맥스를 위한 log-sum-exp 기법을 유도하고 적용한다
- 안정한 버전의 시그모이드, 이진 교차 엔트로피, 소프트맥스 교차 엔트로피를 구현한다
- 파국적 소거를 이해하고 방지하는 방법을 안다
- 혼합 정밀도 학습 개념과 fp16이 안전한 경우를 이해한다
- 학습 파이프라인에서 NaN과 Inf 값을 진단한다

---

## 1. 부동소수점 산술

| 형식 | 비트 | 범위 | 정밀도 |
|------|------|------|--------|
| float16 | 16 | $\pm 6.5 \times 10^4$ | $\sim 3$자리 |
| bfloat16 | 16 | $\pm 3.4 \times 10^{38}$ | $\sim 2$자리 |
| float32 | 32 | $\pm 3.4 \times 10^{38}$ | $\sim 7$자리 |
| float64 | 64 | $\pm 1.8 \times 10^{308}$ | $\sim 15$자리 |

---

## 2. 오버플로우와 언더플로우

- **오버플로우**: $e^{89} = \text{Inf}$ (float32)
- **언더플로우**: 많은 작은 확률의 곱이 0으로 $\to$ 로그를 취해 합으로 변환

---

## 3. Log-Sum-Exp 기법

### 3.1 문제

$\log \sum_i e^{z_i}$를 순진하게 계산하면 큰 $z_i$에서 오버플로우.

### 3.2 해결

$$\log \sum_{i} e^{z_i} = c + \log \sum_{i} e^{z_i - c}, \quad c = \max_i z_i$$

**작동 이유**: $c$를 뺀 후 모든 지수 $\leq 0$ (오버플로우 없음), 하나 이상의 지수 = 0 (합 $\geq 1$, 로그에서 언더플로우 없음).

---

## 4. 안정한 소프트맥스와 로그 소프트맥스

### 4.1 안정한 소프트맥스

$$\text{softmax}(z_i) = \frac{e^{z_i - c}}{\sum_j e^{z_j - c}}, \quad c = \max_j z_j$$

### 4.2 안정한 로그 소프트맥스

$$\log \text{softmax}(z_i) = z_i - c - \log \sum_j e^{z_j - c}$$

$\log(\text{softmax}(z))$보다 수치적으로 안정합니다.

---

## 5. 안정한 시그모이드와 교차 엔트로피

### 5.1 안정한 이진 교차 엔트로피

$$L = \max(z, 0) - yz + \log(1 + e^{-|z|})$$

로짓에서 직접 계산하여 오버플로우/언더플로우를 피합니다.

---

## 6. 파국적 소거

거의 같은 두 부동소수점 수를 빼면 상대 오차가 폭발:

| 위험 | 안전한 대안 |
|------|-----------|
| `np.exp(x) - 1` (작은 $x$) | `np.expm1(x)` |
| `np.log(1 + x)` (작은 $x$) | `np.log1p(x)` |
| $E[X^2] - (E[X])^2$ | 2-패스: `mean((x - mean(x))^2)` |

---

## 7. 혼합 정밀도 학습

### 7.1 이점

- **메모리**: fp16은 fp32의 절반
- **속도**: 전용 텐서 코어로 2-4배 처리량
- **통신**: 분산 학습에서 대역폭 감소

### 7.2 손실 스케일링

손실에 큰 인수 $S$를 곱한 후 역전파:
1. $L' = S \cdot L$ 계산 (fp16)
2. 역전파로 $S \cdot \nabla L$ 얻음 (큰 그래디언트, 언더플로우 감소)
3. 옵티마이저 스텝 전에 $S$로 나눔 (fp32)

---

## 8. NaN과 Inf 디버깅

| 증상 | 원인 | 수정 |
|------|------|------|
| 손실 = NaN | 0으로 나눔, log(0) | 엡실론 추가, 안정한 구현 사용 |
| 손실 = Inf | exp 오버플로우 | log-sum-exp, 그래디언트 클리핑 |
| 그래디언트 = NaN | sqrt(0) 그래디언트 | 입력 클램프, 엡실론 추가 |
| 갑작스러운 NaN | 학습률 너무 높음 | lr 감소, 워밍업 사용 |

---

## 요약

| 개념 | 핵심 요점 |
|------|----------|
| 부동소수점 | fp32는 $\sim 7$자리; fp16은 $\sim 3$자리, 범위 $\pm 65504$ |
| Log-sum-exp | $\log \sum e^{z_i} = c + \log \sum e^{z_i - c}$ ($c = \max z_i$) |
| 안정한 소프트맥스 | 지수화 전에 최댓값을 빼기 |
| 안정한 BCE | 로짓에서 $\max(z,0) - yz + \log(1 + e^{-|z|})$ |
| 파국적 소거 | 거의 같은 수의 뺄셈 피하기; `expm1`, `log1p` 사용 |
| 혼합 정밀도 | 속도를 위해 fp16; 언더플로우 방지를 위해 손실 스케일링 |
| NaN/Inf 디버그 | 엡실론 추가, 입력 클램프, 각 스텝 후 텐서 검사 |
