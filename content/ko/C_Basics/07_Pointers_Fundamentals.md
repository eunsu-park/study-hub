포인터는 C에서 가장 중요한 단일 개념입니다. 포인터는 다른 변수의 메모리 주소를 보유하는 변수입니다. 모든 동적 자료구조, 인자를 수정하는 모든 함수, C의 모든 시스템 수준 API가 포인터에 의존합니다. 이 레슨에서는 다이어그램, 예제, 흔한 실수를 통해 기초부터 이해를 쌓아갑니다.

## 1. 포인터란 무엇인가?

실행 중인 프로그램의 모든 변수는 메모리에서 하나 이상의 바이트를 차지하며, 각 바이트에는 고유한 숫자 **주소**가 있습니다. 포인터는 이러한 주소를 저장하는 변수입니다.

메모리를 번호가 매겨진 긴 우편함 행으로 생각하세요. 각 우편함(바이트)에는 주소가 인쇄되어 있습니다. 포인터는 그 주소 중 하나를 적어 놓은 종이 -- *어디를* 볼지 알려주지만, 거기에 무엇이 저장되어 있는지는 알려주지 않습니다.

```
Memory (simplified):
Address:  0x1000   0x1004   0x1008   0x100C
          +--------+--------+--------+--------+
          |   42   |  0x1000|  ...   |  ...   |
          +--------+--------+--------+--------+
Variable:    x         p
```

이 다이어그램에서 `x`는 주소 `0x1000`에 있고 값 `42`를 보유합니다. 포인터 `p`는 `0x1004`에 있고 값 `0x1000` -- `x`의 주소를 보유합니다.

## 2. 포인터 선언과 초기화

포인터 변수는 기본 타입과 변수 이름 사이에 `*`를 놓아 선언합니다.

```c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;   /* p는 x의 주소를 저장 */

    printf("Value of x:       %d\n", x);        /* 42 */
    printf("Address of x:     %p\n", (void *)&x); /* 예: 0x7ffd1234abcd */
    printf("Value of p:       %p\n", (void *)p);  /* 같은 주소 */
    printf("Value at *p:      %d\n", *p);        /* 42 */

    return 0;
}
```

| 기호 | 의미 | 예시 |
|------|------|------|
| `int *p` | `p`를 `int`에 대한 포인터로 선언 | `int *p;` |
| `&x` | 주소 연산자 — `x`의 주소를 얻음 | `p = &x;` |
| `*p` | 역참조 연산자 — `p`가 보유한 주소의 값에 접근 | `printf("%d", *p);` |

**NULL로 초기화**: 할당할 주소가 아직 없을 때는 포인터를 `NULL`(`<stddef.h>` 또는 `<stdio.h>`에 정의)로 초기화합니다.

```c
int *p = NULL;   /* 안전 — "아무것도 가리키지 않음"을 명확히 나타냄 */
```

## 3. 역참조(Dereferencing)

포인터를 역참조한다는 것은 주소를 따라가서 거기에 저장된 값을 읽거나 쓰는 것입니다.

```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int *p = &a;

    /* 포인터를 통해 읽기 */
    printf("a = %d\n", *p);   /* 10 */

    /* 포인터를 통해 쓰기 */
    *p = 25;
    printf("a = %d\n", a);    /* 25 — *p를 통해 a가 수정됨 */

    return 0;
}
```

### const와 포인터

`const` 키워드는 가리키는 값, 포인터 자체, 또는 둘 다를 보호할 수 있습니다.

```c
int x = 10, y = 20;

const int *p1 = &x;     /* const int에 대한 포인터 — *p1을 수정할 수 없음 */
/* *p1 = 30;  오류 */
p1 = &y;                /* OK — p1이 가리키는 곳을 변경할 수 있음 */

int *const p2 = &x;     /* int에 대한 const 포인터 — p2 자체를 변경할 수 없음 */
*p2 = 30;               /* OK — 값을 수정할 수 있음 */
/* p2 = &y;  오류 */

const int *const p3 = &x;  /* const int에 대한 const 포인터 — 아무것도 변경 불가 */
```

선언을 **오른쪽에서 왼쪽**으로 읽으세요: `const int *p` -> "p는 const인 int에 대한 포인터."

## 4. 포인터 산술

포인터 `p`에 정수 `n`을 더하면, 컴파일러는 주소를 `n`바이트가 아닌 `n * sizeof(*p)`바이트만큼 전진시킵니다. 이것이 배열의 포인터 순회를 자연스럽게 만드는 요소입니다.

```c
#include <stdio.h>

int main(void) {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;  /* arr[0]을 가리킴 */

    printf("*p       = %d\n", *p);       /* 10 */
    printf("*(p + 1) = %d\n", *(p + 1)); /* 20 */
    printf("*(p + 4) = %d\n", *(p + 4)); /* 50 */

    /* 포인터 전진 */
    p += 2;
    printf("*p after p+=2: %d\n", *p);   /* 30 */

    return 0;
}
```

| 표현식 | 결과 | 설명 |
|--------|------|------|
| `p + 1` | 다음 `int`의 주소 | `sizeof(int)`바이트만큼 전진 |
| `p - 1` | 이전 `int`의 주소 | `sizeof(int)`바이트만큼 후퇴 |
| `p2 - p1` | 요소 간 개수 | 바이트 수가 아닌 `ptrdiff_t` 반환 |
| `p++` | `p`를 다음 요소로 전진 | 후위 증가 |

## 5. 배열과 포인터

배열 이름은 대부분의 표현식에서 첫 번째 요소에 대한 포인터로 **퇴화(decay)**합니다. 즉, `arr`과 `&arr[0]`은 같은 주소를 생성합니다.

```c
#include <stdio.h>

int main(void) {
    int arr[] = {100, 200, 300};

    /* 다음은 동등합니다 */
    printf("%d\n", arr[1]);        /* 200 */
    printf("%d\n", *(arr + 1));    /* 200 */

    int *p = arr;
    printf("%d\n", p[2]);          /* 300 — 포인터 인덱싱도 작동 */
    printf("%d\n", *(p + 2));      /* 300 */

    return 0;
}
```

`arr[i]` == `*(arr + i)` 동등성은 단순한 편의가 아닙니다 -- C에서 `[]` 연산자의 **정의**입니다. 실제로 `i[arr]`도 합법적입니다 (덧셈은 교환법칙이 성립하므로). 물론 그렇게 코드를 작성해서는 안 됩니다.

**핵심 차이**: 배열 이름은 **수정 가능한 lvalue가 아닙니다**. `arr++`나 `arr = p`를 할 수 없습니다. 포인터 변수는 자유롭게 재할당할 수 있습니다.

## 6. 참조에 의한 전달(Pass-by-Reference)

C는 모든 인자를 **값에 의해** 전달합니다 -- 함수는 복사본을 받습니다. 함수가 호출자의 변수를 수정할 수 있게 하려면, 해당 변수에 대한 **포인터**를 전달합니다.

```c
#include <stdio.h>

/* 포인터를 사용한 전통적인 교환 */
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 20;
    printf("Before: x=%d, y=%d\n", x, y);  /* 10, 20 */

    swap(&x, &y);
    printf("After:  x=%d, y=%d\n", x, y);  /* 20, 10 */

    return 0;
}
```

또 다른 일반적인 용도 -- 오류 코드를 반환하고 결과를 포인터를 통해 쓰는 함수:

```c
#include <stdio.h>
#include <stdbool.h>

bool safe_divide(double numerator, double denominator, double *result) {
    if (denominator == 0.0) {
        return false;
    }
    *result = numerator / denominator;
    return true;
}

int main(void) {
    double answer;
    if (safe_divide(10.0, 3.0, &answer)) {
        printf("Result: %.4f\n", answer);  /* 3.3333 */
    } else {
        printf("Division by zero!\n");
    }
    return 0;
}
```

## 7. 포인터의 포인터(Pointer to Pointer)

포인터의 포인터는 다른 포인터 변수의 주소를 저장합니다. `**`로 선언합니다.

```c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;
    int **pp = &p;

    printf("x   = %d\n", x);     /* 42 */
    printf("*p  = %d\n", *p);    /* 42 */
    printf("**pp = %d\n", **pp); /* 42 */

    **pp = 99;
    printf("x   = %d\n", x);     /* 99 */

    return 0;
}
```

메모리 다이어그램:

```
  pp            p             x
+--------+   +--------+   +--------+
| &p     |-->| &x     |-->|   99   |
+--------+   +--------+   +--------+
```

**일반적인 사용 사례**:
- 함수 내에서 포인터를 수정 (예: `void alloc(int **out)`)
- 문자열 배열 (`char *argv[]`는 `char **argv`와 동등)
- 동적 2차원 배열 (행에 대한 포인터 배열)

## 8. 흔한 포인터 실수

### 초기화되지 않은 포인터

```c
int *p;          /* p는 쓰레기 값 — 임의의 주소 */
*p = 10;         /* 미정의 동작 — 알 수 없는 메모리에 쓰기 */
```

**해결**: 포인터를 항상 `NULL` 또는 유효한 주소로 초기화하세요.

### 댕글링 포인터(Dangling Pointer)

해제되었거나 스코프를 벗어난 메모리를 참조하는 포인터입니다.

```c
int *get_local(void) {
    int local = 42;
    return &local;  /* 경고: 함수가 반환되면 local이 파괴됨 */
}

int main(void) {
    int *p = get_local();
    printf("%d\n", *p);  /* 미정의 동작 — 댕글링 포인터 */
    return 0;
}
```

**해결**: 지역 변수의 주소를 절대 반환하지 마세요. `static`을 사용하거나, 버퍼를 전달하거나, 힙에 할당하세요.

### NULL 역참조

```c
int *p = NULL;
*p = 10;         /* 충돌 — 대부분의 시스템에서 세그멘테이션 폴트 */
```

**해결**: 역참조하기 전에 항상 `NULL`을 검사하세요.

```c
if (p != NULL) {
    *p = 10;
}
```

### 와일드 포인터(Wild Pointer)

해제되었지만 `NULL`로 설정되지 않은 포인터가 다시 사용되는 경우입니다.

```c
#include <stdlib.h>

int *p = malloc(sizeof(int));
*p = 42;
free(p);
/* p는 여전히 이전 주소를 보유 — "와일드" 상태 */
*p = 10;    /* 미정의 동작 — use-after-free */

/* 해결: free 직후 NULL로 설정 */
free(p);
p = NULL;
```

| 실수 | 증상 | 예방 |
|------|------|------|
| 초기화되지 않은 포인터 | 무작위 충돌 | `NULL` 또는 `&var`로 초기화 |
| 댕글링 포인터 | 간헐적 손상 | 지역 변수의 주소를 반환하지 않기 |
| NULL 역참조 | 세그폴트 | 역참조 전 검사 |
| 와일드 포인터 | use-after-free | `free` 후 `NULL`로 설정 |
