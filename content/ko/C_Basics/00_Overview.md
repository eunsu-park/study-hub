# C 기초

이 토픽은 환경 설정부터 포인터, 구조체, 파일 입출력까지 C 프로그래밍의 기초를 다루며, 실습 미니 프로젝트로 마무리됩니다. 첫 번째 컴파일 언어를 배우는 경우든 Python과 같은 고급 언어에서 전환하는 경우든, 이 레슨들을 통해 C가 하드웨어에 가까이 작동하는 방식과 시스템 프로그래밍, 임베디드 개발, 성능 중심 애플리케이션에서 여전히 필수적인 이유를 확실히 이해할 수 있습니다.

## 학습 내용

이 토픽에서는 다음을 실습 중심으로 다룹니다:

- **시작하기**: 컴파일러 설치, 도구 체인 설정, 첫 번째 컴파일 프로그램
- **핵심 언어**: 변수, 데이터 타입, 연산자, 표현식, 제어 흐름
- **함수**: 선언, 정의, 스코프 규칙, 재귀, 저장 클래스
- **배열과 문자열**: 고정 크기 배열, 다차원 배열, 널 종단 문자열, 표준 라이브러리 문자열 함수
- **포인터(Pointer)**: 주소 연산자와 역참조 연산자, 포인터 산술, 배열과 포인터, 참조에 의한 전달
- **구조체와 공용체**: 복합 데이터 타입, typedef, 열거형, 비트 필드
- **메모리 관리**: malloc/calloc/realloc/free를 이용한 동적 할당과 메모리 누수 방지
- **파일 입출력**: 표준 입출력 라이브러리를 사용한 텍스트 및 바이너리 파일 읽기/쓰기
- **빌드 도구**: 전처리기 지시문, 헤더 가드, Makefile, 컴파일러 플래그, GDB 디버깅
- **프로젝트**: 이전 레슨의 개념을 통합하는 3개의 가이드 프로젝트

## 선수 과목

- [프로그래밍](../Programming/00_Overview.md) — 일반적인 프로그래밍 개념(변수, 제어 흐름, 함수)에 대한 이해

C에 대한 사전 경험은 필요하지 않습니다. 어떤 언어에서든 변수, 루프, 함수가 무엇인지 이해하고 있다면 준비가 된 것입니다.

## 권장 학습 순서

01부터 15까지 순서대로 레슨을 따라가세요. 각 레슨은 이전 레슨에서 소개된 개념을 기반으로 합니다:

1. **환경 설정 (레슨 1)**: C 컴파일러를 설치하고 실행합니다
2. **언어 기초 (레슨 2-4)**: 변수, 연산자, 제어 흐름은 모든 C 프로그램의 근간입니다
3. **함수 (레슨 5)**: 코드를 재사용 가능하고 스코프가 잘 정의된 함수로 구성합니다
4. **배열과 문자열 (레슨 6)**: 고정 크기 컬렉션과 널 종단 문자열을 다룹니다
5. **포인터와 구조체 (레슨 7-8)**: 메모리 주소를 이해하고 복합 데이터 타입을 구축합니다
6. **메모리와 입출력 (레슨 9-10)**: 런타임에 메모리를 할당하고 파일 시스템과 상호작용합니다
7. **빌드 인프라 (레슨 11-12)**: 전처리기, Makefile, 디버깅 도구를 마스터합니다
8. **프로젝트 (레슨 13-15)**: 배운 모든 것을 점점 복잡해지는 3개의 프로젝트에 적용합니다

## 실습 환경

C 컴파일러 설치를 확인합니다:

```bash
gcc --version
# gcc (GCC) 13.x.x (또는 그 이상)

# 빠른 테스트
echo '#include <stdio.h>
int main(void) { printf("Ready!\n"); return 0; }' > test.c
gcc -Wall -Wextra -std=c11 test.c -o test && ./test
rm -f test test.c
```

각 레슨의 예제 코드는 `examples/C_Basics/`에서 확인할 수 있습니다.
