# Python 기초

이 토픽은 설치부터 실용적인 프로그래밍 패턴까지 Python의 기초를 다룹니다. 첫 스크립트를 작성하든 핵심 개념에 대한 이해를 다지든, 이 레슨들은 데이터 과학, 웹 개발, 자동화 등 수많은 분야에서 사용되는 언어에 대한 탄탄한 기초를 제공합니다.

## 학습 내용

이 토픽은 다음의 실습 중심 내용을 제공합니다:
- **시작하기**: 설치, REPL, 가상 환경 및 도구
- **핵심 언어**: 변수 (Variable), 데이터 타입 (Data Type), 연산자 (Operator), 표현식 (Expression), 제어 흐름 (Control Flow)
- **함수 (Function)**: 함수 정의, 호출, Python의 풍부한 매개변수 시스템을 활용한 합성
- **데이터 구조 (Data Structure)**: 리스트 (List), 튜플 (Tuple), 딕셔너리 (Dictionary), 집합 (Set), 컴프리헨션 (Comprehension)
- **문자열 (String)**: 포맷팅, 메서드, 정규 표현식, 유니코드
- **객체 지향 프로그래밍 (OOP)**: 클래스 (Class), 상속 (Inheritance), 다형성 (Polymorphism), 던더 메서드 (Dunder Method), 데이터클래스 (Dataclass)
- **모듈과 패키지 (Module & Package)**: 임포트, 프로젝트 구조화, 표준 라이브러리
- **파일 I/O와 예외 (Exception)**: 파일 읽기/쓰기, 오류 처리, 컨텍스트 관리자 (Context Manager)
- **파이썬다운 스타일 (Pythonic Style)**: 관용구, 모범 사례, 유창한 Python 코드를 구별하는 패턴

## 사전 요구사항

## 권장 학습 순서

01부터 14까지 순서대로 진행하세요. 각 레슨은 이전 레슨에서 소개된 개념을 기반으로 합니다:

1. **환경 설정 (레슨 1)**: Python 설치 및 실행
2. **언어 기초 (레슨 2-4)**: 변수, 연산자, 제어 흐름은 모든 프로그램의 뼈대를 형성합니다
3. **함수 (레슨 5)**: 코드를 재사용 가능한 블록으로 정리하는 방법을 배웁니다
4. **데이터 구조와 문자열 (레슨 6-7)**: Python의 내장 컬렉션과 텍스트 처리를 마스터합니다
5. **객체 지향 프로그래밍 (레슨 8-9)**: 클래스로 실세계 개념을 모델링합니다
6. **프로젝트 구성 (레슨 10)**: 코드를 모듈과 패키지로 구조화합니다
7. **I/O와 오류 처리 (레슨 11-12)**: 파일 시스템과 상호작용하고 실패를 우아하게 처리합니다
8. **숙달 (레슨 13-14)**: 표준 라이브러리를 활용하고 파이썬다운 코드를 작성합니다

## 실습 환경

Python 설치를 확인하세요:

```bash
python3 --version
# Python 3.12.x (or newer)
```

연습문제를 위한 전용 가상 환경을 설정하세요:

```bash
# Create a virtual environment
python3 -m venv ~/.venvs/python-basics

# Activate it
source ~/.venvs/python-basics/bin/activate   # macOS / Linux
# .\.venvs\python-basics\Scripts\activate    # Windows

# Confirm
which python
python --version
```

각 레슨의 예제 코드는 `examples/Python_Basics/`에서 사용할 수 있습니다.
