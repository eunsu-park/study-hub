# 객체 지향 프로그래밍

복잡한 소프트웨어 시스템을 구조화하는 지배적인 패러다임인 객체 지향 프로그래밍(OOP)에 대한 종합 가이드입니다. 클래스와 객체 같은 기초 개념부터 SOLID 원칙, 디자인 패턴, 현대 Python OOP 기능까지 폭넓게 다룹니다. 설명은 언어에 구애받지 않지만, 모든 구현은 명확성과 접근성을 위해 Python을 사용합니다.

## 학습 내용

이 토픽은 다음을 상세히 다룹니다:
- **핵심 구성 요소**: 클래스, 객체, 생성자, 속성, 메서드
- **네 가지 기둥**: 캡슐화, 상속, 다형성, 추상화
- **합성 패턴**: 합성 vs 상속, 위임, 믹스인
- **설계 원칙**: 유지보수 가능하고 확장 가능한 코드를 위한 SOLID 원칙
- **디자인 패턴**: GoF의 대표 패턴 (Singleton, Factory, Observer, Strategy)
- **Python OOP 기능**: 매직 메서드, 데이터클래스, 프로토콜, 현대적 관용구
- **모범 사례**: 안티패턴 회피, 리팩토링 전략, 실전 가이드라인

## 사전 요구사항

- **기본 프로그래밍 지식**: 변수, 제어 흐름, 함수, 기본 자료구조
- **Python 문법에 대한 친숙함**: [프로그래밍](../Programming/00_Overview.md) 토픽 권장
