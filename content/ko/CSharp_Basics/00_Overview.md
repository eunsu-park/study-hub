# C# 기초

이 토픽은 환경 설정부터 제네릭, 예외 처리, 파일 I/O까지 C# 프로그래밍의 기초를 다룹니다. 첫 번째 객체지향 언어를 배우는 경우든 Python, Java, C++에서 전환하는 경우든, 이 레슨들은 C# 타입 시스템, .NET 런타임, 그리고 현대적인 C# 관용구에 대한 탄탄한 이해를 제공합니다. C#은 데스크톱 애플리케이션, 웹 서비스, 클라우드 컴퓨팅, Unity를 이용한 게임 개발, .NET MAUI를 이용한 크로스 플랫폼 모바일 앱 등에 사용되는 다재다능하고 강력한 타입의 언어입니다.

## 학습 내용

이 토픽은 다음 내용을 실습 중심으로 다룹니다:

- **시작하기**: .NET SDK 설치, `dotnet` CLI, Hello World, 프로젝트 구조, 컴파일 파이프라인
- **변수와 타입**: 값 타입(Value Type), 참조 타입(Reference Type), `var`, `const`, 널러블 타입(Nullable Type), 타입 변환
- **연산자와 표현식**: 산술, 비교, 논리, 비트 연산, 널 병합(Null-Coalescing), 검사된 산술(Checked Arithmetic)
- **제어 흐름**: `if`/`else`, `switch` 문과 표현식, `for`, `foreach`, `while`, 패턴 매칭 기초
- **메서드**: 매개변수 전달(`ref`/`out`/`in`/`params`), 오버로딩, 로컬 함수, 재귀, 튜플 반환
- **배열과 문자열**: 단일 및 다차원 배열, 가변 배열(Jagged Array), 문자열 보간(String Interpolation), `StringBuilder`
- **열거형과 구조체**: 열거형(Enum), 플래그(Flags), 구조체(Struct), 값 vs 참조 의미론
- **컬렉션**: `List<T>`, `Dictionary<TKey,TValue>`, `HashSet<T>`, `Queue<T>`, `Stack<T>`, LINQ 기초
- **클래스와 객체**: 생성자, 필드, 프로퍼티, 접근 한정자, 정적 멤버
- **프로퍼티와 인덱서**: 자동 프로퍼티(Auto-Property), init 전용 세터, 계산된 프로퍼티, 인덱서(Indexer)
- **상속**: `virtual`/`override`/`abstract`, `sealed`, `base`, `is`/`as`를 이용한 타입 검사
- **인터페이스**: 인터페이스 설계, 기본 인터페이스 메서드(Default Interface Method), 다중 구현
- **제네릭**: 제네릭 클래스와 메서드, 제약 조건(Constraint), 공변성(Covariance)과 반공변성(Contravariance)
- **예외 처리**: `try`/`catch`/`finally`, 사용자 정의 예외, 예외 필터(Exception Filter)
- **파일 I/O**: `File`과 `Stream` API, 텍스트 및 바이너리 I/O, `using` 문

## 사전 요구사항

- [프로그래밍](../Programming/00_Overview.md) — 일반적인 프로그래밍 개념(변수, 제어 흐름, 함수)에 대한 기본 지식

사전 C# 경험은 필요하지 않습니다. 어떤 언어에서든 변수, 반복문, 함수가 무엇인지 이해하고 있다면 준비가 된 것입니다.

## 권장 학습 순서

레슨 01부터 15까지 순서대로 학습하세요. 각 레슨은 이전 레슨에서 소개된 개념을 기반으로 합니다:

1. **시작하기 (레슨 1)**: .NET SDK를 설치하고 첫 번째 C# 프로그램을 실행합니다
2. **언어 기초 (레슨 2-4)**: 변수, 연산자, 제어 흐름은 모든 C# 프로그램의 핵심입니다
3. **메서드 (레슨 5)**: 유연한 매개변수 전달로 코드를 재사용 가능한 함수로 구성합니다
4. **자료 구조 (레슨 6-8)**: 배열, 문자열, 열거형, 구조체, 컬렉션 클래스를 다룹니다
5. **객체지향 프로그래밍 (레슨 9-12)**: 클래스, 프로퍼티, 상속, 인터페이스를 학습합니다
6. **제네릭 (레슨 13)**: 제네릭 클래스와 메서드로 타입 안전하고 재사용 가능한 코드를 작성합니다
7. **에러 처리와 I/O (레슨 14-15)**: 예외를 우아하게 처리하고 파일 시스템을 다룹니다

## 실습 환경

.NET SDK 설치를 확인합니다:

```bash
dotnet --version
# 8.0.x (또는 그 이상)

# 빠른 테스트
dotnet new console -n test_app && cd test_app && dotnet run
# 출력: Hello, World!
cd .. && rm -rf test_app
```

각 레슨의 예제 코드는 `examples/CSharp_Basics/`에서 확인할 수 있습니다.
