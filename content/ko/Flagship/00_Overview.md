# Flagship 학습 가이드

## 소개

이 폴더는 **Flagship 프로젝트** 모음으로, 핵심 딥러닝 아이디어를 **단일 파일, 최소 의존성** 구현으로 증류하여 학습하는 실전 프로젝트입니다. 각 프로젝트는 하나의 독립적인 Python 파일로, 200-400줄 이내에 완전한 학습·추론 파이프라인을 담고 있습니다.

Flagship 프로젝트의 목표는 프레임워크의 추상화에 의존하지 않고, 핵심 알고리즘의 **수학적 원리와 구현 세부사항**을 동시에 이해하는 것입니다.

## 프로젝트 규칙

모든 Flagship 프로젝트는 다음 규칙을 따릅니다:

1. **단일 파일**: 각 프로젝트는 하나의 `.py` 파일로 구성
2. **200-400줄**: 코어 로직 기준 (import, 공백, 주석 제외)
3. **크기 접두사 네이밍**: `Micro`, `Tiny`, `Nano`, `Pico` 등으로 규모를 명시
4. **최소 의존성**: NumPy만 사용하거나, 최소한의 외부 라이브러리만 허용
5. **완전한 파이프라인**: 데이터 생성 → 학습 → 평가를 모두 포함
6. **교육적 주석**: 코드에 수학적 배경과 설계 의도를 상세히 주석 처리

## 선행 토픽

각 프로젝트를 시작하기 전에 아래 토픽에 대한 기초 이해가 필요합니다:

| 프로젝트 | 선행 토픽 |
|---------|----------|
| Micro Autograd | Deep_Learning, Math_for_AI, Calculus_and_Differential_Equations |
| Tiny GAN | Deep_Learning, Probability_and_Statistics |
| Nano RL | Reinforcement_Learning, Probability_and_Statistics |
| Pico Diffusion | Deep_Learning, Probability_and_Statistics |
| Micro VAE | Deep_Learning, Probability_and_Statistics |

## 추천 학습 순서

```
┌──────────────────┐
│  Micro Autograd  │  ← 자동 미분의 기초, 가장 먼저 학습
│  (L01)           │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐     ┌──────────────────┐
│    Tiny GAN      │     │    Micro VAE     │  ← GAN과 VAE는 병렬 학습 가능
│    (L02)         │     │    (L05)         │
└────────┬─────────┘     └────────┬─────────┘
         │                        │
         ▼                        ▼
┌──────────────────┐     ┌──────────────────┐
│    Nano RL       │     │  Pico Diffusion  │  ← 각각 독립적으로 학습 가능
│    (L03)         │     │  (L04)           │
└──────────────────┘     └──────────────────┘
```

**권장 경로**:
1. **Micro Autograd** (L01)로 시작 — 자동 미분과 연산 그래프의 핵심 이해
2. **Tiny GAN** (L02) — 적대적 학습과 생성 모델의 기초
3. **Nano RL** (L03) — 정책 그래디언트와 강화학습 핵심
4. **Pico Diffusion** (L04) — 확산 모델의 수학적 기초
5. **Micro VAE** (L05) — 변분 추론과 잠재 변수 모델
