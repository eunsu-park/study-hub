# CSharp 고급

CSharp 고급은 C# 프로그래밍의 기초를 넘어 현대 소프트웨어 구축에 가장 생산적인 언어 중 하나로 만드는 강력하고 표현력 있는 기능들을 다루는 종합 과정입니다. 이 과정은 고급 타입 시스템 기능, 비동기 프로그래밍, 성능 최적화, 그리고 전문적인 .NET 개발에서 사용되는 실무 아키텍처 패턴을 다룹니다. 이 과정을 마치면 클라우드 서비스부터 시스템 프로그래밍까지 모든 영역에서 관용적이고, 고성능이며, 유지보수 가능한 C# 코드를 작성할 수 있게 됩니다.

---

## 학습 내용

- **함수형 프로그래밍 패턴** — 델리게이트, 이벤트, 람다, 클로저, 그리고 선언적 데이터 처리를 위한 LINQ
- **현대 타입 시스템 기능** — 패턴 매칭, nullable 참조 타입, 레코드, 불변성
- **비동기 프로그래밍** — async/await, Task 기반 패턴, 취소, ValueTask
- **동시성과 병렬성** — 스레드, Parallel, 동시 컬렉션, 채널, 동기화
- **메모리 효율적 프로그래밍** — Span\<T\>, Memory\<T\>, stackalloc, 할당 감소 기법
- **소프트웨어 엔지니어링 실천** — 의존성 주입, 직렬화, 테스팅, NuGet 패키징
- **저수준 기능** — 리플렉션, 특성, P/Invoke, unsafe 코드, 소스 생성기
- **성능 프로파일링** — BenchmarkDotNet, dotnet-counters, 할당 분석
- **풀스택 통합** — EF Core, 인증, 테스팅을 포함한 프로덕션 수준의 Minimal Web API 구축

---

## 사전 요구사항
