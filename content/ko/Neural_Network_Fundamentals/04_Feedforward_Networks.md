## 학습 목표(Learning Objectives)

이 레슨을 완료하면 다음을 할 수 있습니다:

1. 다층 퍼셉트론(MLP)의 구조를 정의할 수 있습니다
2. 순전파를 행렬 연산의 연속으로 표현할 수 있습니다
3. NumPy를 사용하여 임의 깊이의 MLP 순전파를 구현할 수 있습니다
4. 각 층 유형(입력, 은닉, 출력)의 역할을 설명할 수 있습니다
5. MLP의 총 파라미터 수를 계산할 수 있습니다
6. 2층 MLP의 계산 그래프를 그릴 수 있습니다
7. 너비와 깊이의 차이와 용량에 미치는 영향을 구분할 수 있습니다
8. 적절한 표기법을 사용할 수 있습니다 (층은 위첨자, 뉴런은 아래첨자)

---

순전파 신경망 -- 다층 퍼셉트론(MLP)이라고도 함 -- 은 가장 간단한 심층 구조입니다. 데이터는 한 방향으로만 흐릅니다: 입력에서 출력으로, 하나 이상의 은닉층을 거쳐. 단순함에도 불구하고, MLP는 모든 현대 아키텍처(CNN, RNN, Transformer)가 구축된 기반입니다.

---

## 1. MLP 구조

### 1.1 용어

```
입력 레이어        은닉 레이어 1       은닉 레이어 2       출력 레이어
(n0개 뉴런)        (n1개 뉴런)        (n2개 뉴런)         (n3개 뉴런)

  x1 ─────────┬──► h1^(1) ────────┬──► h1^(2) ────────┬──► y1
              │                   │                   │
  x2 ─────────┼──► h2^(1) ────────┼──► h2^(2) ────────┼──► y2
              │                   │                   │
  x3 ─────────┼──► h3^(1) ────────┼──►   ...  ────────┤
              │                   │                   │
  x4 ─────────┘    ...            └───────────────────┘

  레이어 0          레이어 1            레이어 2            레이어 3
  (입력)            (은닉)              (은닉)              (출력)
```

**핵심 용어**:
- **입력층** (Layer 0): 원시 특성을 받음. 계산 없음.
- **은닉층** (Layer l): 선형 변환 + 활성화 수행. 출력을 직접 관찰할 수 없어 "은닉"이라 함.
- **출력층** (Layer L): 최종 예측 생성. 활성화는 작업에 따라 다름.
- **깊이(Depth)**: 학습 가능한 파라미터가 있는 층의 수 (은닉 + 출력).
- **너비(Width)**: 층 내 뉴런 수.
- **완전 연결(Dense)**: 층 l의 모든 뉴런이 층 l+1의 모든 뉴런과 연결.

## 2. 순전파

### 2.1 단일 층 계산

층 l에서 n_l개 뉴런이 크기 n_{l-1}의 입력 a^(l-1)을 받을 때:

```
z^(l) = W^(l) · a^(l-1) + b^(l)     (선형 변환)
a^(l) = σ(z^(l))                      (활성화 함수)
```

### 2.2 전체 순전파

L층 네트워크에 대해:

```
a^(0) = x                                         (입력)
z^(1) = W^(1) · a^(0) + b^(1)                     (층 1 선활성화)
a^(1) = σ(z^(1))                                   (층 1 활성화)
...
z^(L) = W^(L) · a^(L-1) + b^(L)                   (출력 선활성화)
a^(L) = σ_out(z^(L))                               (출력 활성화)

ŷ = a^(L)
```

---

## 3. 행렬 차원

### 3.1 형상 규칙

레이어 크기 [n0, n1, n2, ..., nL]인 네트워크에 대해:

```
층 l:
  W^(l):  형상 (n_l, n_{l-1})     ← n_l 행, n_{l-1} 열
  b^(l):  형상 (n_l, 1)           ← 뉴런당 편향 하나
  z^(l):  형상 (n_l, 1)           ← 뉴런당 선활성화 하나
  a^(l):  형상 (n_l, 1)           ← 뉴런당 활성화 하나
```

### 3.2 예시: 네트워크 [4, 8, 6, 3]

```
층 1: W^(1)은 (8, 4),  b^(1)은 (8, 1)  →  8×4 + 8 = 40 파라미터
층 2: W^(2)은 (6, 8),  b^(2)은 (6, 1)  →  6×8 + 6 = 54 파라미터
층 3: W^(3)은 (3, 6),  b^(3)은 (3, 1)  →  3×6 + 3 = 21 파라미터

총 파라미터: 40 + 54 + 21 = 115
```

### 3.3 파라미터 수 공식

```
총 파라미터 = Σ_{l=1}^{L} (n_l × n_{l-1} + n_l) = Σ_{l=1}^{L} n_l × (n_{l-1} + 1)
```

## 4. 배치 처리

실제로는 행렬 연산을 사용하여 여러 샘플을 동시에 처리합니다:

```
단일 샘플:
  a^(0) = x          형상: (n0, 1)

m개 샘플의 배치:
  A^(0) = X           형상: (n0, m)     ← 각 열이 하나의 샘플
  Z^(l) = W·A + b     형상: (n_l, m)    ← b는 열 방향으로 브로드캐스트
```

행렬-행렬 곱셈은 CPU/GPU 병렬성을 활용합니다 (BLAS, CUDA). 샘플을 개별 처리하는 것 대비 종종 10-100배 속도 향상.

## 5. 너비 vs. 깊이

### 5.1 깊이: 더 많은 층

- 더 많은 깊이 → **계층적** 특성을 학습할 수 있음
- 너무 많은 깊이 → 기울기 소실, 학습이 더 어려움
- 깊은 네트워크는 넓고 얕은 네트워크보다 **파라미터 효율적**

### 5.2 실용적 가이드라인

```
┌──────────────────────────────────────────────────────────┐
│ 1-2개의 은닉층으로 시작.                                   │
│ 은닉층당 64-256개의 뉴런 사용.                              │
│ 구조화된 데이터에는 너비보다 깊이를 우선 증가.                │
│ 매우 깊은 네트워크에는 스킵 연결(ResNet) 사용.              │
└──────────────────────────────────────────────────────────┘
```

## 6. 일반적인 MLP 구조

### 6.1 이진 분류

```
[n_features] → [64] → [32] → [1]
  입력         ReLU    ReLU   Sigmoid
```

### 6.2 다중 클래스 분류 (K개 클래스)

```
[n_features] → [128] → [64] → [K]
  입력          ReLU    ReLU   Softmax
```

### 6.3 회귀

```
[n_features] → [64] → [32] → [1]
  입력         ReLU    ReLU   항등 (활성화 없음)
```

## 7. 요약

```
핵심 정리
═══════════════════════════════════════════════════════
1. MLP = 입력 → 은닉층 → 출력 (완전 연결)
2. 순전파: z = W·a + b, 그 다음 a = σ(z) (층별)
3. 행렬 차원: W^(l)은 (n_l × n_{l-1})
4. 배치 처리: m개 샘플을 동시에 처리
5. 총 파라미터 = Σ n_l × (n_{l-1} + 1)
6. 깊이는 계층적 특성을; 너비는 용량을 추가
7. 출력 활성화는 작업에 따라 (Sigmoid/Softmax/항등)
═══════════════════════════════════════════════════════
```
