## 학습 목표(Learning Objectives)

이 레슨을 완료하면 다음을 할 수 있습니다:

1. 신경망이 과적합에 취약한 이유를 설명할 수 있습니다
2. L1과 L2 정규화를 구현하고 기하학적 해석을 설명할 수 있습니다
3. 드롭아웃을 밑바닥부터 구현하고 이론적 근거를 설명할 수 있습니다
4. 검증 손실 모니터링을 사용한 조기 종료를 적용할 수 있습니다
5. 파라미터, 활성화, 데이터 수준의 정규화를 구분할 수 있습니다
6. 여러 정규화 기법을 효과적으로 결합할 수 있습니다
7. 검증 성능을 사용하여 정규화 하이퍼파라미터를 튜닝할 수 있습니다
8. 정규화와 베이지안 사전 확률의 관계를 설명할 수 있습니다

---

신경망은 수백만(또는 수십억)개의 파라미터를 가지며, 학습 예제 수보다 훨씬 많습니다. 제약 없이 방치하면 일반화 가능한 패턴을 학습하는 대신 학습 데이터를 외울 것입니다. 정규화는 이러한 과적합을 방지하는 기법의 집합으로, 모델을 더 단순하고 견고하게 제약합니다.

## 1. 과적합 문제

```
과소적합                좋은 적합                과적합
(높은 편향)             (균형)                  (높은 분산)

패턴을 포착하기에        실제 패턴을              노이즈를 외움,
너무 단순               포착                    새 데이터에서 실패
```

---

## 2. L2 정규화 (가중치 감쇠)

### 2.1 공식

```
J_reg = J_data + (λ/2) · Σ ||W^(l)||_F^2

기울기에 대한 효과:
∂J_reg/∂W = ∂J_data/∂W + λ · W

업데이트 규칙:
W ← (1 - η·λ) · W - η · ∂J_data/∂W
     └────────┘
     "가중치 감쇠" — 매 스텝마다 가중치를 0 쪽으로 줄임
```

### 2.2 기하학적 해석

L2는 가중치를 구(ball) 안에 제약합니다. 가중치를 비례적으로 축소하며, 큰 가중치에 더 큰 페널티를 줍니다.

---

## 3. L1 정규화 (Lasso)

```
J_reg = J_data + λ · Σ |W^(l)|

기울기: ∂J_reg/∂w = ∂J_data/∂w + λ · sign(w)
```

| 특성 | L1 | L2 |
|------|----|----|
| 희소성 | 예 (특성 선택) | 아니오 (모든 가중치 유지) |
| 기울기 | 상수 크기 | 가중치에 비례 |
| 사용 사례 | 특성 선택 | 일반 정규화 |

---

## 4. 드롭아웃

### 4.1 아이디어

학습 중, 각 순전파에서 뉴런 활성화의 비율 p를 무작위로 0으로 설정합니다.

### 4.2 드롭아웃이 작동하는 이유

1. **앙상블 효과**: 각 학습 스텝이 다른 "서브 네트워크"를 학습. 최종 모델은 2^n 가능한 서브 네트워크의 평균.
2. **중복성**: 뉴런이 공적응(co-adapt)할 수 없어, 각 뉴런이 독립적으로 유용해야 함.
3. **노이즈 주입**: 활성화 공간에서의 데이터 증강 형태.

### 4.3 역 드롭아웃(Inverted Dropout, 표준 구현)

```
학습 시:
  mask = (random > p)              # 이진 마스크
  a_dropped = a * mask / (1 - p)   # 보상을 위해 스케일업

추론 시:
  a_output = a                     # 드롭아웃 없음, 스케일링 없음
```

### 4.4 드롭아웃 비율

| 레이어 유형 | 일반적 비율 (p = 드롭 확률) |
|------------|--------------------------|
| 입력층 | 0.0 - 0.2 |
| 은닉층 | 0.2 - 0.5 |
| 출력층 | 0.0 (절대 드롭아웃 안 함) |

---

## 5. 조기 종료(Early Stopping)

학습 중 검증 손실을 모니터링합니다. 증가하기 시작하면 중단합니다:

```
Loss
  │
  │  ╲ train
  │   ╲───────────────── train은 계속 감소
  │      ╲  val
  │       ╲───── ← 여기서 중단 (최적 검증)
  │            ╲   val이 증가 시작 → 과적합
  └──────────────────────────► epoch
```

---

## 6. 데이터 증강

레이블을 보존하는 변환을 적용하여 학습 세트의 크기와 다양성을 인위적으로 늘립니다.

| 도메인 | 기법 |
|--------|------|
| 이미지 | 뒤집기, 회전, 자르기, 색상 변환 |
| 텍스트 | 동의어 대체, 역번역 |
| 테이블형 | 특성 노이즈, SMOTE |

---

## 7. 베이지안 해석

- **L2 = 가우시안 사전 확률**: L2 정규화는 가중치에 가우시안 사전 확률 P(w) = N(0, 1/λ)을 부여하는 것과 동일
- **L1 = 라플라스 사전 확률**: L1 정규화는 라플라스 사전 확률에 해당. 0에서의 날카로운 피크가 희소성을 촉진

---

## 8. 요약

```
핵심 정리
═══════════════════════════════════════════════════════
1. 과적합: 네트워크가 패턴 대신 노이즈를 외움
2. L2 (가중치 감쇠): 가중치를 줄이고, 큰 값을 방지
3. L1 (Lasso): 희소성을 촉진, 일부 가중치를 정확히 0으로
4. 드롭아웃: 뉴런을 무작위로 0으로, 앙상블 효과 생성
5. 조기 종료: 검증 손실 개선이 멈추면 중단
6. 데이터 증강: 학습 데이터 다양성 증가
7. 기법을 신중하게 결합; 검증 성능으로 튜닝
8. 정규화 = 가중치에 대한 암시적 베이지안 사전 확률
═══════════════════════════════════════════════════════
```
