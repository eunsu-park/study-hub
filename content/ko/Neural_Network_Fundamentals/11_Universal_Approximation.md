보편 근사 정리(UAT)는 신경망에 대한 가장 중요한 이론적 결과 중 하나입니다. 단일 은닉층을 가진 신경망이 충분한 뉴런만 있다면 어떤 연속 함수든 임의의 정확도로 근사할 수 있다고 말합니다. 이 결과는 왜 신경망이 그토록 강력한지 설명하지만, 모든 실무자가 이해해야 할 중요한 한계도 있습니다.

---

## 1. 정리

### 1.1 비형식적 진술

> 유한 개의 뉴런을 포함하는 단일 은닉층을 가진 순전파 신경망은 R^n의 컴팩트 부분집합 위의 임의의 연속 함수를, 원하는 만큼의 정확도로 근사할 수 있습니다.

### 1.2 형식적 진술 (Cybenko, 1989; Hornik, 1991)

σ가 비상수, 유계, 연속 활성화 함수(예: 시그모이드)라 합시다. 임의의 연속 함수 f: [0,1]^n → R, 임의의 ε > 0에 대해, N ∈ N, 가중치, 편향, 출력 가중치가 존재하여:

```
F(x) = Σ_{i=1}^{N} v_i · σ(w_i · x + b_i)

다음을 만족: |F(x) - f(x)| < ε    모든 x ∈ [0,1]^n에 대해
```

---

## 2. 직관적 증명: 범프로 함수 만들기

### 2.1 시그모이드를 근사 계단 함수로

가중치 w가 매우 클 때, σ(w·x + b)는 계단 함수에 근사합니다.

### 2.2 두 시그모이드로 범프 만들기

```
bump(x) = σ(w(x - a)) - σ(w(x - b))      (a < b)

하나의 "범프" (볼록한 영역)를 생성합니다.
```

### 2.3 범프를 스케일링하여 목표 함수에 맞추기

목표 함수의 각 영역에 대해 하나의 범프를 만들고, 함수 값에 맞게 스케일링합니다. 더 많은 범프(뉴런) → 더 나은 근사.

---

## 3. 너비 vs. 깊이

### 3.1 너비 정리 (1층)

UAT는 하나의 은닉층이면 충분하다고 말합니다. 하지만 필요한 너비(뉴런 수)는 지수적으로 클 수 있습니다.

### 3.2 깊이 정리

심층 네트워크는 특정 함수를 얕은 네트워크보다 지수적으로 적은 파라미터로 근사할 수 있습니다:

```
예: n 비트의 패리티 계산
  - 1 은닉층: 2^n 뉴런 필요
  - O(log n) 층: 총 O(n) 뉴런

→ 심층 네트워크가 일부 함수에서 지수적으로 더 효율적
```

---

## 4. 정리의 한계

### 4.1 존재 ≠ 학습 가능성

UAT는 근사하는 네트워크의 **존재**를 보장하지만, 다음에 대해서는 아무것도 말하지 않습니다:

```
1. 올바른 가중치를 찾는 방법 (최적화는 일반적으로 NP-hard)
2. 필요한 뉴런 수 (천문학적으로 클 수 있음)
3. 필요한 학습 데이터 양
4. 경사 하강법이 해에 수렴할지 여부
```

### 4.2 차원의 저주

고차원 함수에서 필요한 뉴런 수는 차원에 따라 지수적으로 증가:

```
d = 2:   ε = 0.01 → ~10,000 뉴런 (실현 가능)
d = 100: ε = 0.01 → 10^200 뉴런 (불가능)
```

## 5. 실용적 함의

```
✓ 신경망은 보편 함수 근사기
✓ 구조는 충분한 표현력을 가짐
✓ 제한은 표현적이 아닌 계산적
✓ 더 깊은 것이 더 넓은 것보다 종종 나음 (효율성)

✗ 1 은닉층에 의존하지 마세요 (정리에도 불구하고)
✓ 더 나은 파라미터 효율성을 위해 여러 은닉층 사용
✓ 최적화와 일반화에 집중
```
