가중치 초기화는 사소한 세부사항처럼 보일 수 있지만, 신경망 학습의 성패를 가릅니다. 너무 크게 초기화하면 활성화가 폭발하고, 너무 작으면 소실됩니다. 대칭적으로 초기화하면 뉴런이 절대 분화되지 않습니다. 이 레슨에서는 Xavier와 He 초기화의 이론을 유도하고 이 원리적 접근 방식이 왜 잘 작동하는지 보여줍니다.

---

## 1. 왜 초기화가 중요한가

### 1.1 목표

활성화가 층에 걸쳐 대략 동일한 분산을 유지하길 원합니다:

```
Var(a^(l)) ≈ Var(a^(l-1))    모든 층 l에 대해

이는 다음을 보장:
- 활성화 소실 없음 (정보가 순전파됨)
- 활성화 폭발 없음 (수치 안정성)
- 기울기 소실 없음 (모든 층에서 학습 발생)
```

---

## 2. 대칭 깨뜨리기 문제

모든 가중치를 0(또는 같은 상수)으로 초기화하면:

```
같은 층의 모든 뉴런이 같은 출력을 계산:
  z_1 = w·x + b = 0
  z_2 = w·x + b = 0

역전파 중, 모든 뉴런이 같은 기울기를 받음:
  ∂L/∂w_1 = ∂L/∂w_2 = ∂L/∂w_3

업데이트 후에도 모든 뉴런이 여전히 같은 가중치!
→ 뉴런이 영구적으로 동기화 → 층당 단일 뉴런의 효과적 용량
```

무작위 초기화가 대칭을 깨뜨립니다: 각 뉴런이 다른 가중치로 시작하여, 다른 출력을 계산하고, 다른 기울기를 받아, 다르게 특화됩니다.

---

## 3. Xavier/Glorot 초기화 (2010)

### 3.1 유도

순전파: Var(z^(l)) = n_{l-1} · Var(w) · Var(a^(l-1)) → Var(w) = 1/n_{l-1}

역전파: Var(δ^(l)) = n_l · Var(w) · Var(δ^(l+1)) → Var(w) = 1/n_l

**절충** (양쪽 근사):

```
Var(w) = 2 / (fan_in + fan_out)

Xavier 정규: w ~ N(0, 2/(fan_in + fan_out))
Xavier 균등: w ~ U(-√(6/(fan_in + fan_out)), √(6/(fan_in + fan_out)))
```

**사용 시기**: Sigmoid, Tanh 활성화

---

## 4. He/Kaiming 초기화 (2015)

### 4.1 Xavier이 ReLU에서 실패하는 이유

ReLU는 활성화의 절반을 0으로 만들어 분산을 반으로 줄입니다:

```
ReLU의 경우: Var(a^(l)) = (1/2) · n_{l-1} · Var(w) · Var(a^(l-1))

안정을 위해: (1/2) · n · Var(w) = 1 → Var(w) = 2/n
```

### 4.2 공식

```
He 정규: w ~ N(0, 2/fan_in)
He 균등: w ~ U(-√(6/fan_in), √(6/fan_in))
```

Xavier 대비 2배 계수 -- ReLU의 절반 제로화를 보상합니다.

### 4.3 활성화별 초기화

| 활성화 | 초기화 | 분산 |
|--------|--------|------|
| Sigmoid, Tanh | Xavier | 2/(fan_in + fan_out) |
| ReLU | He (fan_in) | 2/fan_in |
| Leaky ReLU (α) | 수정된 He | 2/((1+α^2) · fan_in) |

---

## 5. 편향 초기화

- **기본**: 편향을 0으로 초기화 (b = 0)
- **ReLU 은닉층**: 초기화 시 죽은 뉴런 방지를 위해 작은 양수 편향(b = 0.01) 권장하기도 함
- **출력층**: 사전 확률의 로그-오즈로 초기화 (분류의 경우)

```python
# 불균형 이진 분류 (예: 양성 5%)
prior = 0.05
bias_init = np.log(prior / (1 - prior))  # ≈ -2.94
```

## 6. 요약

```
핵심 정리
═══════════════════════════════════════════════════════
1. 모든 가중치를 0으로 초기화하면 안 됨 (대칭 문제)
2. 목표: Var(활성화) ≈ 층에 걸쳐 상수
3. Xavier: Var(w) = 2/(fan_in + fan_out), sigmoid/tanh용
4. He: Var(w) = 2/fan_in, ReLU용
5. He는 ReLU가 활성화 절반을 0으로 만드는 것을 보상
6. 층별 활성화 통계를 추적하여 초기화 검증
7. 직교 초기화는 기울기 노름을 정확히 보존
8. 편향: 보통 0, 특수한 경우 제외
═══════════════════════════════════════════════════════
```
