## 학습 목표(Learning Objectives)

이 레슨을 완료하면 다음을 할 수 있습니다:

1. 미적분의 연쇄 법칙에서 역전파를 유도할 수 있습니다

3. 2층 MLP의 역전파를 밑바닥부터 구현할 수 있습니다
4. 각 층의 가중치와 편향에 대한 기울기를 계산할 수 있습니다
5. 수치 기울기 검증을 사용하여 분석적 기울기를 검증할 수 있습니다
6. 순전파 / 역전파의 대칭성을 설명할 수 있습니다
7. 기울기 흐름 패턴과 잠재적 문제를 파악할 수 있습니다
8. 다른 활성화 함수를 가진 네트워크에 역전파를 적용할 수 있습니다

---

역전파는 신경망 학습을 가능하게 하는 알고리즘입니다. 미적분의 연쇄 법칙을 출력에서 입력으로 층별로 적용하여, 네트워크의 모든 가중치에 대한 손실의 기울기를 효율적으로 계산합니다. 수학이 처음에는 복잡해 보일 수 있지만, 핵심 아이디어는 놀라울 정도로 단순합니다: 계산 그래프를 역방향으로 순회하면서 국소 기울기를 곱해 나가는 것입니다.

## 1. 핵심 아이디어

### 1.1 역전파가 해결하는 문제

경사 하강법으로 가중치를 업데이트하려면:

```
∂J/∂W^(l)   모든 층 l에 대해
∂J/∂b^(l)   모든 층 l에 대해

이 기울기는 다음을 알려줍니다: "각 가중치를 약간 조정하면
손실이 얼마나 변하는가?"
```

### 1.2 핵심 통찰: 연쇄 법칙

```
y = f(g(x))이면, dy/dx = dy/dg · dg/dx

신경망에 대해:
  x → z^(1) → a^(1) → z^(2) → a^(2) → L

  ∂L/∂W^(1) = ∂L/∂a^(2) · ∂a^(2)/∂z^(2) · ∂z^(2)/∂a^(1) · ∂a^(1)/∂z^(1) · ∂z^(1)/∂W^(1)
                                연쇄 법칙, 오른쪽에서 왼쪽으로
```

## 2. 계산 그래프

### 2.1 국소 기울기

각 연산은 간단한 국소 기울기를 가집니다:

```
덧셈:      f = a + b     →  ∂f/∂a = 1,  ∂f/∂b = 1
곱셈:      f = a · b     →  ∂f/∂a = b,  ∂f/∂b = a
시그모이드: f = σ(a)     →  ∂f/∂a = σ(a)(1 - σ(a))
제곱:      f = a^2       →  ∂f/∂a = 2a
ReLU:      f = max(0,a)  →  ∂f/∂a = 1 만약 a > 0, 아니면 0
행렬곱:    f = W·a       →  ∂f/∂W = a^T,  ∂f/∂a = W^T
```

## 3. 2층 MLP의 역전파

### 3.1 역전파 요약

```
δ^(L) = a^(L) - y                              (출력 오차)
∂L/∂W^(L) = δ^(L) · (a^(L-1))^T               (가중치 기울기)
∂L/∂b^(L) = δ^(L)                              (편향 기울기)

l = L-1, L-2, ..., 1에 대해:
  δ^(l) = (W^(l+1))^T · δ^(l+1) ⊙ σ'(z^(l))  (오차를 역방향 전파)
  ∂L/∂W^(l) = δ^(l) · (a^(l-1))^T             (가중치 기울기)
  ∂L/∂b^(l) = δ^(l)                            (편향 기울기)
```

### 3.2 배치 역전파

m개 샘플의 배치에 대해:

```
dZ^(L) = A^(L) - Y                              형상: (nL, m)
dW^(L) = (1/m) · dZ^(L) · (A^(L-1))^T           형상: (nL, n_{L-1})
db^(L) = (1/m) · Σ_{열} dZ^(L)                  형상: (nL, 1)

dA^(l) = (W^(l+1))^T · dZ^(l+1)                 형상: (n_l, m)
dZ^(l) = dA^(l) ⊙ σ'(Z^(l))                     형상: (n_l, m)
dW^(l) = (1/m) · dZ^(l) · (A^(l-1))^T            형상: (n_l, n_{l-1})
db^(l) = (1/m) · Σ_{열} dZ^(l)                   형상: (n_l, 1)
```

## 4. 기울기 검증

### 4.1 방법

각 파라미터 θ_i에 대해 분석적 기울기를 수치 근사와 비교합니다:

```
수치적: ∂L/∂θ_i ≈ [L(θ_i + ε) - L(θ_i - ε)] / (2ε)

상대 오차 < 1e-5 → 올바를 가능성 높음
상대 오차 > 1e-3 → 버그 가능성 높음
```

---

## 5. 역전파 직관

### 5.1 기여도 할당(Credit Assignment)

역전파는 "각 가중치가 오차에 얼마나 기여했는가?"에 답합니다:

```
w2가 오차에 2.1만큼 기여 → 큰 업데이트
w1이 오차에 0.3만큼 기여 → 작은 업데이트

이것이 "기여도 할당": 오차에 대한 책임을 분배하는 것입니다.
```

### 5.2 계산 복잡도

```
순전파:   O(N)   여기서 N = 총 가중치 수
역전파:   O(N)   순전파와 동일한 차수!

역전파는 효율적: 모든 기울기를 계산하는 비용이 순전파 한 번과 비슷합니다.
```

---

## 6. 일반적인 함정

### 6.1 캐시 누락

역전파에는 순전파에서 계산된 활성화가 필요합니다. 항상 z^(l)과 a^(l)을 순전파 중에 저장하세요.

### 6.2 형상 불일치

항상 행렬 차원이 맞는지 검증합니다:
```
dW = dz @ a_prev.T    # (n_l, m) @ (n_{l-1}, m)^T = (n_l, n_{l-1}) ✓
db = sum(dz, axis=1)   # (n_l, m) → (n_l, 1) ✓
```

## 7. 요약

```
핵심 정리
═══════════════════════════════════════════════════════
1. 역전파 = 연쇄 법칙을 층별로 적용, 출력 → 입력
2. 각 층: δ^(l) = (W^(l+1))^T · δ^(l+1) ⊙ σ'(z^(l))
3. 가중치 기울기: dW^(l) = δ^(l) · (a^(l-1))^T / m
4. 편향 기울기: db^(l) = 샘플에 대한 δ^(l)의 평균
5. Softmax + CCE는 δ^(L) = a^(L) - y (우아!)
6. 순전파와 동일한 계산 비용: O(N)
7. 항상 기울기 검증으로 확인 (ε = 1e-7)
8. 순전파 값을 캐시; 인플레이스 수정 금지
═══════════════════════════════════════════════════════
```
