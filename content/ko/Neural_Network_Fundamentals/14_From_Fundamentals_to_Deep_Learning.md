## 학습 목표(Learning Objectives)

이 레슨을 완료하면 다음을 할 수 있습니다:

1. CNN이 공간 구조 인식을 통해 MLP를 어떻게 확장하는지 설명할 수 있습니다
2. RNN이 순차 데이터를 처리하는 방법과 그 한계를 설명할 수 있습니다
3. Transformer 구조와 셀프 어텐션 메커니즘을 개략적으로 설명할 수 있습니다
4. 각 딥러닝 아키텍처를 이 과정에서 배운 MLP 기초와 연결할 수 있습니다
5. 다양한 데이터 유형에 가장 적합한 구조를 파악할 수 있습니다
6. 매우 깊은 네트워크 학습을 가능하게 한 핵심 혁신을 나열할 수 있습니다
7. 이 기초에서 전문 딥러닝 토픽으로의 학습 경로를 계획할 수 있습니다

---

이제 신경망 기초에 대한 탄탄한 이해를 갖추었습니다: 생물학적 뉴런에서 역전파, 최적화, 정규화가 포함된 완전한 MLP 구현까지. 이 마지막 레슨은 세 가지 가장 중요한 딥러닝 아키텍처 -- 합성곱 신경망(CNN), 순환 신경망(RNN), 트랜스포머 -- 를 미리보면서, 여러분이 숙달한 MLP 개념이 어떻게 확장되는지 보여줍니다.

## 1. MLP의 한계

```
문제 1: 이미지 (공간 구조)
  MLP 입력: 28×28 이미지를 784차원 벡터로 평탄화
  문제점: 픽셀 간의 공간적 관계가 파괴됨
  해결: → CNN (합성곱 레이어가 공간 구조를 보존)

문제 2: 시퀀스 (시간 구조)
  MLP 입력: 고정 길이 입력만 가능
  문제점: 가변 길이 시퀀스를 처리할 수 없음
  해결: → RNN (순환 연결이 시퀀스를 처리)

문제 3: 장거리 의존성
  RNN 문제: 긴 시퀀스에서의 기울기 소실
  해결: → Transformer (어텐션 메커니즘, 병렬 처리)
```

---

## 2. 합성곱 신경망 (CNN)

### 2.1 핵심 아이디어: 국소 연결 + 가중치 공유

모든 뉴런을 모든 입력에 연결하는 대신, CNN은 입력 위를 미끄러지는 작은 **필터**(커널)를 사용합니다.

```
MLP (완전 연결):              CNN (합성곱):
모든 뉴런이 모든 픽셀을       각 뉴런이 국소 패치만
볼 수 있음                   볼 수 있음

파라미터: 25 × 뉴런 = 많음   파라미터: 3×3 = 9 (위치 간 공유!)
```

### 2.2 합성곱이 MLP를 어떻게 확장하는가

```
MLP 은닉층:   z = W · x + b           (W는 n_out × n_in)
CNN 합성곱:   z[i,j] = Σ K[m,n] · x[i+m, j+n] + b

둘 다: 선형 변환 + 편향 + 활성화
CNN은 W를 희소하고 공유된 형태(커널 K)로 제한
```

---

## 3. 순환 신경망 (RNN)

### 3.1 핵심 아이디어: 시간에 걸친 은닉 상태

```
RNN: 각 시간 단계에서
  h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b_h)
  y_t = W_hy · h_t + b_y

시간에 걸쳐 펼치면 가중치가 공유된 매우 깊은 MLP처럼 보임
→ 역전파를 통한 시간 전파(BPTT) = 이 펼쳐진 그래프에서의 역전파
→ 긴 시퀀스에서 기울기 소실 문제 (심층 MLP와 동일!)
```

### 3.2 LSTM과 GRU

기울기 소실 문제를 **게이팅 메커니즘**으로 해결:

- **LSTM**: 망각 게이트, 입력 게이트, 출력 게이트 + 셀 상태 (기울기 고속도로)
- **GRU**: LSTM보다 단순 (게이트 2개), 대부분의 작업에서 유사한 성능

---

## 4. 트랜스포머

### 4.1 핵심 아이디어: 셀프 어텐션

트랜스포머는 순환을 **어텐션**으로 대체합니다: 시퀀스의 모든 요소가 다른 모든 요소에 직접 참여할 수 있습니다.

```
RNN:         x1 → x2 → x3 → x4    (순차적, O(n) 경로 길이)
Transformer: 모든 토큰이 모든 다른 토큰에 동시 참여  (병렬, O(1) 경로 길이)
```

### 4.2 셀프 어텐션 메커니즘

```
각 토큰에 대해:
  Query:  Q = W_Q · x     "나는 무엇을 찾고 있는가?"
  Key:    K = W_K · x     "나는 무엇을 포함하는가?"
  Value:  V = W_V · x     "나는 어떤 정보를 제공하는가?"

Attention(Q, K, V) = softmax(Q · K^T / √d_k) · V

이것은 행렬 곱셈 + 소프트맥스 — 모두 여러분이 아는 개념!
```

### 4.3 여러분이 이미 아는 것

| Transformer 구성 요소 | MLP 기초 |
|----------------------|---------|
| Feed-forward 네트워크 | MLP (레슨 04, 13) |
| 어텐션의 Softmax | Softmax 활성화 (레슨 03) |
| 레이어 정규화 | 배치 정규화 변형 (레슨 10) |
| 스킵 연결 | 기울기 흐름 (레슨 06) |
| Adam 옵티마이저 | 경사 하강법 변형 (레슨 07) |
| 교차 엔트로피 손실 | 손실 함수 (레슨 05) |

**Transformer는 이 과정에서 배운 동일한 빌딩 블록으로 구축됩니다.**

## 5. 구조 선택 가이드

```
어떤 종류의 데이터인가?
    │
    ├── 이미지 / 공간 데이터 → CNN
    ├── 시퀀스 (텍스트, 시계열)
    │     ├── 짧은 시퀀스 → LSTM / GRU
    │     └── 긴 시퀀스 → Transformer
    ├── 테이블형 데이터 → MLP (또는 그래디언트 부스팅)
    └── 모든 것 (현대 트렌드) → Transformer
```

```

═══════════════════════════════════════════════════════
```
