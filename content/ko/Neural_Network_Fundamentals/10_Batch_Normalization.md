## 학습 목표(Learning Objectives)

이 레슨을 완료하면 다음을 할 수 있습니다:

1. 내부 공변량 이동이 무엇이며 학습을 방해하는 이유를 설명할 수 있습니다
2. 배치 정규화 순전파를 단계별로 유도할 수 있습니다
3. 학습 및 추론 모드에 대한 배치 정규화를 구현할 수 있습니다
4. 배치 정규화를 통한 역전파를 계산할 수 있습니다
5. 학습 가능한 파라미터 감마와 베타의 역할을 설명할 수 있습니다
6. 추론을 위한 이동 통계가 유지되는 방법을 설명할 수 있습니다
7. 네트워크에서 배치 정규화를 어디에 배치할지 논의할 수 있습니다
8. 배치 정규화와 레이어 정규화를 비교할 수 있습니다

---

배치 정규화(BatchNorm, BN)는 2015년 Ioffe와 Szegedy가 도입했으며, 딥러닝에서 가장 영향력 있는 혁신 중 하나였습니다. 미니배치 내에서 활성화를 정규화하여 학습을 안정화하고, 더 높은 학습률을 허용하며, 초기화에 대한 민감도를 줄이고, 약한 정규화 효과도 제공합니다.

## 1. 문제: 내부 공변량 이동

학습이 진행됨에 따라 각 층의 가중치가 변합니다. 이로 인해 각 층의 입력 분포가 지속적으로 변합니다:

```
에포크 1:   층 1 출력의 평균=0.5, 표준편차=1.2
에포크 10:  층 1 출력의 평균=-0.3, 표준편차=0.8
에포크 100: 층 1 출력의 평균=1.1, 표준편차=2.5

층 2는 끊임없이 변하는 입력 분포에 재적응해야 합니다.
이것이 "내부 공변량 이동"입니다.
```

---

## 2. 배치 정규화 알고리즘

### 2.1 핵심 아이디어

각 미니배치 내에서 각 특성을 평균 0, 분산 1로 정규화한 후, 학습 가능한 아핀 변환을 적용합니다:

```
단계 1: 미니배치 평균
  μ_B = (1/m) Σ z_i

단계 2: 미니배치 분산
  σ_B^2 = (1/m) Σ (z_i - μ_B)^2

단계 3: 정규화
  ẑ_i = (z_i - μ_B) / √(σ_B^2 + ε)

단계 4: 스케일과 시프트 (학습 가능)
  y_i = γ · ẑ_i + β

γ (스케일)과 β (시프트)는 학습 가능한 파라미터입니다.
```

### 2.2 학습 가능한 γ와 β가 필요한 이유

정규화만 하면(단계 3) 네트워크의 표현력이 제한됩니다. 학습 가능한 파라미터는 필요한 경우 정규화를 취소할 수 있게 합니다:

```
γ = √(σ_B^2 + ε)이고 β = μ_B이면: y = z (항등 연산)

네트워크가 BN을 항등 연산으로 만드는 것이 최적이면 그렇게 학습할 수 있습니다.
```

## 3. 학습 vs. 추론

```
학습 모드:
  - 현재 미니배치의 배치 통계(μ_B, σ_B^2) 사용
  - 지수 이동 평균으로 이동 통계 업데이트

추론 모드:
  - 이동 통계 사용 (학습 중 누적)
  - 결정적 출력

중요: 평가 모드로 전환을 잊는 것은 흔한 버그!
```

---

## 4. 배치 정규화의 한계

### 4.1 배치 크기 의존성

```
큰 배치 (B=256):  μ_B ≈ μ_모집단    (좋은 추정)
작은 배치 (B=4):  μ_B ≈ 노이즈      (신뢰할 수 없음)
배치 크기 1:      μ_B = z            (BN 무용)
```

### 4.2 작은 배치를 위한 대안

| 방법 | 정규화 축 | 배치 크기 의존? |
|------|----------|---------------|
| 배치 정규화 | 배치 방향, 특성별 | 예 |
| 레이어 정규화 | 특성 방향, 샘플별 | 아니오 |
| 인스턴스 정규화 | 샘플별, 채널별 | 아니오 |
| 그룹 정규화 | 샘플별, 채널 그룹별 | 아니오 |

**레이어 정규화**는 다음에 적합:
- Transformer / NLP (가변 시퀀스 길이)
- 작은 배치 크기
- 순환 네트워크
