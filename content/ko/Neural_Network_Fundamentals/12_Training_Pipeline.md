## 학습 목표(Learning Objectives)

이 레슨을 완료하면 다음을 할 수 있습니다:

1. 데이터에서 평가까지의 완전한 신경망 학습 파이프라인을 설계할 수 있습니다
2. 적절한 학습/검증/테스트 분할 전략을 구현할 수 있습니다
3. 모델 선택을 위한 k-폴드 교차검증을 적용할 수 있습니다
4. 그리드 및 랜덤 서치를 사용하여 체계적으로 하이퍼파라미터를 튜닝할 수 있습니다
5. 메트릭 로깅과 체크포인팅이 포함된 학습 루프를 구현할 수 있습니다
6. 학습 곡선에서 과소적합과 과적합을 진단할 수 있습니다
7. 완전한 파이프라인을 분류 문제에 적용할 수 있습니다
8. 재현 가능한 실험 워크플로우의 단계를 나열할 수 있습니다

---

개별 구성 요소(활성화 함수, 손실 함수, 옵티마이저)의 작동 원리를 아는 것은 필요하지만 충분하지 않습니다. 효과적인 신경망을 구축하려면 데이터 분할, 하이퍼파라미터 탐색, 모델 평가, 진단을 처리하는 체계적인 학습 파이프라인이 필요합니다.

## 1. 완전한 파이프라인

```
┌──────────────────────────────────────────────────────────┐
│                    학습 파이프라인                         │
│                                                          │
│  1. 데이터 준비                                           │
│     ├── 데이터 로드 및 검사                                │
│     ├── 결측값 처리                                       │
│     ├── 특성 스케일링 (표준화 / 정규화)                     │
│     └── 학습 / 검증 / 테스트 분할                          │
│                                                          │
│  2. 모델 설계                                             │
│     ├── 구조 선택 (층, 뉴런)                               │
│     ├── 활성화 함수 선택                                   │
│     ├── 손실 함수 선택                                     │
│     └── 옵티마이저 선택                                    │
│                                                          │
│  3. 학습 루프                                             │
│     ├── 순전파 → 손실 계산 → 역전파 → 가중치 업데이트       │
│     └── 메트릭 로깅 (학습 손실, 검증 손실, 정확도)          │
│                                                          │
│  4. 하이퍼파라미터 튜닝                                    │
│     ├── 그리드 서치 / 랜덤 서치                            │
│     └── 검증 메트릭 기반 최적 모델 선택                     │
│                                                          │
│  5. 평가                                                  │
│     ├── 테스트 세트에서 평가 (최종, 일회성)                  │
│     └── 신뢰구간과 함께 메트릭 보고                         │
└──────────────────────────────────────────────────────────┘
```

## 2. 데이터 준비

### 2.1 특성 스케일링

신경망은 입력 스케일에 민감합니다. 항상 표준화 또는 정규화하세요:

```python
# 중요: 학습 데이터에서만 fit, 학습/검증/테스트 모두에 transform
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_val_scaled = scaler.transform(X_val)      # 학습 통계 사용!
X_test_scaled = scaler.transform(X_test)    # 학습 통계 사용!
```

### 2.2 데이터 분할

```
전체 데이터
├── 학습 세트 (60-80%)     ← 모델이 이것으로 학습
├── 검증 세트 (10-20%)     ← 하이퍼파라미터 튜닝, 과적합 모니터링
└── 테스트 세트 (10-20%)   ← 최종 평가 전용 (절대 튜닝에 사용 금지!)

규칙: 학습이나 하이퍼파라미터 선택 중에 테스트 데이터를 절대 보지 마세요.
```

## 3. 하이퍼파라미터 튜닝

### 3.1 핵심 하이퍼파라미터

| 하이퍼파라미터 | 일반적 범위 | 탐색 스케일 |
|-------------|-----------|-----------|
| 학습률 | 1e-4 ~ 1e-1 | 로그 스케일 |
| 배치 크기 | 16, 32, 64, 128 | 2의 거듭제곱 |
| 은닉층 수 | 1 ~ 5 | 정수 |
| 층당 뉴런 수 | 32 ~ 512 | 2의 거듭제곱 |
| 드롭아웃 비율 | 0.0 ~ 0.5 | 선형 |
| L2 (가중치 감쇠) | 1e-5 ~ 1e-2 | 로그 스케일 |

### 3.2 랜덤 서치

랜덤 서치는 대부분의 하이퍼파라미터 공간에서 그리드 서치보다 효율적입니다.

---

## 4. 학습 곡선 진단

```
증상                           │ 진단            │ 조치
──────────────────────────────┼────────────────┼─────────────────
Train ↓, Val ↓ (둘 다 개선)   │ 좋은 학습      │ 계속
Train ↓, Val ↑ (발산)         │ 과적합         │ 정규화 강화
Train ↓ 느림, Val ↓ 느림      │ 과소적합       │ 모델 확대
Train 크게 진동                │ LR 너무 높음   │ 학습률 감소
Train 거의 감소 안 함          │ LR 너무 낮음   │ 학습률 증가
```

---

## 5. 재현성 체크리스트

```
□ 랜덤 시드 설정
□ 모든 하이퍼파라미터 기록
□ 학습 메트릭 로깅 (에포크당 손실, 정확도)
□ 최적 모델 체크포인트 저장
□ 소프트웨어 버전 기록
□ 데이터 전처리 단계 문서화
□ 학습/검증/테스트 분할 인덱스 저장
□ 신뢰구간과 함께 결과 보고
```

## 6. 요약

```
핵심 정리
═══════════════════════════════════════════════════════
1. 파이프라인: 데이터 준비 → 모델 설계 → 학습 → 튜닝 → 평가
2. 특성 스케일링; 학습에서 fit, 모든 분할에 transform
3. 최종 평가까지 테스트 데이터 사용 금지
4. 미니배치(32-256)와 에포크마다 셔플링 사용
5. 랜덤 서치 > 그리드 서치 (하이퍼파라미터 튜닝)
6. 제한된 데이터에서는 K-폴드 CV로 신뢰할 수 있는 평가
7. 학습 곡선으로 문제 진단
8. 재현성: 시드, 로깅, 버전 관리
═══════════════════════════════════════════════════════
```
