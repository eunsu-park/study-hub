손실 함수(비용 함수 또는 목적 함수라고도 함)는 네트워크의 예측이 실제 값과 얼마나 떨어져 있는지를 측정합니다. 신경망 학습은 근본적으로 최적화 문제입니다: 가중치를 조정하여 손실을 최소화합니다. 손실 함수의 선택은 네트워크가 무엇을 최적화하도록 학습하는지를 결정하며, 학습 역학에 깊은 영향을 미칩니다.

## 1. 손실 함수 기초

### 1.1 손실 vs. 비용

```
손실:   L(ŷ, y)          ← 단일 샘플에 대해
비용:   J = (1/N) Σ L    ← 전체 N개 샘플의 평균

가중치 W와 편향 b에 대해 비용 J를 최소화합니다.
```

---

## 2. 평균 제곱 오차 (MSE)

```
L_MSE(ŷ, y) = (1/2)(ŷ - y)^2              (단일 샘플)
J_MSE = (1/2N) Σ_{i=1}^{N} (ŷ_i - y_i)^2  (N개 샘플에 대한 비용)

기울기: ∂L/∂ŷ = ŷ - y
```

- **회귀 작업**에 적합: 연속 값 예측
- **분류에는 비추천** (기울기 문제)

---

## 3. 교차 엔트로피 손실

### 3.1 이진 교차 엔트로피 (BCE)

시그모이드 출력 ŷ ∈ (0, 1)을 가진 이진 분류에 사용:

```
L_BCE = -[y · log(ŷ) + (1 - y) · log(1 - ŷ)]

y = 1일 때:  L = -log(ŷ)       ← ŷ가 0에 가까울수록 큰 페널티
y = 0일 때:  L = -log(1 - ŷ)   ← ŷ가 1에 가까울수록 큰 페널티
```

시그모이드 출력 z → ŷ = σ(z)와 결합하면:

```
∂L/∂z = ŷ - y    ← 아름답게 간단! σ' 항이 없음!
```

이것이 시그모이드 + BCE가 자연스러운 쌍인 이유입니다.

### 3.2 범주형 교차 엔트로피 (CCE)

K개 클래스의 다중 클래스 분류에서, 원-핫 인코딩된 y와 소프트맥스 출력 ŷ를 사용:

```
L_CCE = -Σ_{k=1}^{K} y_k · log(ŷ_k)

y가 원-핫이므로 (하나의 y_k만 1, 나머지 0):
L_CCE = -log(ŷ_c)    여기서 c는 실제 클래스

소프트맥스와 결합하면:
∂L/∂z_k = ŷ_k - y_k    ← 동일한 우아한 단순화!
```

---

## 4. 분류에서 교차 엔트로피가 MSE를 이기는 이유

### 4.1 기울기 문제

```
시그모이드 출력 뉴런 + MSE 손실:
∂L/∂z = (σ(z) - y) · σ'(z)
                       ↑
                σ'(z) ≤ 0.25 → 기울기가 억제됨!

교차 엔트로피:
∂L/∂z = σ(z) - y
                 ↑
          σ'(z) 항 없음 → 기울기가 오차에 비례!
```

### 4.2 학습 속도 비교

```
y = 1, z = -5 (매우 틀린 예측) 가정:

MSE 기울기:   (-0.993) × 0.0066 = -0.0066
BCE 기울기:   -0.993

BCE 기울기가 150배 큼 → 큰 오류에서 150배 빠르게 학습!
```

## 5. 힌지 손실

레이블 y ∈ {-1, +1}인 SVM 스타일 분류기에 사용:

```
L_hinge = max(0, 1 - y · ŷ)

기울기: ∂L/∂ŷ = { -y   만약 1 - y·ŷ > 0
               { 0    그렇지 않으면
```

## 6. 수치 안정성

### 6.1 Log-Sum-Exp 기법

```
불안정: log(e^1000 + e^1001) → 오버플로!
안정:   M = max(z), log(Σ e^z_i) = M + log(Σ e^(z_i - M))
```

항상 log 취하기 전에 예측값을 클리핑합니다:

```python
def stable_bce(y_pred, y_true, eps=1e-15):
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))
```

## 7. 손실 함수 선택 가이드

| 작업 | 손실 | 출력 활성화 | 출력 형상 |
|------|------|-----------|----------|
| 회귀 | MSE | 항등 | (1,) |
| 이진 분류 | BCE | Sigmoid | (1,) |
| 다중 클래스 (K) | CCE | Softmax | (K,) |
| 다중 레이블 | BCE (클래스별) | Sigmoid | (K,) |
| 랭킹/마진 | Hinge | 항등 | (1,) |
