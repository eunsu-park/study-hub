활성화 함수가 없다면, 신경망은 단순히 선형 변환의 연속일 뿐 -- 깊이에 상관없이 하나의 선형 변환으로 축소됩니다. 활성화 함수는 신경망에 표현력을 부여하는 비선형성을 도입합니다. 적절한 활성화 함수를 선택하면 모델 학습이 몇 분 안에 끝날 수도 있고, 잘못 선택하면 영원히 수렴하지 않을 수도 있습니다.

## 1. 왜 활성화 함수가 필요한가?

### 1.1 선형성의 문제

활성화 함수 없이 2층 네트워크를 생각해 봅시다:

```
Layer 1:  h = W1 · x + b1
Layer 2:  y = W2 · h + b2
         = W2 · (W1 · x + b1) + b2
         = (W2 · W1) · x + (W2 · b1 + b2)
         = W' · x + b'           ← 단 하나의 선형 레이어!
```

아무리 많은 층을 쌓아도, **비선형성 없이는 전체 네트워크가 하나의 선형 변환으로 축소됩니다**. 100층 선형 네트워크도 1층 선형 모델과 동일한 표현력을 갖습니다.

## 2. 활성화 함수 카탈로그

### 2.1 Sigmoid (로지스틱)

```
σ(z) = 1 / (1 + e^(-z))

출력 범위: (0, 1)
도함수:   σ'(z) = σ(z) · (1 - σ(z))
```

**특성**:
- 매끄럽고, 모든 곳에서 미분 가능
- 출력이 (0, 1) 범위 -- 확률로 해석 가능
- 최대 기울기 = z = 0에서 0.25

**문제점**:
- **기울기 소실**: |z| > 5이면 σ'(z) ≈ 0 → 기울기가 사라짐
- **영점 중심이 아님**: 출력이 항상 양수 → 지그재그 기울기 업데이트
- **연산 비용**: exp()가 계산 비용이 높음

```python
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def sigmoid_derivative(z):
    s = sigmoid(z)
    return s * (1 - s)
```

### 2.2 Tanh (쌍곡 탄젠트)

```
tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z)) = 2·σ(2z) - 1

출력 범위: (-1, 1)
도함수:   tanh'(z) = 1 - tanh^2(z)
```

**특성**:
- **영점 중심** (출력 범위가 -1에서 1)
- Sigmoid보다 강한 기울기 (z = 0에서 최대 기울기 = 1.0)

**문제점**:
- 큰 |z|에서 여전히 기울기 소실 문제
- exp() 사용으로 다소 높은 연산 비용

### 2.3 ReLU (정류 선형 유닛)

```
ReLU(z) = max(0, z)

출력 범위: [0, ∞)
도함수:   ReLU'(z) = { 1  만약 z > 0
                      { 0  만약 z < 0
```

**특성**:
- **빠름**: exp() 없이, 비교 연산만 필요
- z > 0에서 **기울기 소실 없음** (기울기 = 1)
- **희소 활성화**: 음수 입력은 0을 생성 → 자연스러운 희소성
- 2012년 이후 은닉층에서 가장 널리 사용되는 활성화 함수

**문제점**:
- **죽은 ReLU**: z < 0이면 기울기 = 0 → 뉴런이 영구적으로 학습 중단
- 영점 중심이 아님 (출력이 항상 ≥ 0)

```python
def relu(z):
    return np.maximum(0, z)

def relu_derivative(z):
    return (z > 0).astype(float)
```

### 2.4 Leaky ReLU

```
LeakyReLU(z) = { z           만약 z > 0
               { α · z       만약 z ≤ 0      (보통 α = 0.01)
```

**특성**: 죽은 ReLU 문제를 해결 -- 음수 입력에도 작은 기울기 유지

```python
def leaky_relu(z, alpha=0.01):
    return np.where(z > 0, z, alpha * z)
```

### 2.5 GELU (가우시안 오류 선형 유닛)

```
GELU(z) = z · Φ(z)    여기서 Φ(z)는 표준 정규 분포 CDF

근사식:
GELU(z) ≈ 0.5 · z · (1 + tanh(√(2/π) · (z + 0.044715 · z^3)))
```

**특성**: 현대 Transformer(BERT, GPT)에서 사용되는 ReLU의 매끄러운 근사

### 2.6 Softmax (출력층용)

```
Softmax(zi) = e^zi / Σ(e^zj)    j = 1, ..., K에 대해

출력 범위: 각 클래스에 대해 (0, 1), 합계 = 1
```

원시 점수(logits) 벡터를 확률 분포로 변환합니다.

**수치 안정성 기법**: 오버플로 방지를 위해 지수화 전에 max(z)를 뺍니다.

```python
def softmax(z):
    """수치적으로 안정한 softmax."""
    z_shifted = z - np.max(z)
    exp_z = np.exp(z_shifted)
    return exp_z / np.sum(exp_z)
```

## 3. 기울기 소실 문제

### 3.1 문제

역전파 과정에서 기울기는 연쇄 법칙을 통해 층마다 곱해집니다:

```
Sigmoid의 경우: 각 σ'(z) ≤ 0.25
L개 층 이후: 기울기 ≤ 0.25^L

L=4:   기울기 ≤ 0.0039  (소실!)
L=10:  기울기 ≤ 9.5e-7  (사실상 0)
```

### 3.2 해결 방법

| 해결 방법 | 효과 |
|----------|------|
| ReLU 활성화 | z > 0에서 기울기 = 1 (곱셈 감쇠 없음) |
| 잔차 연결 | 스킵 연결을 통해 기울기 직접 흐름 |
| 배치 정규화 | 활성화를 비포화 영역에 유지 |
| 적절한 초기화 | 초기화 시 활성화 포화 방지 |

## 4. 활성화 함수 선택 가이드

### 4.1 은닉층

```
은닉층 활성화 함수 선택:
──────────────────────
ReLU로 시작
  │
  ├── 학습이 잘 됨? → ReLU 유지 ✓
  │
  ├── 죽은 뉴런? → Leaky ReLU 또는 ELU 시도
  │
  └── Transformer 구조? → GELU 사용
```

### 4.2 출력층

| 작업 | 출력 활성화 | 손실 함수 |
|------|-----------|----------|
| 이진 분류 | Sigmoid | Binary Cross-Entropy |
| 다중 클래스 분류 | Softmax | Categorical Cross-Entropy |
| 회귀 | 없음 (항등) | MSE |
| 다중 레이블 분류 | Sigmoid (클래스별) | Binary Cross-Entropy |

## 5. 도함수 요약

역전파를 위해 각 활성화 함수의 도함수가 필요합니다:

```
Sigmoid:     σ'(z) = σ(z) · (1 - σ(z))
Tanh:        tanh'(z) = 1 - tanh²(z)
ReLU:        ReLU'(z) = 1 만약 z > 0, 아니면 0
Leaky ReLU:  LReLU'(z) = 1 만약 z > 0, 아니면 α
ELU:         ELU'(z) = 1 만약 z > 0, 아니면 α·e^z
Softmax:     ∂Si/∂zj = Si·(δij - Sj)   δij는 크로네커 델타
```

## 6. 요약

```
핵심 정리
═══════════════════════════════════════════════════════
1. 활성화 함수 없이는 심층 네트워크 = 하나의 선형 레이어
2. Sigmoid: (0,1) 범위, 출력에 적합, 기울기 소실 문제
3. Tanh: 영점 중심 (-1,1), Sigmoid보다 우수하지만 여전히 소실
4. ReLU: 빠름, 기본 선택, 하지만 "죽은 뉴런" 가능
5. Leaky ReLU / ELU: 죽은 ReLU 해결, 약간의 음수 기울기
6. GELU: 매끄러운 ReLU 변형, Transformer의 표준
7. Softmax: logits를 분류를 위한 확률로 변환
8. 은닉층은 ReLU; 출력 활성화는 작업에 따라 선택
═══════════════════════════════════════════════════════
```
