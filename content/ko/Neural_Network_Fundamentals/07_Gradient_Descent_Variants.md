## 1. 기본 경사 하강법

### 1.1 세 가지 변형

| 변형 | 배치 크기 | 기울기 추정 |
|------|----------|-----------|
| 배치 GD | N (전체 데이터) | 정확 (낮은 분산) |
| 확률적 GD | 1 샘플 | 노이즈가 많음 (높은 분산) |
| 미니배치 GD | B (예: 32) | 균형적 |

**미니배치 GD**가 표준: 충분히 안정적이고, 충분히 빠르며, B = 32, 64, 128, 256이 일반적입니다.

## 2. 모멘텀이 포함된 SGD

### 2.1 기본 SGD의 문제

기본 SGD는 좁은 방향에서는 진동하고 긴 방향으로는 느리게 진행합니다. 모멘텀은 진동을 완화하고 일관된 방향으로 가속합니다.

### 2.2 알고리즘

```
v ← β · v + (1 - β) · ∇J(θ)     (속도 항)
θ ← θ - η · v

β ∈ [0, 1)는 모멘텀 계수 (보통 β = 0.9)
```

**직관**: 언덕을 굴러 내려가는 공. 속도가 일관된 방향으로 축적되고 진동 방향에서는 상쇄됩니다.

### 2.3 지수 이동 평균 관점

```
v_t = (1-β) · g_t + β(1-β) · g_{t-1} + β^2(1-β) · g_{t-2} + ...

유효 윈도우: ~1/(1-β) 스텝
β = 0.9 → 최근 ~10개 기울기의 평균
```

## 3. Adam (적응적 모멘트 추정)

### 3.1 모멘텀 + RMSProp 결합

```
1차 모멘트 (평균):     m ← β1 · m + (1 - β1) · g        (모멘텀)
2차 모멘트 (분산):     v ← β2 · v + (1 - β2) · g^2     (RMSProp)

편향 보정:
  m̂ = m / (1 - β1^t)
  v̂ = v / (1 - β2^t)

업데이트:
  θ ← θ - η · m̂ / (√v̂ + ε)

기본값: β1 = 0.9, β2 = 0.999, ε = 1e-8, η = 0.001
```

### 3.2 편향 보정이 필요한 이유

초기(t=1)에 m과 v는 0으로 초기화됩니다. 보정 없이는 추정치가 0 쪽으로 편향됩니다:

```
t=1:  m = (1 - β1) · g_1 = 0.1 · g_1    (10배 낮게 편향!)
      m̂ = m / (1 - 0.9^1) = g_1          (편향 없음)
```

## 5. 학습률 스케줄링

### 5.1 일반적인 스케줄

**단계 감쇠(Step Decay)**:
```
η(t) = η_0 · γ^(floor(t / step_size))
```

**코사인 어닐링(Cosine Annealing)**:
```
η(t) = η_min + (η_max - η_min) / 2 · (1 + cos(πt / T))
```

**워밍업 + 코사인(Warmup + Cosine)**:
```
η(t) = { η_max · t / T_warmup              만약 t < T_warmup
       { η_min + (η_max - η_min)/2 · (1 + cos(π(t-T_warmup)/(T-T_warmup)))  그렇지 않으면
```
