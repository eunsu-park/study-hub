# C++ 기초

이 토픽은 환경 설정부터 클래스, 표준 템플릿 라이브러리(STL), 빌드 도구까지 C++ 프로그래밍의 기본을 다루며, 실습 캡스톤 프로젝트로 마무리됩니다. C에서 전환하는 분이든 객체지향 기능을 갖춘 첫 시스템 레벨 언어를 배우는 분이든, 이 레슨들을 통해 현대 C++(C++17)와 실무 코드베이스에서 매일 사용되는 관용구에 대한 탄탄한 이해를 얻을 수 있습니다.

## 학습 내용

이 토픽에서는 다음 내용을 실습과 함께 다룹니다:

- **시작하기**: 컴파일러 설치, IDE 설정, 첫 번째 컴파일된 C++ 프로그램
- **핵심 언어**: 변수, 데이터 타입, 연산자, 표현식, 제어 흐름
- **함수**: 오버로딩, 기본 매개변수, 인라인 함수, 재귀
- **배열과 문자열**: C 스타일 배열, `std::string`, `std::string_view`, 문자열 스트림
- **포인터와 참조**: 주소 연산자와 역참조 연산자, `new`/`delete`, 스마트 포인터 미리보기
- **네임스페이스와 I/O**: 네임스페이스 구성, `iostream`, `iomanip`, `stringstream`
- **OOP 기초**: 클래스, 생성자, 소멸자, 캡슐화, 연산자 오버로딩, 3의 법칙
- **상속과 다형성**: 가상 함수, 추상 클래스, 다중 상속
- **STL**: 컨테이너(`vector`, `map`, `set`), 알고리즘(`sort`, `find`, `transform`), 반복자
- **오류 처리와 파일 I/O**: 예외 계층 구조, `try`/`catch`, `fstream`
- **빌드 도구**: CMake 기초, 타겟, 다중 파일 프로젝트 구성
- **프로젝트**: 모든 개념을 통합하는 캡스톤 학생 관리 시스템

## 권장 학습 순서

레슨 01부터 15까지 순서대로 학습하세요. 각 레슨은 이전 레슨에서 소개된 개념을 기반으로 합니다:

1. **환경 설정 (레슨 1)**: C++ 컴파일러를 설치하고 실행하기
2. **언어 기초 (레슨 2-3)**: 변수, 연산자, 제어 흐름은 모든 C++ 프로그램의 근간
3. **함수 (레슨 4)**: 오버로딩, 기본 매개변수, 재귀
4. **데이터 처리 (레슨 5-6)**: 배열, 문자열, 포인터, 참조
5. **I/O와 구성 (레슨 7)**: 네임스페이스와 서식 있는 입출력
6. **객체지향 프로그래밍 (레슨 8-10)**: 클래스, 상속, 다형성
7. **표준 라이브러리 (레슨 11-12)**: 컨테이너, 알고리즘, 반복자
8. **견고성 (레슨 13-14)**: 예외 처리, 파일 I/O, 빌드 시스템
9. **캡스톤 (레슨 15)**: 모든 내용을 학생 관리 시스템에 적용

## 실습 환경

C++ 컴파일러 설치를 확인하세요:

```bash
g++ --version
# g++ (GCC) 13.x.x (또는 그 이상)

# 빠른 테스트
echo '#include <iostream>
int main() { std::cout << "Ready!\n"; return 0; }' > test.cpp
g++ -std=c++17 -Wall -Wextra test.cpp -o test && ./test
rm -f test test.cpp
```

각 레슨의 예제 코드는 `examples/CPP_Basics/`에서 확인할 수 있습니다.
