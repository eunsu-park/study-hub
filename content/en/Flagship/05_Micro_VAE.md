## 1. Theory: Variational Autoencoders

### 1.1 Latent Variable Models

A latent variable model assumes that observed data `x` is generated by a two-step process:

1. Sample a latent variable `z` from a prior `p(z)` (typically `N(0, I)`).
2. Sample the observation `x` from a conditional distribution `p_theta(x | z)`.

The marginal likelihood is:

```
p_theta(x) = integral p_theta(x | z) p(z) dz
```

This integral is intractable for all but the simplest models because it requires summing over all possible latent configurations.

### 1.2 The Evidence Lower Bound (ELBO)

Since we cannot compute `p_theta(x)` directly, we introduce an approximate posterior `q_phi(z | x)` and derive a lower bound:

```
log p_theta(x) >= E_{q_phi(z|x)} [log p_theta(x|z)] - KL(q_phi(z|x) || p(z))
```

This is the **ELBO** (Evidence Lower Bound). Maximizing the ELBO with respect to `theta` and `phi` simultaneously:

- **Reconstruction term** `E[log p_theta(x|z)]`: The decoder should reconstruct `x` well from sampled `z`.
- **KL term** `KL(q_phi(z|x) || p(z))`: The encoder's posterior should stay close to the prior `N(0, I)`.

### 1.3 The Reparameterization Trick

The encoder outputs `mu` and `log_var` (the parameters of `q_phi(z|x) = N(mu, sigma^2)`). To sample `z` while allowing gradients to flow through:

```
z = mu + sigma * epsilon,    epsilon ~ N(0, I)
```

The randomness is isolated in `epsilon`, which does not depend on `phi`. Gradients with respect to `mu` and `log_var` flow through the deterministic transformation.

Without this trick, the sampling operation `z ~ q_phi(z|x)` blocks gradient flow because you cannot differentiate through a random sample.

### 1.4 KL Divergence (Closed Form)

When both the posterior and prior are Gaussian, the KL divergence has a closed-form solution:

```
KL(N(mu, sigma^2) || N(0, 1)) = -0.5 * sum(1 + log(sigma^2) - mu^2 - sigma^2)
```

This avoids the need for Monte Carlo estimation of the KL term.

### 1.5 Reconstruction Loss

For continuous data, the reconstruction loss is typically MSE (equivalent to assuming a Gaussian decoder):

```
L_recon = || x - x_hat ||^2
```

For binary data, binary cross-entropy is used instead. The implementation uses MSE since the synthetic data is continuous.

## 2. Implementation Walkthrough

### 2.1 Encoder

The encoder maps input `x` to the parameters of the approximate posterior:

```python
class Encoder:
    def __init__(self, input_dim, hidden_dim, latent_dim):
        self.W1 = np.random.randn(input_dim, hidden_dim) * 0.01
        self.b1 = np.zeros(hidden_dim)
        self.W_mu = np.random.randn(hidden_dim, latent_dim) * 0.01
        self.b_mu = np.zeros(latent_dim)
        self.W_logvar = np.random.randn(hidden_dim, latent_dim) * 0.01
        self.b_logvar = np.zeros(latent_dim)
```

The forward pass produces both `mu` and `log_var`:

```python
def forward(self, x):
    self.x = x
    self.h = np.maximum(0, x @ self.W1 + self.b1)     # ReLU
    self.mu = self.h @ self.W_mu + self.b_mu
    self.log_var = self.h @ self.W_logvar + self.b_logvar
    return self.mu, self.log_var
```

Note the two separate output heads (`W_mu` and `W_logvar`) sharing the same hidden layer. The `log_var` parameterization (instead of `sigma` directly) ensures numerical stability — `sigma = exp(0.5 * log_var)` is always positive.

### 2.2 Reparameterization

The sampling step is a standalone function:

```python
def reparameterize(mu, log_var):
    std = np.exp(0.5 * log_var)
    eps = np.random.randn(*mu.shape)
    z = mu + std * eps
    return z, eps
```

Returning `eps` is important — the backward pass needs it to compute `dL/d_mu` and `dL/d_log_var`.

### 2.3 Decoder

The decoder maps latent `z` back to the data space:

```python
class Decoder:
    def __init__(self, latent_dim, hidden_dim, output_dim):
        self.W1 = np.random.randn(latent_dim, hidden_dim) * 0.01
        self.b1 = np.zeros(hidden_dim)
        self.W2 = np.random.randn(hidden_dim, output_dim) * 0.01
        self.b2 = np.zeros(output_dim)

    def forward(self, z):
        self.z = z
        self.h = np.maximum(0, z @ self.W1 + self.b1)
        self.x_hat = self.h @ self.W2 + self.b2
        return self.x_hat
```

The output is a linear layer (no activation), matching the unbounded range of the synthetic data.

### 2.4 Loss Computation

The total loss combines reconstruction and KL:

```python
def vae_loss(x, x_hat, mu, log_var):
    recon_loss = np.mean((x - x_hat) ** 2)
    kl_loss = -0.5 * np.mean(1 + log_var - mu ** 2 - np.exp(log_var))
    return recon_loss + kl_loss, recon_loss, kl_loss
```

Both terms are averaged over the batch. The balance between them is critical:

- If KL dominates, the encoder collapses to the prior (`mu -> 0`, `log_var -> 0`) and the decoder ignores `z` — this is **posterior collapse**.
- If reconstruction dominates, the latent space becomes unstructured and sampling from `N(0, I)` produces garbage.

### 2.5 Training Loop

```python
for epoch in range(epochs):
    for batch in batches:
        # Forward
        mu, log_var = encoder.forward(batch)
        z, eps = reparameterize(mu, log_var)
        x_hat = decoder.forward(z)

        # Loss
        loss, recon, kl = vae_loss(batch, x_hat, mu, log_var)

        # Backward (decoder)
        d_x_hat = 2 * (x_hat - batch) / batch.shape[0]
        d_z = decoder.backward(d_x_hat)

        # Backward (reparameterization + encoder)
        d_mu = d_z + mu / batch.shape[0]                       # recon + KL gradient
        d_log_var = d_z * 0.5 * eps * np.exp(0.5 * log_var)    # chain rule through reparam
        d_log_var += 0.5 * (np.exp(log_var) - 1) / batch.shape[0]  # KL gradient
        encoder.backward(d_mu, d_log_var)

        # Update weights
        encoder.update(lr)
        decoder.update(lr)
```

The gradient through the reparameterization step is the most subtle part. The KL term contributes directly to `d_mu` (gradient `mu / N`) and to `d_log_var` (gradient `0.5 * (exp(log_var) - 1) / N`). The reconstruction gradient flows through `z = mu + std * eps`, giving `d_z` for `mu` and `d_z * 0.5 * eps * exp(0.5 * log_var)` for `log_var`.

### 2.6 Generating New Samples

After training, generation is straightforward:

```python
z_sample = np.random.randn(1, latent_dim)   # sample from prior
x_generated = decoder.forward(z_sample)       # decode
```

If the latent space is well-structured, nearby points in `z`-space map to similar outputs, and interpolation between two `z` vectors produces smooth transitions.

## 3. Diagnostics

### 3.1 Monitoring the Loss Components

Track `recon_loss` and `kl_loss` separately:

- **Healthy training**: Both decrease initially, then KL increases slightly as the encoder learns to use the latent space.
- **Posterior collapse**: KL drops to near zero early and stays there. The reconstruction loss plateaus at a high value.

### 3.2 Latent Space Visualization

For 2-D latent spaces, plot the encoded `mu` values colored by the data mode (e.g., which Gaussian component the point came from). A well-trained VAE shows distinct but smoothly connected clusters.
