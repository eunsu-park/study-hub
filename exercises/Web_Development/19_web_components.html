What is Shadow DOM?

Shadow DOM provides encapsulation for DOM and CSS. Styles inside a shadow tree don't leak out, and external styles don't leak in. This makes components truly self-contained.

 Why Web Components?

Web Components are framework-agnostic, natively supported by browsers, and interoperate with any JavaScript framework. They use standard APIs: Custom Elements, Shadow DOM, HTML Templates, and CSS Custom Properties.
