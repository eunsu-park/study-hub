Why Semantic HTML Matters for SEO

Search engines use HTML structure to understand content hierarchy. Using <article>, <section>, <nav>, and <header> provides meaningful signals about your content organization.

Heading Hierarchy Checklist

ElementUsageSEO Impact
<h1>Page title (one per page)High
<h2>Major sectionsMedium
<h3>SubsectionsLow-Medium

Exercise 3: robots.txt and Sitemap

Example configuration files for search engine crawlers.

robots.txt

User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/
Sitemap: https://example.com/sitemap.xml

sitemap.xml

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/</loc>
    <lastmod>2025-01-15</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://example.com/lessons/seo-basics</loc>
    <lastmod>2025-01-15</lastmod>
    <changefreq>monthly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
